# 实习材料教师互检审查对照表

本对照表专供各指导教师在进行**学生实习档案袋互检与审查**时使用。请在审查每个档案袋时，严格依据此表逐一核实打勾（√）。审查不合格者，必须退回整改。

---

## 一、 档案袋封装与总体一致性审查
- [ ] **封面清单核对**：档案袋封面上黏贴的清单内容是否填写完整且无误，是否已对内部资料逐一打勾（√）。
- [ ] **核心组件是否齐全**：袋内必须同时包含以下材料：
  1. 培训会记录 + 签到表
  2. 实习手册
  3. 分散表
  4. 安全承诺书
  5. 实习协议
  6. 成绩登记表
  7. 其他佐证材料（在岗证明等）
- [ ] **一致性红线审查**：
  - [ ] **公司名称绝对一致**：检查《实习手册》、《分散表》、《在岗证明》、《实习协议》等所有材料上填写的公司名称是否**一字不差的完全一致**。
  - [ ] **专升本标识绝对一致**：针对专升本学生，资料各处的专业名称填写必须前后一致，不可漏填。

---

## 二、 核心单据专项审查

### 1. 培训会记录与签到表
- [ ] 是否具备指导教师/相关负责人的完整**签字**。
- [ ] 对应的**盖章**是否完整清晰。

### 2. 实习分散表
- [ ] **时间逻辑**：签署日期是否**早于**开始实习日期。
- [ ] **签名与意见**：意见栏是否完整，签名是否齐备。
- [ ] **双章规范**：盖章处必须同时盖有**冯院章（院长签名章）**和**设计学院公章**。

### 3. 安全承诺书
- [ ] **签名与日期**：必须有手写签字，且签署日期必须**早于**开始实习日期。

### 4. 实习协议（合同/三方协议）
- [ ] **基本信息**：企业名称、保险条款、薪酬等基本信息是否填写正确且无留空。
- [ ] **实习时长**：协议注明的实习日期跨度必须**不少于 28 天**。
- [ ] **盖章与签字时间**：签名盖章必须完整，且**第一阶段老师签协议日期早于 26年2月28日**。

### 5. 实习手册（核心重灾区）
- [ ] **月志数量与周期**：实习月志必须**一个月一份**（超过一个月需写多篇，含4月）。
- [ ] **时间逻辑**：日期填写逻辑无误（总结 $\to$ 教师意见 $\to$ 整改），不能在同一天。
- [ ] **企业部分**：具备企业反馈意见和清晰的企业盖章。
- [ ] **导师评语底线**：导师评语部分必须**不少于 4 行**。
- [ ] **成绩双轨制格式**：成绩认定处的格式必须是“**分数 + 五级制**”（例如：85分 / 良好）。
- [ ] **签字时间**：各处签字与日期是否严谨合规。

### 6. 成绩登记表
- [ ] **计算公式核实**：必须严格遵循公式：**企业成绩 30% + 导师成绩 70% = 学生总评成绩**。
- [ ] **总分绝对一致**：成绩登记表上的最终分数，必须与《实习手册》上的最终成绩保持**完全一致**。
