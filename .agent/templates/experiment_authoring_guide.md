# 实验内容撰写与架构防错规范指南 (Experiment Authoring Guide)

> **生效范围**：2025-2026-2 课程项目及后续教务材料生成
> **沉淀来源**：结合《交互产品开发》等课程真实讲义转化经验与 Subagent 架构复盘。

本指南旨在规范将教师的原始教学讲义（通常是具备强教学节奏的 Markdown 文档）转化为系统可用的结构化双轨 YAML 格式的过程，并针对双轨架构的脆弱性提出维护建议。

---

## 1. 内容映射与提取准则 (Mapping Rules)

教师原生的 Markdown 讲义通常兼具“指导语、示例占位、避坑提示、流程图结构”。在转化为 `practices/experiments/exp_X.yaml`（现在的**单一事实源**）时，需遵循以下分片与降维法则：

### 1.1 教务元数据填充 (Meta Data)
- **提取目标**：将宏观的教学目标、所需软硬件、核心原理框架抽取出来，直接填入该实验专属的 `exp_X.yaml` 根级字段。
- **对应关系**：
  - “一、实验目的” ➔ `objectives`
  - “二、实验条件/要求” ➔ `equipment`, `requirements`
  - “三、实验方法/原理”（如：什么是 Agent？开发的工作流全貌是什么？）➔ `method_theory`

### 1.2 执行细节与步骤拆解 (Execution Data)
对于 Markdown 中强干预式的“实验步骤”与“结果分析”，应精准拆解到同一个 YAML 的 `steps` 结构中：
- **教学指令“分片化”**：将标准的操作指令（“点击这个”、“输入那个”）放入 `guide_text`。将老师原本的警示性语言（“如果AI建议使用框架，立即制止”）也融入 `guide_text`（建议未来生成器引入 `warnings` 字段来单独承载以改变排版样式）。
- **示例与输出“外置化”**：教师提供的截图演示或输出要求，不能混在纯文本指令中，必须转移至 `report_prompt` 数组，通过 `type: text` 或 `type: image` 控制学生实验报告上的图文穿插版式。
- **反思提问“聚焦化”**：讲义最后的体验反思（如“哪一个环节对代码生成影响最大？”）必须全数平移至 `analysis_prompts` 中作为学生的答题提示语。

## 2. YAML Schema 富语义扩展建议 (Future Enhancement)

目前 `exp_*.yaml` 仅包含 `guide_text` 和 `report_prompt`。为更好保留 Markdown 的排版与教学节奏，建议未来升级 `experiment_doc_schema.md`，为单个 Step 引入以下可选富语义节点：
- `warnings: list[str]`：剥离避坑指南，生成 Word 时渲染为醒目的警告框。
- `examples: list[dict]`：剥离教学示例图与示例提示词，形成“老师教”与 `report_prompt`（学生做）的对仗。
- `flow_steps: list[str]`：将 Markdown 中的流程图抽象为有序的流程节点数组。

## 3. 单一事实源的架构优势与运维建议

由于已废弃“总表 + 增量”的双轨架构，数据遗漏和“孤儿数据”的问题已被根除。所有的实验都以去中心化单文件的形式存放在 `practices/experiments/` 下。

### 3.1 人工维护规范
- **新建实验**：只需在 `practices/experiments/` 目录下新建 `exp_{id}.yaml`，填入所有必需字段即可。引擎会自动读取并把它加入到教务大纲生成流程中。
- **删除实验**：直接删除对应的 `exp_X.yaml` 文件，所有相关的元数据与执行数据将一并被安全移除。
- **空壳占位法则**：如果在规划阶段不确定详细步骤，可以先创建一个包含元数据，但 `steps: []`，`analysis_prompts: []` 的“大纲骨架”文件。

### 3.2 脚本级防御设计 (推荐研发侧加入)
未来的生成引擎（如 `course_loader.py` 或 `generate.py`）需保持防御性编程：
1. **全局门限校验**：组装所有 `exp_X.yaml` 时，动态累加各自的 `hours`，与 `course.yaml` 或大纲配置中的“总实验学时”进行核对。如果数值不符，抛出致命错误，防止教务大纲的学时不平。
2. **沙盒化加载**：捕获单次解析的 `yaml.YAMLError`，打上异常标记并跳过损坏的实验，防止因一个 YAML 缩进错误导致整个学期的课程材料生成中断。
3. **中文错误日志**：屏蔽纯粹的 Python Traceback，改用易懂的业务级中文报错指引。
