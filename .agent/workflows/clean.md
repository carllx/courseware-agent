# 废弃素材清理工作流 (Clean)

本工作流用于扫描并清理课程脚本中已不再引用的废弃素材及构建产物，帮助维护整洁的项目环境。

## 使用方法 (参数说明)
`/clean [课程名] [--week N] [--delete]`

- `[课程名]`: (可选) 目标课程的目录名称。
- `--week N`: (可选) 限制扫描和清理的特定周次。
- `--delete`: (可选) 若提供此参数，则直接执行删除操作。

## 步骤说明

### 1. 解析参数
提取并解析用户命令中的 `[课程名]`、`--week N` 和 `--delete` 参数，为后续脚本运行准备上下文。

### 2. 执行干跑扫描
运行 Python 清理脚本进行干跑扫描（Dry-run）。该操作仅生成废弃素材和产物的报告，不会执行物理删除。

> **Action**
> 运行下方命令（替换相应的参数，但不要传递 `--delete`）：
> ```bash
> python cleanup_stale_assets.py [课程名] [--week N] // turbo
> ```

### 3. 安全校验与解读报告
读取扫描步骤生成的 `cleanup_report.json`。
1. **必须首先检查 `errors` 数组**：如果存在任何解析异常，**立即中止工作流**，向用户报告具体的解析错误，并拒绝执行后续的清理步骤。
2. 若无错误，提炼并向用户总结关键发现（例如：废弃素材的数量、占用空间、受影响的模块等）。

### 4. 执行清理
在确认无解析错误，且获得用户确认后（或当初始指令包含 `--delete` 时），执行实际的文件清理操作。

> **安全底线**：底层的 Python 脚本已被硬编码保护。如果在解析出错的情况下强行调用 `--delete`，脚本将自动拦截移动操作并以 Exit Code 2 退出。

> **Action**
> 等待用户确认。确认后运行下方命令：
> ```bash
> python cleanup_stale_assets.py [课程名] [--week N] --delete
> ```
