# /extract_quiz — 逐字稿课间练习提取器

> 核心功能：遍历指定周次 `src/M*.md` 中的全部 `[ACTIVITY] Type: Quiz` 块，
> 按模块编号自动编排序号，转换为标准题库导入格式。

## 使用方式

```
/extract_quiz <课程名> W<周次号>
```

**示例**：
- `/extract_quiz 交互产品开发 W04`
- `/extract_quiz 信息可视化 W02`

**可选参数**：
- `--chaoxing` — 输出超星学习通智能导入格式（调用 chaoxing-quiz Skill 的格式规范）
- `--plain` — 输出纯净题目文本（默认模式，按下方标准格式输出）

---

## 前置条件

1. 目标课程目录存在：`<工作区>/<课程名>/weeks/W<XX>_*/src/`
2. `src/` 下至少包含一个 `M*.md` 逐字稿文件
3. 逐字稿中至少包含一个 `> [ACTIVITY]` + `> **Type**: \`Quiz\`` 块

---

## Step 1：定位目标目录

1.1 根据用户输入的 `<课程名>` 和 `W<周次号>`，在工作区中定位目标目录：
```
<工作区>/<课程名>/weeks/W<XX>_*/src/
```

1.2 `list_dir` 列出 `src/` 下所有 `M*.md` 文件，按文件名自然排序。

1.3 **记录模块清单**：提取每个文件的模块编号（如 `M00`, `M01`, `M02`...），
排除非模块文件（如 `task.md`、`sourcing_checklist.yaml` 等）。

---

## Step 2：逐模块扫描 Quiz 块

对每个 `M<XX>_*.md` 文件执行以下操作：

2.1 **全文读取** — `view_file` 读取整个文件内容。

2.2 **识别 Quiz 块** — 定位所有匹配以下结构的块（注意：缩进和引用标记 `>` 可能有细微差异）：

```markdown
> [ACTIVITY]
> **Type**: `Quiz`
> **Duration**: `Xmin`
> **Desc**: <题目描述>
> **Q**: <题干>
> **Options**: A. xxx | B. xxx | C. xxx | D. xxx
> **Answer**: `X`
> **Explain**: <解析>
```

**字段提取规则**：
- `Desc` — 题目简述/标题（可选，用于生成知识点标签）
- `Q` — 题干文本（必需）
- `Options` — 选项列表，用 ` | ` 分隔各选项（必需）
- `Answer` — 标准答案，单字母或多字母（必需）
- `Explain` — 答案解析（可选，若存在则保留）

2.3 **编号规则** — 每个模块内的 Quiz 题目独立计数，序号包含周次前缀：
- 第一道题序号为 `W<周次号>-M<模块号>-Q1`
- 第二道题序号为 `W<周次号>-M<模块号>-Q2`
- 以此类推（例如：`W04-M01-Q1`、`W04-M02-Q3`）

2.4 **累计全局题号** — 同时维护一个从 `1` 开始的全局连续编号，用于最终输出。

---

## Step 3：转换为标准题库格式

### 3.1 默认模式（`--plain`）

对每道提取到的 Quiz 题，按以下模板输出：

```
<全局题号>. [W<周次号>-M<模块号>-Q<模块内题序>]【单选题】<题干>
A.<选项A>
B.<选项B>
C.<选项C>
D.<选项D>
答案：<答案字母>
答案解析：<解析文本>
知识点：<从 Desc 字段提取的关键词>
```

**格式细节**：
- **题型自动识别**：
  - 若 `Answer` 为单字母 → `【单选题】`
  - 若 `Answer` 包含多个字母（如 `AB`、`ACD`）→ `【多选题】`
  - 若 `Options` 字段不存在且 `Answer` 为 `对/错/T/F` → `【判断题】`
- **选项格式**：每个选项独占一行，以 `A.` `B.` `C.` `D.` 开头
  - 从 `Options` 字段按 ` | ` 分割
  - 去除原始选项中的前缀（如 `A. ` 或 `A、`），统一重新编排为 `A.` 格式
- **选项间不空行**
- **题与题之间空一行**
- **非必填项规则**：`答案解析` 和 `知识点` 仅在原始数据中存在时输出
- **序号标记**：在题号后、题型标注前，插入 `[W<周次号>-M<模块号>-Q<题序>]` 标识来源周次与模块

### 3.2 超星模式（`--chaoxing`）

若用户指定 `--chaoxing`，则：
1. 加载 `chaoxing-quiz` Skill 的格式规范
2. 序号改为纯数字 `1. 2. 3.`（不含模块前缀）
3. 按 [chaoxing_format_spec.md] 规范严格输出
4. 在文件顶部添加注释：`# 来源：<课程名> W<周次号> 逐字稿自动提取`

---

- 超星模式：`<课程名>/practices/materials/W<XX>/chaoxing_quiz_w<xx>.txt`

---

## Step 5：后处理（可选）

5.1 若用户在后续对话中要求**合并多周题目**，支持追加模式：
- 读取已有文件，续接全局题号
- 在文件中以 `--- W<XX> ---` 分隔不同周次

5.2 若用户要求**过滤特定模块**，支持 `--module M01,M03` 参数只提取指定模块。

---

## 错误处理

| 场景 | 处理方式 |
|---|---|
| 目标目录不存在 | 列出可用的周次目录供用户选择 |
| 无 Quiz 块 | 报告"未在该周次逐字稿中发现课间练习" |
| Quiz 块缺少必填字段 | 跳过该题并在摘要中标记为"格式异常" |
| `Options` 分割失败 | 尝试按 `\n` 换行分割作为降级方案 |
