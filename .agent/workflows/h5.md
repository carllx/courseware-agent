# /h5 工作流

本工作流将 Markdown 逐字稿转换为 H5 交互式课件预览（Vite + React），供浏览器端查看。
支持三种模式：

- **全量模式** (v2.0): 一键生成所有课程所有讲次，统一 Dashboard 浏览
- **单讲模式** (v1.0 兼容): 指定单个脚本文件生成
- **片段模式** (v2.1): 直接渲染单个 `M0X.md` 源文件，跳过编译，提供 `vscode://file` 精准直跳
- **热重载模式** (v2.2): 保存 `.md` 文件后自动重建 + 浏览器自动刷新，无需手动操作
- **实时工作台 Craft-room** (v3.0): 热重载激活时，后台启动验证管线，并在浏览器端实时投射验证面板面板、健康度指示器和 Agent 批注层（基于段落指纹机制不漂移）。

支持纯文本/图文模式，以及音频播放 + SRT 字幕同步。

## 前置条件

1. **环境**: Python 3 (conda mybase) + Node.js
2. **依赖**: workspace 根目录已有 `.agent/scripts/validation/` 目录下的解析器和验证器（如 `script_parser.py`, `validate_runner.py`）
3. **模板**: `engines/h5_template/` 目录存在
4. **热重载/工作台** (v2.2+): Python 解释器需在 `PATH` 中可用（插件默认使用 `python`），或通过环境变量 `H5_PYTHON` 指定完整路径

## 执行步骤

### Step 0-A (可选): 段落级动态 TTS（推荐）

当前架构通过浏览器端 **TTS Toolbar** 按需合成段落音频，无需预先准备 MP3/SRT 文件。

**前置条件**：
1. Chrome 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. 导入两个油猴脚本（位于 `.agent/skills/doubaotts/scripts/`）：
   - `userscript.js` — 原版豆包 TTS 引擎（提供 `window.tts()` API）
   - `tts_bridge.user.js` — H5 凭证桥接器（postMessage 中继）
3. 登录 [doubao.com](https://www.doubao.com) 确保有有效会话

**使用流程**：
1. 在 H5 预览中点击 TTS Toolbar 的 **「⚙️ 连接豆包」** 按钮
2. 弹窗自动打开 doubao.com 并通过桥接脚本交换凭证
3. 连接成功后状态灯变绿 🟢，点击 **「🎬 提取」** 按钮批量合成
4. 音频将通过 Vite 中间件自动保存到项目本地文件系统（`weeks/<周次>/tts/<fp>.aac`），支持跨浏览器共享和静态部署。
5. 编辑逐字稿后仅需重新提取**文本变更的段落**（增量 diff 机制）

> [!TIP]
> 弹窗必须保持打开状态才能提取。提取完成后音频已缓存到本地，关闭弹窗不影响已缓存的播放。如果之前在旧架构积累了 IndexedDB 缓存，可通过 TtsToolbar 中的迁移按钮一次性导出到本地。

### Step 0-B (Legacy): 离线批量 TTS + SRT 对齐

> [!WARNING]
> 以下流程为旧版离线管线，已被 Step 0-A 的动态桥接架构取代。仅在无法使用 doubao.com 时作为后备方案。

### Step 1: 生成数据

在 **workspace 根目录** 下运行生成脚本。

#### 模式 A: 全量模式（推荐）

自动扫描 workspace 下所有课程和讲次，生成 `manifest.json` + 分讲 JSON。

```bash
/opt/anaconda3/envs/mybase/bin/python engines/generate_course_h5.py --all
```

也可指定单门课程的全量生成：
```bash
/opt/anaconda3/envs/mybase/bin/python engines/generate_course_h5.py 交互产品开发 --all
```

#### 模式 B: 单讲模式（兼容旧版）

```bash
/opt/anaconda3/envs/mybase/bin/python engines/generate_course_h5.py 交互产品开发 scripts/W01_交互体系概论基础.md
```

#### 模式 C: 片段模式（开发调试推荐）

仅渲染单个 `M0X.md` 源文件，跳过 `dumptext.py` 编译，`copy-locator-btn` 直接指向源文件精确行号。适用于逐字稿迭代修改时的快速预览与精准定位。

```bash
/opt/anaconda3/envs/mybase/bin/python engines/generate_course_h5.py \
  交互产品开发 --fragment \
  交互产品开发/weeks/W01_交互体系概论基础/src/M01_数字产品之殇_我们为什么会抓狂.md
```

> [!TIP]
> 片段模式特别适合 Agent 接收 `copy-locator-btn` 定位信息后精准修改源文件——无需全局编译，修改 → 渲染 → 验证闭环从分钟级缩短到秒级。

> **功能特性**:
> 1. **自动解析**: 复用 `script_parser.py`，支持 VISUAL/SPEECH/ACTIVITY/TAG 等全部块类型
> 2. **主题注入**: 自动加载 `visual_system.yaml`，CSS 变量运行时注入
> 3. **课程自动发现**: 扫描 workspace 下所有含 `course.yaml` 的子目录
> 4. **结构感知**: 自动识别 weekly (W*.md) 和 phasic (S*.md) 课程结构
> 5. **模板实例化**: 首次运行时自动从 `h5_template/` 复制到 workspace `build/h5_preview/`
> 6. **增量同步**: 后续模板更新时自动覆盖更新的文件
> 7. **音频检测**: 自动检测 `scripts/tts/audio/` 和 `scripts/tts/srt/` 中的对应文件
> 8. **符号链接**: 自动链接各课程 `weeks/*/public/`（V5）或 `weeks/*/assets/`（旧架构）、`build/tts/` 到 `public/courses/<courseId>/`
> 9. **视觉完整度**: 统计每讲的图片覆盖率 (已有/总数)
> 10. **源映射回馈**: 正式模式自动解析 compiled.md 的 `BEGIN/END` 标记，将 `srcPath` 从 compiled.md 行号回馈为源文件行号
> 11. **片段直渲**: `--fragment` 模式跳过 `dumptext.py` 编译，直接解析 `M0X.md`，`srcPath` 天然精准

### Step 4: 验证

#### 全量模式验证

1. **Dashboard 主页**: 显示所有课程卡片（含讲次数量、视觉覆盖率、音频徽章）
2. **课程页**: 点击课程卡片进入周次列表，每个周次显示 slides 数/段落数/覆盖率
3. **预览器**: 点击周次进入单讲预览

#### 单讲预览验证

1. **模块导航**: 底部 Tab 可切换模块，每个 Tab 显示 slide 数量徽章
2. **幻灯片**: 左侧区域渲染图片或灰盒占位（灰盒显示预期素材路径）
3. **文本面板 (Craft Room)**: 右侧显示逐字稿，标签类型有颜色区分。面板头部包含 `[👁️ 记忆检视]` Toggle，支持在文字全隐模式下仅靠锚词芯片进行排练。
4. **翻页与温度胶囊**: 键盘方向键或底部导航点均可翻页。底部导航点以**胶囊形态**展现宏观数据：宽度映射该 Slide 中的段落字数，背景色映射段落情感温度（暖色=故事/案例，冷色=理论/强调）。
5. **防误触排练机制**: 在记忆检视模式下，首次点击隐藏段落仅用于“揭示提示字”，系统自动拦截原有的切页闪烁和语音播报，保障心流不断裂。
5. **🔊 音频** (若有): 顶栏右侧显示音频徽章，播放器可播放/暂停/拖拽
6. **🔗 联动** (若有音频): Audio↔Slide↔Text 三向自动联动
7. **🛠️ 实时反馈** (Craft-room 环境下): 
   - 🔴 **HealthDot**: 顶栏右侧全局健康状态灯，点击展开详细数据
   - 📊 **DurationGauge**: 底部模块导航栏显示各模块估算耗时百分比进度条
   - 🔍 **ValidationOverlay**: 右侧边缘展开抽屉，展示模块填充热力栏和断链详情
   - 📍 **锚点跳转**: 文本面板段落旁边的 📍 按钮可直接通过 `vscode://file` 呼出编辑
   - 📝 **Agent 批注**: 文本面板的段落指纹吸附层，显示内容稀释或基调偏离预警

### Step 5: 热重载与边写边审工作台 (Craft-room, v3.0+)

启动 `npm run dev` 后，**Vite 热重载插件自动激活**。工作台进入"双管线监控"模式：
1. **P0 极速渲染（~300ms）**: 修改 `.md` 文件并保存，浏览器不仅在 ~1s 内自动刷新最新画面。
2. **P1 异步验证（~2000ms）**: 画面刷新后后台静默启动 `validate_runner.py` 进行综合研判（内容长度、断链情况、预算对齐）。
3. **心流保护呈现**: 如果您高频写字，报警 UI 会被冻结；当您停笔长于防抖期后，ValidationOverlay 等新界面会柔和淡入提醒发现的问题。

终端日志示例：
```
[h5-hot-reload] 🔬 信息可视化/W01_Visual_Perception/M00_课程导览
[h5-hot-reload] ✅ 完成 (315ms)
```

工作模式：
- **默认 (week 模式)**: 重建变更文件所属的整个教学周 JSON，保留完整上下文
- **片段模式**: `H5_WATCH_MODE=fragment npm run dev`，仅重建单模块（更快但丢失整周上下文）

环境变量：
- `H5_WATCH_MODE=fragment` — 切换为片段模式
- `H5_PYTHON=/path/to/python` — 指定 Python 解释器
- `H5_DEBOUNCE=800` — 自定义防抖时间（毫秒）

> [!TIP]
> 热重载插件会自动保持你在 H5 预览中的当前浏览位置（section/slide），修改后无需重新导航。

## 故障排除

- **"脚本文件不存在"**: 检查脚本路径是否正确，必须是相对于课程目录的路径
- **图片不显示**: 检查 `public/courses/<courseId>/` 下符号链接是否正确指向素材目录（V5：`weeks/*/public/`，旧架构：`weeks/*/assets/`）
- **"Cannot find module"**: 在 `build/h5_preview/` 下运行 `npm install`
- **主题色不对**: 检查 `visual_system.yaml` 路径和 palette 字段格式
- **TTS 连接失败（动态模式）**: 确认 Tampermonkey 已安装 `tts_bridge.user.js` 和 `userscript.js`；doubao.com 弹窗须保持打开
- **TTS 提取全部失败**: 检查 doubao.com 弹窗控制台是否有 `window.tts is not a function` 错误（原版 userscript 未加载）
- **TTS 缓存丢失**: 编辑脚本后仅变更段落需重新提取（增量 diff）；若全量丢失，检查 IndexedDB `h5_tts_cache`
- **TTS 音频播放（离线旧版）**: 若使用 Legacy 离线管线，检查 MP3 在 `build/tts/audio/` 且文件名与脚本 stem 一致
- **Dashboard 空**: 确认已运行 `python engines/generate_course_h5.py --all` 生成 `manifest.json`
