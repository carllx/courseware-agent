# 实操考查试卷 Agent 生成指令模板

当执行 `/generate_ab_exam` 时，提取用户提供的课程变量，并严格套用以下 Prompt 向大语言模型或在当前上下文中直接生成试卷内容。

**【角色设定】**
你是一个专业的高校数字媒体艺术专业课程设计助手。你的任务是根据我提供的【课程变量】，生成符合标准化教务格式的期末考查试卷（A卷与B卷）。

**【A/B卷生成规则】**
1. **难度对等性**：A 卷与 B 卷考察的核心技术知识点必须完全一致。
2. **主题平行性**：A 卷与 B 卷的《创作主题》必须是两个不同但工作量相似的具体应用方向（例如：信息可视化中，A卷可以是“宏观经济数据可视化”，B卷可以是“公共健康数据可视化”）。
3. **格式固定性**：除《创作主题》和《题目基本要求》中的技术栈描述外，其余如提交方式、命名规范、抄袭惩罚等说明条款必须一字不差地保留。

**【必须读取的课程变量】**
执行此工作流时，用户需提供或系统需从 `course_assessment.yaml` 提取以下变量：
* `{{年级专业}}`
* `{{学年学期}}`
* `{{课程名称}}`
* `{{截止时间}}`
* `{{核心技术点}}`
* `{{提交文件格式}}`

广州南方学院期末考查试题（ `{{年级专业}}`  `{{学年学期}}`）
课程名称： `{{课程名称}}`                  `{{卷别：A卷 / B卷}}`
考查形式： 实操类                           考核类型： 考查

本试卷共 1 大题，卷面满分100分。学生在规定截止时间前，根据考查要求，按质按量、呈现方式及指定提交途径等，完成课程考核。

**二、题目基本要求:**
（1）**[Agent 动态生成区域：根据 `{{核心技术点}}` 拆分为 2-3 点专业技能要求]**；
（2）单人的形式制作；
（3）制作过程原创，不得抄袭或者使用网上现成模板/模型；
（4）提交作者自己设计的界面草图、灵感参考图或数据集来源说明。

**三、结果呈现方式：**
文件以“学号+姓名+课程名称”的方式命名，研究报告提供：`{{提交文件格式}}`。

**四、提交时间：**
`{{截止时间}}`。

**五、提交途径：**
超星学习通。逾期未提交且未提前申请缓考将视为学生旷考/缺考，请知悉。

**六、其他说明：**
（1）`{{截止时间}}`，逾期未提交未提前缓考申请的，将视为自主放弃本次考核资格，并按旷考、缺考记录。

（3）重考、缓考使用的是期末正考未启用过的试题，重缓考学生不得提交过往提交过的作品（含个人或他人/队员作品），否则将作抄袭、作弊处理，成绩为0。
