# MSG-013: W02 Deep Audit 教务端修复项

> **来源**: `/audit --deep --course "交互产品开发" --week 2` (2026-04-30)

---

## 项目 1: `extract_week.py` cwd 自适应

**问题**: `audit.md` Step 1 命令 `python 《课程》/extract_week.py --week N` 在 workspace 根目录执行时报 `找不到文件 course.yaml`，因为脚本内部 `open('course.yaml')` 使用相对路径，而 cwd 不在课程子目录内。

**建议修复**:
- 方案 A: 脚本内自动定位 `course.yaml`（`Path(__file__).parent / 'course.yaml'`）
- 方案 B: 在 `audit.md` Step 1 命令前加 `cd <课程>/`

**优先级**: P2（不阻塞审计，但每次手动 cd 增加操作摩擦）

---

## 项目 2: W02 孤立素材清理

**问题**: `validate_visuals.py` 报告 W02 存在 **51 个孤立素材**（`slides/*-b.png` / `*-c.png` / `*-d.png`），全部为同 Slide ID 的多变体冗余生成，未被任何脚本引用。

**建议**:
- 确认是否为 PPT 生成器批量产出的备选变体（若是，建议在生成器侧加 `--cleanup-orphans` 选项）
- 或在 `validate_visuals.py` 输出中区分"备选变体"与"真正孤立"

---

## 项目 3: `package.yaml` schema 增 `supported_objectives` 字段

**问题**: OBE 审计 G6 要求脚本 frontmatter 与 `course.yaml` calendar 的 `supported_objectives` 双向交叉校验。当前 `package.yaml` schema 无此字段，课程端无法声明。

**建议**: 在 package schema 中新增可选字段：
```yaml
supported_objectives:   # list[str], 可选
  - "知识1"
  - "知识2"
```

**依赖**: schema 升级后，课程端将补填 W02 数据。
