# 屏幕照明与环境适配工作流 (Monitor Illumination and Monitor Surrounds)

## Prerequisites & Context (前提与背景)
在数据可视化和界面设计中，准确感知表面的亮度（Lightness）和颜色至关重要。屏幕上呈现的颜色和对比度受到用户当前视觉适应状态的严重影响，而这一状态主要由环境照明（Room Illumination）和屏幕周围环境（Monitor Surround）决定。
> **理论深潜**: `bash scripts/query_theory.sh "视觉系统如何适应环境亮度和对比度？"`

## Comprehensive Guide & Best Practices (综合指南与最佳实践)

### 1. 屏幕与背景墙亮度平衡
- **墙面颜色与反射率**：显示器后方的墙壁应为浅中性色，并反射与显示器发出的光量相近的光；而面向屏幕的墙壁（即用户背后的墙壁）应具有较低的反射率（中至深灰色），以减少屏幕反光。
- **光源避免直射屏幕**：环境照明灯具的位置应精心设计，绝不能直接在屏幕上产生反射或明显的高光。
- **理论依据**: `bash scripts/query_theory.sh "What is Guideline 3.6 (G3.6) regarding monitor surround lighting?"`

### 2. 投影系统的环境光控制
- **遮光挡板的使用**：在设置投影系统时，需通过挡板（Baffles）遮挡投影屏幕，确保最少的环境光直接照射在屏幕上。
- **环境墙面控制**：与显示器类似，墙壁应为低反射率（中至暗灰色），以减少不可避免的散射光影响投影画面的对比度。
- **理论依据**: `bash scripts/query_theory.sh "What is Guideline 3.7 (G3.7) regarding projection system lighting?"`

### 3. 环境光补偿机制 (Ambient Light Compensation)
- 现代 LCD/OLED 显示器通常会反射 1.5% 到 2.0% 的环境光。这种反射会改变暗部的显示表现。
- 在标准办公照明下，通过增加 1.5% 的环境光基数，屏幕的 sRGB 输出转换为 CIE L*（感知亮度）时会表现出极佳的线性对应关系。因此在正常的开灯办公环境中，通常不需要对 RGB 输入应用额外的亮度补偿校正。
- **视觉参考**: 参阅 `../../images/f03-22-9780128128756.jpg` 查看环境光对 L* 感知曲线的线性化影响。

### 4. 虚拟环境与现实光照的匹配 (Matching Virtual and Physical Lighting)
- 当需要在屏幕上准确再现物理对象颜色（如布料样本、材质设计）时，必须匹配室内标准亮度与光源色温。
- 校准屏幕白点，使其与屏幕旁举起的白纸在环境光下的视觉表现相匹配。
- 物理屏蔽：使用专门设计的遮罩（Masks）阻挡多余的环境光落在显示器显像区域，同时保持屏幕边框和桌面的照明与虚拟场景光照一致。
- **视觉参考**: 参阅 `../../images/f03-23-9780128128756.jpg`。

## If/Then Troubleshooting Logic (故障排除逻辑)
- **If** 屏幕暗部细节丢失，整体对比度下降：
  - **Then** 检查是否由环境光直接照射到屏幕或面朝屏幕的墙壁反射率过高所致。重新调整光源或更换深灰色墙面。
- **If** 屏幕中的白色与环境中的标准白纸呈现色差（偏蓝或偏黄）：
  - **Then** 重新校准显示器的白点与色温，并统一室内标准光源（如使用 D65 标准光源）。
- **If** 投影系统的图像发灰，黑色不纯：
  - **Then** 增加遮光挡板，并确保投影室环境墙壁为中灰到暗灰色以吸收散射光。

## Verification Checklists (验证清单)
- [ ] 显示器后方的墙壁颜色是否为中性且亮度与显示器相近？
- [ ] 面向屏幕的墙面是否使用了低反射率的暗灰色材料？
- [ ] 所有的室内光源是否已经调整，避免在屏幕上形成镜面反射？
- [ ] 在展示关键色彩匹配的系统时，显示器的白点是否与环境中的物理白纸视觉匹配？
- [ ] 若为投影系统，是否已经加装了挡板阻挡环境光直射屏幕？
