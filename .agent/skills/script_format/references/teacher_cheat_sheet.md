# 教师备课脚手架 (Teacher Cheat Sheet)

> **定位**：本文件是 `SKILL.md` §5.1 教师分级赋能策略的配套工具。按教师经验级别提供不同强度的备课填空引导。
>
> **加载时机**：Lv.1 新手教师备课、`/write` 工作流首次使用时按需加载。

---

## Lv.1 全约束模式（三层全启用）

> 适用于语言能力偏弱的新手教师。按以下逐步填空即可产出结构完整的讲稿段落。

### 模板：完整模块备课骨架

```markdown
<!-- ═══════════════════════════════════════════════════ -->
<!-- 第一层 · 叙事启动（模块 ≥8 分钟时使用）               -->
<!-- ═══════════════════════════════════════════════════ -->

在大家的认知中，[当前领域过去的常识/做法] 一直以来被视为理所当然。

但真实情况是，[发生了什么矛盾/冲突/痛点]，
其后果是 [具体的代价/损失/用户抓狂的场景]。

**(Pause: 3s)**

那么，问题的破解口究竟在哪？

<!-- ═══════════════════════════════════════════════════ -->
<!-- 第二层 · 认知传递（必填 · 核心层）                     -->
<!-- ═══════════════════════════════════════════════════ -->

核心定义：[用一句完整的断言句概括今天教的知识点]。

这个原理从以下三个维度重构了我们的认知：

第一，[维度一名称]：[一句话解释该维度的核心机制]。
第二，[维度二名称]：[一句话解释该维度的核心机制]。
第三，[维度三名称]：[一句话解释该维度的核心机制]。

（每个维度配一张 Slide，使用 Split/Grid 布局，
  挂载 **List** 字段将要点同步显示在 PPT 上。）

<!-- ═══════════════════════════════════════════════════ -->
<!-- 第三层 · 实证锚定（有案例时使用）                      -->
<!-- ═══════════════════════════════════════════════════ -->

> [CASE STUDY: 案例标题]

[公司/项目名] 曾面临 [困境]，
他们采取了 [具体动作]，
最终实现了 [可量化的结果/行业启示]。

（配一张 Layout: Full 真实截图/视频，≤250 字收束。）

<!-- ═══════════════════════════════════════════════════ -->
<!-- 互动检查点（连续讲授 ≥10 分钟时强制）                  -->
<!-- ═══════════════════════════════════════════════════ -->

> [ACTIVITY]
> *   **Type**: `QA`
> *   **Duration**: `1min`
> *   **Desc**: [一个检验学生是否理解核心断言的快速问题]
```

### 使用说明

1. 将模板复制到目标模块的 Markdown 文件中
2. 逐个替换 `[方括号]` 内的占位符
3. 填写完成后，润色为自然的口语白话
4. 补充 `> [VISUAL]` 块（参照 `SKILL.md` §3 字段规范）

## Lv.2 核心约束模式（仅第二层强制）

> 适用于有一定教学经验的教师。仅需确保认知传递层的底线合规。

### 精简自检清单

- [ ] 核心知识点是否以**断言句**开头（而非名词标签）？
- [ ] 是否拆分了 ≥2 个支撑维度（避免平铺直叙）？
- [ ] 连续讲授是否超过 10 分钟未插入互动检查？
- [ ] 每个 `[VISUAL]` 块是否包含必填三要素（Slide/Layout/Scene）？
- [ ] 段落是否超过 350 字硬性上限？

> **叙事启动与实证丰化**为推荐项——如果你对某个模块已有自己的引入方式，完全可以跳过 SCQA 和 STAR 结构。

---

## Lv.3 底线约束模式（仅物理规范）

> 适用于表达流畅的资深教师。系统仅检查以下基础卫生指标。

### 自动审查的底线

| 指标 | 底线 |
|:---|:---|
| 单段落字数 | ≤ 350 字 |
| 视觉间隔 | ≤ 360 字无 `[VISUAL]` |
| 模块 Slide 数 | ≥ `⌈讲授净分钟 ÷ 3⌉` |
| `[ACTIVITY]` 总时长 | > 0 |

> 超出底线的部分（如叙事弧线质量、情感共鸣深度）由教师自行把控，系统不做强制审查。

## 附：三层与 H5 Layout 推荐对照

| 约束层 | 推荐 H5 Layout | 视觉意图 |
|:---|:---|:---|
| 第一层（叙事启动） | `Full` / `Center` | 全屏沉浸痛点画面，极简留白制造悬念 |
| 第二层（认知传递 · 断言） | `Center` + `CTA` | 核心结论高亮定格 |
| 第二层（认知传递 · 拆解） | `Split` / `Grid` | 结构化要点并列排布 |
| 第三层（实证锚定） | `Full` | 真实案例截图/视频全屏呈现 |
| 互动检查点 | `Split: Workshop` | 左侧任务说明，右侧操作区域 |

## 渐进脱稿训练指引（防认知卸载依赖）

> **理论基础**：Sparrow et al. (2011) 的"谷歌效应"研究表明，当人知道信息可通过外部工具获取时，
> 内部记忆编码深度会显著下降。长期依赖逐字稿和视觉提示可能弱化教师对课程内容的内化程度。

### 三阶段脱稿路径

| 阶段 | 依赖工具 | 训练方法 | 目标 |
|:--|:--|:--|:--|
| **Lv.1 全稿** | 逐字稿 + PPT + Presenter View | 逐字朗读排练 3 遍 | 熟悉内容流 |
| **Lv.2 骨架** | 仅骨架卡片（H3 标题 + 金句） | 看骨架卡片即兴展开 | 内化逻辑结构 |
| **Lv.3 脱稿** | 仅 PPT 图片（零文字提示） | 看图即兴讲述 | 内化全部内容 |

### 每次备课的"主动回忆"练习

1. **闭卷骨架还原**：合上所有材料，在白纸上默写本模块的 H3 标题骨架链
2. **看图说话**：仅看 PPT 图片（不看备注），尝试讲出对应段落的核心论点
3. **错位检测**：标记无法回忆的段落 → 这些段落需要额外排练或简化

> **核心口诀**：PPT 是你的路标，不是你的拐杖。路标帮你确认方向，但双腿必须是自己的。
