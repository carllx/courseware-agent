## §2.5 修辞通胀检测 (Rhetorical Inflation Check)

> **来源**：M00 课程导览复盘——IAR 在段落粒度有效但无法拦截句子粒度的修辞膨胀。

### 2.5.1 定义

当同一句话可以用 ≤ 50% 的字数表达相同信息量时，该句存在**修辞通胀**。

### 2.5.2 检测信号

| 信号类型 | 触发条件 | 示例 |
|:---|:---|:---|
| **形容词堆砌** | 连续 ≥ 3 个形容词/副词修饰同一名词或动词 | "极其华丽赛博的动效" → "赛博风动效" |
| **程度词叠加** | "极其/极度/毫无保留/彻底/死死/绝对" 同一段出现 ≥ 3 次 | "绝对不需要…死死记住…极度苛刻地" |
| **军事/战争隐喻过载** | 同一 `###` 块内 ≥ 3 个战争/末日比喻 | "核爆/万劫不复/深渊/镇压/炮灰/提线木偶" |
| **同义反复** | 前后两个分句用不同修辞说同一件事 | "毫无保留地引入…颠覆性全新…" = 双层强调同义 |

### 2.5.3 处置

检测到以上任一信号时，标记该句/段为 `[RHETORIC_INFLATION]`，执行压缩：
1. **保留信息骨架**：提取该句的核心动词和宾语
2. **删除修饰枝叶**：移除不改变信息量的形容词、程度副词和隐喻
3. **压缩后自验**：压缩版是否丢失了任何**不可还原的信息**？如果没有 → 采用压缩版
