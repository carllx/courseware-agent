# 图式层知识不对称检测 — 详细规范 (Schema-Level Asymmetry)

> **原属**：`rule_prerequisite_awareness.md` §3.4（因规则文件体量限制拆分至此）

## 理论基础

Shulman PCK 的"表征选择"（Representations）维度要求教师选择最能让目标受众具象化理解的类比和隐喻。当类比取材于学生经验之外的领域时，非但不能降低认知负荷，反而会引入额外的"解码成本"。

## 3.4.1 受众经验匹配测试

对脚本中每个**类比/隐喻/生活化举例**，检查其取材领域是否属于目标受众（DMA 数字媒体艺术学生）的高概率经验域：

| 经验域类型 | 示例 | DMA 学生匹配度 |
|:---|:---|:---:|
| **高概率** | 手机交互、社交媒体（微信/抖音/小红书）、游戏、视频剪辑（Premiere/剪映）、设计软件（PS/Figma/Sketch）、摄影、展览、流媒体（B站/Netflix） | ✅ |
| **中概率** | 网购（淘宝/京东）、外卖、地图导航、办公软件（Word/PPT）、公共交通 | ✅ 可用 |
| **低概率** | 煤气灶操作、工厂阀门、数据库建表、企业 ERP/CRM 系统、服务器运维、底层网络协议、传统制造业流程 | ⚠️ 需桥接 |

## 3.4.2 处置策略

- 使用**低概率**经验域的类比 → 标记 `[SCHEMA_MISMATCH]` 🟡
- 处置方式（任选其一）：
  - **A. 替换**：用同等教学效果的高概率经验域类比替换
  - **B. 桥接**：保留原类比但前置一句经验桥（"就像你用 PS 时…"引渡到学生的真实体验）
  - **C. 标注刻意性**：如果使用低概率类比是教学设计的刻意选择（如故意用工程师视角制造"你也不懂吧？这就是用户的感受"的共情效果），在脚本注释中标注 `<!-- DELIBERATE_SCHEMA_CHOICE: 理由 -->`，豁免标记
