# 标杆密度样本 (Benchmark Density Sample)

> **用途**：当课程无已完成脚本时（冷启动场景），Agent 必须将本节片段作为**人文密度基线锚点**，代替前序脚本参考。

以下为一个符合密度标准的模块片段示范（~500 字，含 3 个人文标签 + 1 个 VISUAL 块）：

```markdown
### 3.1 心理模型的本质

> [VISUAL]
> *   **Slide**: 心理模型冰山
> *   **Layout**: `Split`
> *   **Scene**: 冰山图：水面上为"用户看到的界面"，水面下为"用户想象的运作方式"
> *   **Search**: `mental model iceberg diagram UX`

每个人在使用一款产品时，脑中都有一个"它应该怎么工作"的隐形剧本——心理学家 Donald Norman 称之为**心理模型**。

**(Pause: 3s)**

> [STORY TIME: 电梯关门按钮]
> 你有没有注意过，很多电梯的"关门"按钮其实**根本不接线**？
> 早在 1990 年代，美国残障法案就规定电梯门必须保持开启足够久。
> 但制造商保留了那个按钮——因为它给了乘客一种"我能控制"的错觉。
> 这就是心理模型的力量：用户不需要知道真相，他们需要的是**可预测的行为反馈**。

所以，当一个产品的实际行为——Norman 称之为"系统映像"——与用户脑中的剧本对不上，
**(Pause: 2s)**
挫败感就产生了。不是因为产品"坏了"，而是因为它**辜负了用户的期待**。

> [PHILOSOPHY: 现象学的"上手性"]
> 海德格尔在《存在与时间》中提出：当工具完美契合使用者预期时，
> 工具会"隐退"到背景中——你不会意识到锤子的存在，直到它砸到你的手指。
> 这恰恰是心理模型对齐的终极目标：让界面如空气般透明。

> [CASE STUDY: 微信支付 vs 早期网银]
> 2013 年，中国网银转账需要填写 6 个字段、插入 U 盾、输入动态令牌。
> 而微信红包只需要一个手势——"捏"着手机"塞"进群里。
> 微信成功的秘诀不是技术更先进，而是它的系统映像完美匹配了"发红包"这个生活中的心理模型。
```

**密度指标**：512 字讲授文本 / 3 个人文标签（STORY TIME + PHILOSOPHY + CASE STUDY）/ 1 个 VISUAL 块 → 每 ~170 字一个人文锚点，远超 `⌈512÷2000⌉=1` 的底线。
