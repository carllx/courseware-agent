# 多维与多值场可视化工作流 (Multidimensional, Vector & Tensor Fields)

> [!NOTE]
> 本工作流整合了多维传输函数的设计、向量场（流体力学 CFD 等）的四大可视化流派，以及张量场（扩散张量成像等）的标符设计。旨在指导 Agent 或设计者如何将复杂的高维物理与标量空间映射为清晰的可视化表达。

## 1. 前置条件与上下文 (Prerequisites & Context)

在处理具有方向、幅度、甚至矩阵属性的复杂场数据（如风洞流场、大脑扩散张量数据或医疗三维体数据）时，传统的 1D 或单变量映射会丢失边界与结构特征。

**适用场景 (WHEN & WHY)**：
- **多维标量场**：当单一标量值（如组织密度）无法区分不同的材质边界（如空气-组织，组织-骨骼）时，需引入派生属性（如梯度幅值）构建多维传输函数。
- **向量场 (Vector Fields)**：当数据包含每个单元格的方向和幅值（如流体速度、风向）时，需要探索动态或稳态的几何流（流线、迹线）。
- **张量场 (Tensor Fields)**：当数据测量的是方向相关的扩散率、曲率或应力（如 MRI、各向异性扩散）时。

> [!TIP]
> **深入理论查询 (Progressive Disclosure)**

> ```

## 2. 综合指南与最佳实践 (Comprehensive Guide & Best Practices)

### 2.1 多维传输函数设计 (Multidimensional Transfer Functions)

通过派生空间与交互式小组件构建多维传输函数，通常应用于直接体渲染（Direct Volume Rendering）。

1. **计算派生空间**：除了原始标量数据值（作为 X 轴），计算**梯度幅值 (Gradient Magnitude)**（即变化最快的方向与强度，作为 Y 轴）。
2. **构建二维联合直方图 (2D Joint Histogram)**：将视图作为热力图，每个像素格利用灰度色图显示其频数。这种视图能有效暴露不同材质间的“边界”。
3. **分配颜色与不透明度**：在 2D 派生空间中选择区域，将其映射为特定的颜色和不透明度。

### 2.2 向量场可视化：四大核心流派

向量场（如 CFD 模拟数据）关注于流速和方向，主要分为四大家族：

- **A. 局部标符 (Flow Glyphs)**：
  - **方法**：在各个数据单元格放置内部有结构的物体（如箭头）。长度编码幅值，指向编码方向。
  - **局限**：在 3D 场中极易产生遮挡 (Occlusion)。
  - **策略**：仅在 2D 切片上使用，或对数据进行稀疏采样。

- **B. 几何流 (Geometric Flow)**：
  - **方法**：通过数值积分（Integration-based），从稀疏的种子点集合追踪粒子的轨迹。
    - *稳态场 (Steady)*：使用**流线 (Streamlines)**。
    - *非稳态/时变场 (Unsteady)*：使用**迹线 (Pathlines)**、**条纹线 (Streaklines)** 和 **时间线 (Timelines)**。
  - **高级技术（相似性聚类流线）**：提取几何签名（曲率、挠率、曲折度）构建相似性矩阵与聚类层次。通过分配集群颜色与交互式不透明度，保留宏观结构并减少视觉混乱。

![](../../images/508f3d61fd5e113f033bb33f758c32c5c2b2d3c3dc469ea8255be6129cafe430.jpg)
*基于几何特征（曲率、挠率等）进行聚类着色的流线 (Similarity-Clustered Streamlines)*

- **C. 纹理流 (Texture Flow)**：
  - **方法**：密集覆盖整个场，而非稀疏种子点。例如使用线性积分卷积（LIC，Line Integral Convolution）沿粒子流方向涂抹白噪声。
  - **适用性**：最适用于 2D 场或 3D 表面流。

- **D. 特征流 (Feature Flow / Topological Flow)**：
  - **方法**：跨整个向量场进行全局计算，直接检测并提取**临界点 (Critical points)**（如鞍点、汇流点、源点）、涡流和冲击波。
  - **策略**：将提取出的高级特征使用标符或几何体直接编码，降低认知负荷。

### 2.3 张量场可视化 (Tensor Fields)

张量场在每个网格处存储矩阵数据（例如衡量水分子在组织中扩散各向异性的扩散张量成像 MRI）。

- **椭球张量标符 (Ellipsoid Tensor Glyphs)**：
  - **信息分解**：将张量自然分解为形状与方向，利用 3D 椭球体标符编码。
  - **三大基础形状**：
    1. **完全各向同性 (Fully Isotropic)**：完美的球体（水分子均匀无偏向地扩散）。
    2. **部分各向异性 (Partially Anisotropic)**：平面状（沿特定平面扩张）。
    3. **完全各向异性 (Fully Anisotropic)**：长条雪茄/线性状（水分子沿明确路径移动，如神经纤维束）。
  - **过滤与渲染**：通常将各向同性区域的标符过滤隐藏（Filtered out），只保留高各向异性的关键结构。

> [!WARNING]
> 单纯的椭球体标符存在视角歧义问题（不同形状从特定角度看可能形似），要求更高准确性的任务可考虑引入超二次曲面张量标符 (Superquadric tensor glyphs)。

## 3. 故障排除逻辑 (If/Then Troubleshooting Logic)

| 触发条件 (IF) | 故障现象与原因 | 解决策略 (THEN) |
| :--- | :--- | :--- |
| **IF** 传统 1D 颜色映射无法区分不同材质结构 | 标量值发生重叠，缺失材料交界面的结构变化信息。 | **THEN** 添加计算“梯度幅值”作为第二维度属性，构建 2D 联合直方图传输函数，以二维热力图形式呈现以精确锁定边界。 |
| **IF** 3D 向量/张量场中的标符互相遮挡严重 | 数据的网格采样密度过高，导致内部视角被外部标符全盘遮挡。 | **THEN** 采用交互式切面（Cutting planes）、设置透明度层级，或过滤掉低重要性区域（例如隐藏张量场的各向同性球形）。 |
| **IF** 几何流线 (Streamlines) 产生严重的视觉杂乱 | 种子点 (Seed points) 的放置与采样策略不当，或是流线数量失控。 | **THEN** 切换到相似性聚类算法（提取曲率/挠率等签名构建相似性矩阵），让用户通过聚类颜色和交互调整簇群不透明度进行高亮聚焦。 |
| **IF** 在高频时变流动 (Unsteady flows) 中跟踪结构失败 | 使用了仅适用于稳态场的流线（Streamlines）进行渲染。 | **THEN** 必须改用迹线（Pathlines）、条纹线（Streaklines）或时间线（Timelines）机制，才能真实反映粒子随时间演化的拓扑轨迹。 |

## 4. 验证清单 (Verification Checklists)

- [ ] **维度推导验证**：是否针对三维体数据计算了合理的衍生属性（如梯度），并验证了它们能否在 2D 传输函数中区分边界？
- [ ] **语义映射对齐**：使用张量标符时，球形、平面形、线性等视觉映射是否准确反映了流体的物理扩散率（各向同性 / 各向异性）？
- [ ] **遮挡控制机制**：处理三维场域数据时，是否已强制应用了数据过滤（过滤次要区域）、切片检查或不透明度分层，以保障视觉上的可读性？
- [ ] **种子策略优化**：生成几何流（流线等）时，种子点分发策略是否具备防遮挡约束（Sparse seeding）且兼顾了结构捕捉？
- [ ] **理论知识就绪**：若需进一步了解数据衍生与底层特征积分机制，是否已经执行了 `query_theory.sh` 并掌握了所需物理数学规则？
