# 工作流：忽略字重少于五种的字体 (Ignore Typefaces With Less Than Five Weights)

## Prerequisites & Context (前提与背景)
- **WHY (为什么需要此工作流)**：构建层次分明的 UI 时，字重（Font Weight）是区分信息主次的最强大工具（呼应“Hierarchy is Everything”）。如果一种字体家族只提供两三种字重（如只包含 Regular, Bold），它将无法支撑复杂的界面需求，导致设计师被迫使用破坏一致性的其他字体或妥协排版。
- **WHEN (何时使用)**：在项目初期进行字体选择或制定 UI 规范的探索阶段。

## Comprehensive Guide & Best Practices (全面指南与最佳实践)
1. **为什么需要至少五种字重**
   - 在复杂的 UI 中，你通常需要：
     - **Regular (400)**：用于绝大多数标准正文。
     - **Medium (500)**：用于按钮标签、激活状态的导航项或略微突出的正文。
     - **Semi-bold (600)**：用于次级标题或卡片标题。
     - **Bold (700)**：用于主标题或极端强调。
     - **Light (300) / Extra Bold (800+)**：用于巨大的数字展示（如仪表盘指标）或超大排版标语。
2. **筛选字体库的第一法则**
   - 当在 Google Fonts 或其他字体库浏览时，直接过滤掉所有变体稀少的字体家族。
   - 即使某个字体看起来很美，如果它没有足够的字重，就绝对不适合作为 Web/App 界面的主字体。
3. **字重提供了不改变字号的排版层次**
   - 丰富的字重系列允许你在完全相同的 `font-size` 下，拉开巨大的视觉层级差异，这是保持界面紧凑和整洁的核心技巧。

## If/Then Troubleshooting Logic (故障排除逻辑)
- **IF** 你在使用一款精美的字体，但发现为了突出标题，只能不断放大字号导致布局失衡：
  - **THEN** 这说明当前字体的字重不足。你需要更换为具有更广字重光谱的超级字体家族（Superfamily），利用字重而不是字号来建立层级。
- **IF** 界面中的按钮文本和普通段落文本缺乏区分度，但你不想改变它们的颜色：
  - **THEN** 利用 Medium (500) 或 Semi-bold (600) 字重赋予按钮文本稍微更强的存在感。

## Verification Checklists (验证清单)
- [ ] 选定作为主要 UI 排版的字体，是否至少拥有从 300(Light) 到 700(Bold) 之间的 5 个以上的平滑字重阶梯？
- [ ] 设计系统是否充分利用了如 Medium 和 Semi-bold 这样细微的中间字重来处理按钮、表头等中间层级的强调需求？
- [ ] 是否坚决摒弃了那些只有 Regular 和 Bold 的字体用于核心组件的排版？
