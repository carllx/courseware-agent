# 启发式工作流：行高与字号的反比例法则 (Line Height Inversely Proportional to Font Size)

## 1. 前置条件与上下文 (Prerequisites & Context)
- **应用场景 (WHEN)**: 设置标题排版系统（H1 到 H6）或需要展示超大字号文本（如 Hero Section 标语）时。
- **理论依据 (WHY)**: 行高通常以相对值（如 1.5 倍）定义。然而，空白空间的绝对面积会随着字号的增加呈平方级放大。如果为 48px 的大标题使用与 16px 正文相同的 1.5 倍行高，标题行与行之间的物理距离会变得极其巨大（24px的间隙），这不仅打破了标题的视觉内聚力，还使其看起来脱节、松散，无法发挥标题统领下文的作用。

## 2. 综合指南与最佳实践 (Comprehensive Guide & Best Practices)
- **反比例调整法则**
  - 字号越大，所需的相对行高乘数越小。
  - **正文字号 (14px-18px)**：通常需要 `1.5` 到 `1.7` 的行高以保证可读性。
  - **中等标题 (20px-24px)**：行高应降至 `1.3` 到 `1.4` 左右。
  - **大号标题 (30px-48px+)**：行高必须大幅压缩到 `1.1` 甚至 `1.0`（甚至在极少数巨大字体中可以出现略低于1的值，如 `0.95`）。
- **维持标题的“块”感**
  - 标题的首要功能是作为一个整体抓住读者的注意力。紧凑的行高能让多行标题在视觉上紧紧咬合在一起，形成一个不可分割的视觉重锤。
- **考虑下降部（Descenders）**
  - 在压缩极大字体的行高时，要注意字母的下降部（如 g, p, y）与下一行的升部（如 h, l, t）是否发生物理重叠。适当微调行高以避免碰撞，但不要为了避免碰撞而过度放大行距。

## 3. 如果/那么 故障排除逻辑 (If/Then Troubleshooting Logic)
- **IF** 你的两行 H1 标题看起来像是两个完全独立的短句，或者页面顶部显得极其空旷，**THEN** 标题的行高太大。将 H1 的行高重置为 1.1 并观察改善效果。
- **IF** 压缩行高后，某些带有复杂变音符号（如 é, å）或长下降部的语言发生了文字截断或重叠，**THEN** 在紧凑的原则下，谨慎调高行高（例如从 1.1 加到 1.2），或者增加一些 `letter-spacing` 以给字母留出呼吸空间。
- **IF** 在设计系统中通过 `rem` 或相对单位继承了根节点的 `line-height: 1.5`，**THEN** 必须在每个层级的 Heading 样式中明确覆盖该属性，重置为合适的倒数比例值。

## 4. 验证检查单 (Verification Checklists)
- [ ] 检查从 H1 到 H6 的排版比例，是否随着字体变小，行高乘数逐步递增？
- [ ] 在响应式断点处，当 H1 的字号发生改变时，其对应的行高是否保持在紧凑的范围内（1.1-1.2）？
- [ ] 页面上的多行大字号标语是否视觉上凝聚成一个有力的信息块？
- [ ] 确保没有对大标题使用全局的默认行高设置。
