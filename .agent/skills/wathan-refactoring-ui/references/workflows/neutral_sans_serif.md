# 工作流：选择中性无衬线字体 (Neutral Sans Serif)

## Prerequisites & Context (前提与背景)
- **WHY (为什么需要此工作流)**：在大多数用户界面（UI）（如应用仪表盘、系统工具、SaaS 平台）中，文字需要充当“隐形”的容器，传递信息而不喧宾夺主。具有强烈个性的字体会干扰界面的专业性并影响阅读效率。
- **WHEN (何时使用)**：为任何非纯展示性（如品牌官网、杂志式排版）的数字产品选择基础主字体时。

## Comprehensive Guide & Best Practices (全面指南与最佳实践)
1. **优先考虑中性无衬线字体 (Neutral Sans Serif)**
   - 这类字体的特点：低对比度（笔画粗细均匀）、较大的 x-height（提高小字号可读性）、清晰的字元辨识度。
   - 优秀的例子：Inter, Roboto, San Francisco, Helvetica Neue, Segoe UI。
2. **为何中性最安全**
   - 中性字体能够完美融入各种设计风格。无论你的界面是深色模式、明亮的高端感、还是紧凑的数据平台，中性无衬线字体都不会显得突兀。
   - 它们把舞台留给颜色、布局和实际内容，使得界面更加经得起时间的考验。
3. **避免个性过强的字体作为正文**
   - 带有怪异尾缀、极高对比度（如 Didot）、或者过于几何化（如 Futura，在小字号下难以阅读）的字体，应当仅限于标志或极其巨大的标题中使用。

## If/Then Troubleshooting Logic (故障排除逻辑)
- **IF** 界面看起来过于“有趣”或“不专业”，且数据表格难以快速扫描：
  - **THEN** 检查是否在基础 UI 中使用了带有强烈个性的几何无衬线体或衬线体。立即替换为标准的中性无衬线体（如 Inter）。
- **IF** 需要在品牌风格和实用性之间取得平衡：
  - **THEN** 在主标题或营销页面使用品牌个性字体，而在应用内部的核心 UI 元素（表单、按钮、表格）强制采用中性无衬线字体。

## Verification Checklists (验证清单)
- [ ] 应用的核心 UI 正文字体是否选择了低调、清晰的中性无衬线字体？
- [ ] 在小字号和密集信息展示场景下，该字体的可读性是否经过验证？
- [ ] 是否克制了在基础界面排版中使用过度装饰性字体的冲动？
