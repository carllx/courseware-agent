# 边界色阶构建工作流 (Edges Of Scale)

## Prerequisites & Context (前提与背景)
- **WHY (为什么要先确定边界)**: 在建立一个包含 9 到 10 个层级的色阶系统时，从中间的基准色随意向两端盲目探索是困难且容易迷失的。通过优先钉死“两端的极限”（最亮和最暗的颜色），相当于为你的整个色系确立了“安全边界”和参照坐标。
- **WHEN (什么时候使用)**: 在确立了基准色（Base Color，如 500），准备扩充完整色系阶梯的第一步时。

## Comprehensive Guide & Best Practices (综合指南与最佳实践)
1. **定义极深边界 (Darkest Edge - 900 级)**:
   - 目标：这个颜色需要足够深，以便在极浅或白色的背景上作为**正文或标题文本**使用，同时仍保留该色系的微量特征。
   - 启发式方法：如果它是蓝色的极深边界（Blue-900），它看起来应该像是一滴蓝墨水滴在了一整瓶黑墨水中——它必须提供强烈的对比度，不能显得刺眼。
2. **定义极浅边界 (Lightest Edge - 50/100 级)**:
   - 目标：这个颜色需要足够浅，以便能够作为**背景色**大面积铺设，而在其上能够清晰地展示常规深色文本。
   - 启发式方法：它应该是一种“微弱的暗示”。如果这是一个红色系统，红色的极浅边界看起来应该像是一张白纸上被涂抹了极淡的粉色。
3. **锚定坐标系的价值**:
   - 一旦定义了基准色（500）以及两个极端边界（900 和 100），中间层级的颜色就只是在这三个坐标点之间“插值”的过程，这样能避免最终色彩偏离预期轨道。

## If/Then Troubleshooting Logic (故障排除逻辑)
- **IF** 极深边界（900级）的颜色在屏幕上看起来像是纯黑色：
  - **THEN** 过于暗了。稍微提高一点亮度，或者增加一点饱和度，以确保在它被作为文本使用时，仍然带有一点品牌色的温度或冷度。
- **IF** 极浅边界（100级）在白色背景上几乎看不出来（或在某些显示器上完全消失）：
  - **THEN** 在不牺牲对比度的前提下，稍微增加一点点的饱和度或稍微降低亮度，直到你能在它和纯白之间画出清晰的视觉界限。
- **IF** 两端边界和基准色看起来像属于完全不同的颜色：
  - **THEN** 极端的暗和极端的光容易冲淡色相的感知。在调整亮度的同时，需要遵循“感知亮度偏移（Hue Rotation）”法则，通过微调色相（Hue）来维持视觉上的血统纯正。

## Verification Checklists (验证清单)
- [ ] 色阶系统中最暗的颜色（900级）是否通过了作为背景文本的高对比度测试？
- [ ] 色阶系统中最亮的颜色（100级）是否足够淡，可用作大面积背景而不会让眼睛疲劳？
- [ ] 极深和极浅的边界色彩是否仍然保留了该色系的基础基因（未完全变成纯黑或纯白）？
- [ ] 这两个边界的设定是否为后续填充中间色阶提供了明确的物理极限限制？
