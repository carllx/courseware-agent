# 个人高效备课与极速脱稿工作流 (Visual Unpacking Prep)

本技能为您量身定制的长期备课数字助手，专为解决“时间紧、难脱稿”问题而生。它将帮助您打通“提取教材 → 结构化大纲/教案 → 极简提示PPT → 心流排练”的闭环。

## 核心教条：材料的非必要性与抛弃原则

执行本技能前，Agent 和讲师都必须牢记以下材料的角色：
- 教学大纲 (Syllabus) & 进度表 (Schedule)：备课阶段的**顶层必须品**，用来做内容减法。**绝不带入课堂**。
- 教案 (Lesson Plan)：**微观必须品**（BOPPPS 骨架），用于掌握节奏。**绝不带入课堂**。
- 逐字稿 (Script)：**有害的中间废弃物**。它是用来盘顺逻辑的，一旦逻辑通畅，立刻销毁或打入冷宫（移到 PPT 备注），禁止拿到讲台上背诵，否则摧毁心流。
- PPT：**极简的视觉锚点，但不排斥图文结合**。绝对禁止大段啰嗦文字（Redundancy Principle），但必须包含支持案例的视觉图片（图）和核心提示词（文）。页数的多少不取决于时间（如每2分钟1页是不科学的），而取决于“案例切换”与“视觉证据”的真实展示节奏。

## 标准执行流 (4 步)

当用户输入源教材内容并呼叫本技能时，Agent 必须严格执行以下工作流：

### 1. 逆向提取 (Backward Design)
1. 询问用户本节课的 1-3 个核心 OBE 教学目标。
2. 根据目标，大刀阔斧地从原教材中剥离冗余信息。
3. 提取出核心的“知识块 (What/Why/How)”。

### 2. BOPPPS 教案切片
将提取的知识块，套入预设的 BOPPPS 模板，生成 15-45 分钟的微型教案骨架。
> 详情见模板：[BOPPPS 模板](references/templates.md)

### 3. 口语化逐字稿（核心前置产物）
1. 将教案翻译为逻辑通畅、具有高代入感的**实战逐字稿**。这是确保案例细节不丢失的托底文件。
2. 必须先向用户输出这份逐字稿进行确认。

### 4. 视觉“降维压缩”与 PPT 脚本
1. 逐字稿确认后，进行降维压缩。
2. **核心动作**：放弃机械的时间切片。根据“案例展示”的天然节奏，从逐字稿中提炼出“视觉图片（如案例图）+ 核心提示词”。
3. 产出适用于 Gamma 或 Marp 的极简 Markdown 脚本，并将完整的逐字稿折叠进备注中。

### 5. 心流排练指引
指导用户如何看着极简 PPT，使用“费曼技巧”进行知识解压。强调“找出卡壳的特定 30 秒重复练习”和“锁死前 3 分钟肌肉记忆”。

## 动态自我更新协议 (Self-Evolution Protocol)

本技能被设计为“长期演进”型资产。当用户反馈：
*   *“这个视觉词太抽象，我没想起来”*
*   *“导入环节时间不够，总是拖堂”*
*   *“我想加入一种新的排练技巧”*

**系统指令**：Agent 须即时总结经验，并自动提出修改当前 `SKILL.md` 或 `references/templates.md` 的计划，使得您的备课助手越来越懂您。
