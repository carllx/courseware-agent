# 超星学习通 — 智能导入格式规范

> 本文档为超星学习通平台"智能导入"功能的完整格式规范。
> 来源：超星学习通官方帮助文档。由 Agent 按需加载。

## 一、录入说明

### 1.1 基本规则

1. **题号**：需要有题号，用数字表示：`1. 2. 3.`
2. **题型标注**：
   - 若未标注题型，系统根据内容结构自动识别为：单选题、多选题、填空题、判断题、简答题
   - 组合题型（阅读理解/完形填空/共用选项题）须用 `{{` `}}` 括起
   - 其他题型用 `【题型名称】` 标注（如 `【名词解释】`、`【计算题】`、`【论述题】`），否则默认识别为简答题
3. **答案**：题干或选项下方另起一行，用 `答案：` 或 `参考答案：` 标出
4. **难度**（非必填）：`难度：难/中/易`
5. **知识点**（非必填）：`知识点：知识点1；知识点2`（分号分隔多个）
6. **课程目标**（非必填）：`课程目标：能力目标（10分）；创新目标（10分）`
7. **答案解析**（非必填）：`答案解析：` 或 `解析：`，须在答案之后另起一行
8. **分值**（非必填）：题干后用 `（5分）` 格式标出
9. **内容格式**：支持文本、图片（JPG/PNG/GIF）、公式（不支持域代码公式）

### 1.2 各题型格式详解

#### 单选题 / 多选题

- 选项内容不可重复，选项间不可有空行
- 答案可用 `（）` 标明：`题干（A）` 或 `题干（ABD）`
- 多选答案需 ≥ 2 个字母
- 支持横向选项：`A.xxx B.xxx C.xxx`（空格分隔）
- 支持选项格式：`A.` / `A、` / `A，`

```
1.【单选题】关于《花间集》说法错误的是（ ）
A.作者是赵崇佐
B.收录当时流行歌曲歌词
C.针砭时弊
D.内容是美女与爱情
答案：C
答案解析：花间集的答案解析
知识点：知识点1；知识点2
```

#### 判断题

- 答案支持：`对/错`、`正确/错误`、`T/F`、`True/False`
- 答案可用 `（）` 标明：`题干。（对）`

```
4.【判断题】多音节是中国语言文化的特性。
答案：对
```

#### 填空题

- 题干中作答处用**下划线** `__` 标明
- 多个空的答案用**分号** `；` 隔开

```
3.【填空题】中国诗经的写作方式不包括__、___、____。
答案：赋；比；兴
```

#### 简答题 / 名词解释 / 论述题

- 用 `【题型名称】` 标注
- 未标注则默认为简答题

```
5.【名词解释】请解释塞曼效应
答案: 正常塞曼效应是指……
```

#### 阅读理解 / 组合题（大题套小题）

- 前后用 `{{` `}}` 括起
- `{{` 前要加题号
- 大题和小题题干都需标题号
- 小题答案可跟在题干后，用空格隔开

```
8. {{【阅读理解】People often say that...
知识点：大题知识点
1.What will James do tomorrow? B
A. Watch a TV program.
B. Give a talk.
C. Write a report.
知识点：小题知识点
2.What can we say about the woman? C
A. She's generous.
B. She's curious.
C. She's helpful.}}
```

#### 完形填空

- 与阅读理解类似，用 `{{` `}}` 括起
- 选项横排：`A.选项1 B.选项2 C.选项3 D.选项4 答案：A`

```
9.{{【完形填空】Directions: For each blank...
1. A.选项1 B.选项2 C.选项3 D.选项4 答案：A
知识点：小题知识点
2. A.选项1 B.选项2 C.选项3 D.选项4 答案：A}}
```

#### 共用选项题

- 用 `{{` `}}` 括起
- 共用选项在前，小题题干在后
- 选项和小题间不空行

```
10.{{【共用选项题】共用选项题说明...
A.商品名
B.通用名
C.化学名
D.别名
E.药品代码
1.国际非专利药品名是（）
答案：B
2.只有名称拥有者才能使用的药品名是（）
答案：A}}
```

## 二、常见问题与限制

| 问题 | 说明 |
|---|---|
| 单次导入上限 | 1000 题 |
| 表格 | **不支持**导入表格 |
| 图片格式 | JPG/PNG/GIF，支持 base64 |
| 公式 | 不支持源代码公式，建议用 Word 公式编辑器或图片 |
| 代码块 | 智能导入**不支持**代码块（需手动创建） |
| 重复检测 | 与题库已有题目重复时自动过滤 |
| 识别失败 | 确认题干用 `【题型名称】` 标注，正确换行分行，两题间加空行 |

## 三、Agent 生成注意事项

1. **换行严格性**：题干、选项、答案、解析各占独立行，不可合并
2. **空行策略**：题与题之间空一行提升识别率，同一题内选项间**不空行**
3. **编码**：UTF-8 无 BOM
4. **答案行**：`答案：` 与答案内容之间不加换行
5. **多选答案**：使用中文逗号 `，` 或英文逗号 `,` 分隔均可，推荐中文逗号
6. **填空下划线**：至少 2 个连续下划线 `__`
