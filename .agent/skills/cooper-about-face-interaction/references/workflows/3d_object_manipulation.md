# 工作流：3D 对象操作 (3D Object Manipulation)

## 1. 前置条件与上下文 (Prerequisites & Context)
**为何需要 (WHY)**: 
在涉及三维空间的产品（如 CAD 软件、医学成像、游戏引擎及 3D 建模工具）中，传统的 2D 鼠标或触控输入设备在控制 3D 对象时天然存在维度错配（以 2D 控制 3D）。如果不加设计，用户会产生极强的认知负荷和空间迷失感。
**何时使用 (WHEN)**:
当界面需要用户进行旋转、缩放、平移（操作摄像机或对象自身）或对三维物体进行局部编辑时使用。

## 2. 综合指南与最佳实践 (Comprehensive Guide & Best Practices)
- **解耦操作维度**：不要试图让用户一次性控制三个旋转轴。提供单独的约束轴控制（例如 X、Y、Z 轴的控制手柄），将复杂的 3D 操作拆解为一系列的一维或二维操作。
- **提供空间参考线 (Spatial Cues)**：
  - **包围盒 (Bounding Boxes)**：当选中对象时，显示带有控制点（Control points）的包围盒。
  - **地平面投影 (Drop Shadows/Ground Planes)**：通过阴影来提供物体在三维空间中的深度感知。
  - **网格线 (Grid)**：帮助用户理解透视关系和绝对尺寸。
- **对象中心 VS 相机中心**：
  - 允许用户明确选择是“移动对象”还是“移动相机（视角）”。
  - 缩放时，默认以光标悬停点或当前选中物体的中心为缩放锚点，而非屏幕中心。
- **直接操作与参数面板结合**：提供视觉上的直接拖拽（如 Gizmo 控件），同时在属性面板提供精确的数值输入框，以满足不同精度的需求。
- **利用手势和习惯**：在触屏上，应用符合物理直觉的平移（单指拖拽）、缩放（双指捏合）和旋转（双指旋转或特定区域拖拽）手势。

## 3. If/Then 故障排除逻辑 (If/Then Troubleshooting Logic)
- **If** 用户在旋转对象时迷失了原本的正面方向，**Then** 提供一个一键“重置视角 (Reset View)”或正交视图（Top/Front/Right）的快速切换按钮。
- **If** 场景中有多个互相遮挡的 3D 对象导致无法精准选中目标，**Then** 启用“透视选中 (X-ray selection)”或提供层级大纲视图（Outliner），允许按列表选择。
- **If** 用户拖拽控制柄时容易误触其他轴，**Then** 增加鼠标悬停时该轴的高亮反馈，并在拖拽开始后锁定其他轴的交互响应。

## 4. 验证检查表 (Verification Checklists)
- [ ] 是否在 3D 场景中提供了明确的坐标系指示器（如左下角的 XYZ 轴标）？
- [ ] 对象的平移、旋转、缩放是否拥有独立的视觉控件（Gizmo）？
- [ ] 是否提供了在透视视图 (Perspective) 与正交视图 (Orthographic) 之间切换的功能？
- [ ] 数值输入框是否支持微调（如鼠标拖拽数值框可以无缝增减数值）？
- [ ] 是否确保了所有 3D 交互的帧率至少达到 60fps，以避免眩晕和操作滞后？
