# （七） 漏斗图

漏斗图一般是以单个研究的效应量为横坐标 样本含量为纵坐标的散点图 在平面坐标系中的集合为一个倒置的漏斗形 因此称为漏斗图 样本量小 研究精度低 分布在漏斗图的底部， 向周围分散； 样本量大， 研究精度高， 分布在漏斗图的顶部， 向中间集中。 实际使用时 做数据分析的研究个数较少时不宜做漏斗图 一般推荐数据分析的研究个数在 个及以上才做漏斗图 图
