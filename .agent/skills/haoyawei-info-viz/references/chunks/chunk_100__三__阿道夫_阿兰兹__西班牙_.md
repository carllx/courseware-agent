# （三） 阿道夫·阿兰兹 （西班牙）

阿道夫·阿兰兹 （Adolfo Arranz） 是世界上最被推崇的信息可视化设计师之一。 他先加入了西班牙报纸 世界 后来又成为新加坡传媒公司的创意总监 入行这些年来 他几乎荣获了国际的主要奖项 目前他负责管理中国香港一家报纸的咨询图像部 阿道夫 阿兰兹认为大部分的设计项目都是个有趣的挑战 能让你学习新知识 因为咨询图像的好坏取决于前期信息资料的搜集和研究的丰富性 这背后是一个持续不断学习的过程
