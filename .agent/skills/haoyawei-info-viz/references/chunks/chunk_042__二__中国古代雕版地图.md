# （二） 中国古代雕版地图

我国目前发现的最早的雕版印刷实物地图， 是南宋或唐代出版的 《九州山川实证总图》图 九州代表冀 兖 青 徐 杨 豫 荆 雍 梁 大区域 加上山川 河流

湖泊和海洋信息， 构成一张较为完整的地图。

图2 －8 中国最早雕版地图 《九州山川实证总图》 （局部）

考古学家还发现宋朝的 《古今华夷区域总要图》 （图2 －9）， 据考证是公元1185 年前后制作的地图 该地图较全面地绘制了宋代全国 路及州郡分布情况 其中还包括海岸线和岛屿等信息。
