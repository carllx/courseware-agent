# （五） 地图

地图是按照一定的法则 使用制图方法 通过制图有选择地以二维或多维形式与手段在平面或球面上表示地球 或其他天体 上各种事物的空间分布 联系及时间的发展变化状态的图形或图像 它具有严格的数学基础 符号系统 文字注记 并能用地图概括原则 科学地反映出自然和社会经济现象的分布特征及其相互关系 古代地图一般画在羊皮纸或石板上 传统地图的载体多为纸张 随着科技的发展出现了电子地图等多种载体
