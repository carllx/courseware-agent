# 设计者： 米希尔

蒙古国留学生米希尔为故乡蒙古国乌兰巴托市小圈路地区绘制了区域地图 蒙古乌兰巴托城市的中心从上空看起来像蒙古包的形态 小圈路地区是城市的文化艺术中心 是文艺演出的主要场所 学生尝试运用达达主义等拼贴的艺术风格进行作品的最后视觉呈现 区域地图中的图标采用艺术的拼贴形象代表， 整个作品体现出小圈路地区的艺术风格特征 （图5 －17 ～图 5 － 21）。
