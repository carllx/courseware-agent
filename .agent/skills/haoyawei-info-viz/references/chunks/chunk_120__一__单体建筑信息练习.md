# （一） 单体建筑信息练习

本练习从简单直观的信息开始， 选取学校区域内的一个单体建筑， 要求学生亲自调研，研究建筑内外部具体位置的信息与功能信息， 加以结构清晰化的视觉表达。 案例选取学校一栋高层教学楼， 学生设计分为一般性分层图表表达 （图5 －4、 图5 －5） 和用楼层错层插图图表表达 （图5 －6、 图5 －7）， 分别用色彩、 插图和符号等表示具体楼层区域功能和设备的配置情况。
