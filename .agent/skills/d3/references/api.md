# D3 API Index

本文件为 D3 技能包的核心 API 路由表。已根据官方 [d3js.org/api](https://d3js.org/api) 结构进行了 1:1 映射，旨在帮助 Agent 渐进式检索正确的底层代码与方法。

## Visualization (可视化)
- [d3-axis](d3-axis.md): 坐标轴
- [d3-chord](d3-chord.md): 弦图与 Ribbons
- [d3-color](d3-color.md): 颜色空间处理
- [d3-contour](d3-contour.md): 等值线图
- [d3-delaunay](d3-delaunay.md): Delaunay 三角剖分与 Voronoi 图
- [d3-force](d3-force.md): 力导向图模拟
- [d3-geo](d3-geo.md): 地理投影与数学计算
- [d3-hierarchy](d3-hierarchy.md): 层级数据布局 (如树图、打包图)
- [d3-interpolate](d3-interpolate.md): 数值、颜色与复杂对象插值
- [d3-path](d3-path.md): Canvas 路径序列化
- [d3-polygon](d3-polygon.md): 二维多边形几何操作
- [d3-quadtree](d3-quadtree.md): 二维空间四叉树分割
- [d3-scale](d3-scale.md): 比例尺映射
- [d3-scale-chromatic](d3-scale-chromatic.md): 官方色彩方案
- [d3-selection](d3-selection.md): DOM 元素选择与数据绑定 (Data Join)
- [d3-shape](d3-shape.md): 图形基元生成器 (线、面积、饼图等)

## Animation (动画)
- [d3-ease](d3-ease.md): 缓动曲线函数
- [d3-timer](d3-timer.md): 动画循环定时器
- [d3-transition](d3-transition.md): DOM 元素的动画过渡

## Interaction (交互)
- [d3-brush](d3-brush.md): 一维或二维的区域框选
- [d3-dispatch](d3-dispatch.md): 自定义事件与回调调度
- [d3-drag](d3-drag.md): 拖拽行为支持
- [d3-zoom](d3-zoom.md): 缩放与平移行为支持

## Data (数据)
- [d3-array](d3-array.md): 高级数组操作、统计与分组计算
- [d3-dsv](d3-dsv.md): CSV / TSV 数据解析与格式化
- [d3-fetch](d3-fetch.md): 便捷的网络请求 (Fetch API) 封装
- [d3-format](d3-format.md): 数字格式化
- [d3-random](d3-random.md): 多种分布概率的随机数生成
- [d3-time](d3-time.md): 时间刻度与算术运算
- [d3-time-format](d3-time-format.md): 时间日期的解析与格式化
