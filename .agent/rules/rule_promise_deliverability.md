# 规则：前向承诺可交付性 (Promise Deliverability)

> **核心原则**：导览模块是课程的"销售合同"——你在这里承诺的每一项能力目标，后续教学必须有能力兑现。画饼不是激励，是信用破产。

## TL;DR

脚本中每个"你们将学会/将掌握"等承诺性描述，必须通过 T(工具)/D(数据)/S(范围) 三要素中至少两项验证。禁止将需要 NLP、爬虫、专业授权等课程未教技能才能获取的数据源，作为学生将操作的对象。审计时标记不达标承诺为 `[OVERPROMISE]`。

---

## §1 承诺性动词识别

以下动词模式出现在描述后续教学单元时，触发可交付性验证：

| 动词模式 | 示例 |
|:---|:---|
| "你们将学会/将掌握/会学习" | "你们将学会如何利用 D3 的物理引擎来模拟…" |
| "我们要教你/带你" | "我们要教你怎么用自然语言驾驭 AI…" |
| "你将能够/你会具备" | "你将能够独立完成从数据清洗到前端部署的全链路…" |
| "课程结束后你可以" | "课程结束后你可以把社会情绪转化为动态可视化…" |

---

## §2 前向承诺三要素验证 (TDS Check)

每个被识别的承诺必须通过以下三要素中的**至少两项**：

| 要素 | 定义 | 检查方式 | 不合格示例 |
|:---|:---|:---|:---|
| **T (Tool)** | 课程大纲是否教授实现该能力所需的工具/库/方法 | 在 `course.yaml` 对应周次的 `steps` 中能找到相关工具教学 | 承诺"用 D3 做力导向图"但大纲中无 d3-force 教学环节 |
| **D (Data)** | 学生是否有能力获取实现该能力所需的数据源 | 数据源在大纲中有明确教学路径，或属于公开可下载数据集 | 承诺"可视化集体社会情绪"但课程未教 NLP/情感分析 |
| **S (Scope)** | 该能力的描述粒度是否在课程学时内可验证 | 能在期末作品或课堂实验中被具体评判 | 承诺"掌握全链路数据工程"但课程仅 8 周且无后端教学 |

**判定**：
- T + D + S 至少满足两项 → 合格
- 仅满足一项或零项 → 标记为 `[OVERPROMISE]`，必须降级为更具体、可交付的表述

**对照示例**：

```
❌ "你们将学会把某种集体的社会情绪变成一幅极具张力的动态数字生命体"
   → T: ✅ (D3 d3-force 在 W05 教学)
   → D: ❌ (社会情绪需 NLP 量化，课程未教)
   → S: ❌ ("数字生命体"无法在作业中被具体评判)
   → 1/3 → 不合格 → [OVERPROMISE]

✅ "你们将学会指挥 D3 的力导向引擎，把角色关系或资金流向转化为动态关联网络"
   → T: ✅ (D3 d3-force 在 W05 教学)
   → D: ✅ (角色关系可从公开数据集获取，如 GOT API)
   → S: ✅ ("动态关联网络"可在期末作品中具体评判)
   → 3/3 → 合格
```

## §3 不可控数据源红线

禁止在承诺性段落中将以下类型的数据源描述为学生将直接操作的对象，除非 `course.yaml` 中有明确的数据获取教学环节：

| 数据类型 | 示例 | 不可控原因 |
|:---|:---|:---|
| 需 NLP/情感分析的主观数据 | "社会情绪"、"舆论倾向"、"用户满意度情感" | 量化需要课程未教的 NLP 技术栈 |
| 需爬虫/API 的实时数据 | "微博热搜"、"股票实时行情"、"外卖平台评分" | 获取需要课程未教的爬虫/API 技能 |
| 需专业授权的受限数据 | "医疗诊断记录"、"金融征信数据"、"司法判决书" | 学生无权限获取 |

**豁免**：如果教师已预先准备好清洗后的示例数据集并放置在课程资源中，可豁免 D 要素检查。

## §4 写作阶段自检

在 `/write` Phase 2 撰写导览/概述模块时，对每个前向承诺追加以下自检：

> _"这个承诺，我能在期末作品评审时对着学生说'你们完全有能力做到这个'，并且学生不需要任何课外自学就能实现吗？"_

如果答案为否，该承诺必须降级——从"你们将掌握 X"改为"你们将理解 X 的原理"或直接替换为课程可交付的具体能力。

---

## §5 审计检查项

`/audit` Standard 级别中，新增以下检查：

> **A-PROMISE (前向承诺可交付性)**：
> 扫描导览模块中的承诺性动词（§1），逐条验证 TDS 三要素（§2）。
> - 不满足者标记为 `[OVERPROMISE]`
> - 判定：🟡 中等严重度（单个模块 ≥ 2 处升级为 🔴 高严重度）
