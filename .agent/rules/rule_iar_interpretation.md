# 规则：IAR 输出解读协议 (IAR Interpretation Protocol)

> **核心原则**：IAR 自动化脚本（`generate_cheat_sheet.py --diagnose`）是 **L1 快检层**——它只能检测格式信号和口癖词汇，不具备语义仲裁能力。Agent 在审计报告中**禁止将 IAR/wIAR 满分直接等价于"该模块无冗余"**。

## TL;DR

L1 脚本输出 IAR/wIAR → Agent 必须执行 L2 语义仲裁（一句话压缩测试 + 跨段语义去重）→ 最终报告中标注 `[L1-OVERRIDE]` 修正项 → 与 `rule_cognitive_efficiency.md` DD 豁免联动。

---

## §1 L1 层的能力边界声明

`classify_paragraph()` v2 使用以下纯规则手段进行 A/S/R 分类：

| 检测手段 | 能检测 | 不能检测 |
|:---|:---|:---|
| 冗余信号词（段首 30 字） | 显式的"总之/换句话说"等套话 | 不含信号词的隐性重述 |
| 推进信号正则（年份/人名/数据/加粗） | 格式规范的新概念引入 | 未加粗的纯中文新概念 |
| 跨段落字符重叠（≥70%） | 高度相似的相邻段落 | 换词但语义等价的排比膨胀 |
| 加权 wIAR（连续 S 降权） | 结构性原地踏步 | 单个 S 段内部的空洞叙述 |

**L1 的四个已知盲区**（Agent 必须在 L2 中覆盖）：

1. **排比膨胀盲区**：三个平行排比句论述同一观点，因用词不同不触发字符重叠阈值
2. **华丽废话盲区**：不含信号词的长篇抒情，因无冗余词被默认归为 S
3. **格式依赖盲区**：作者忘记加粗的核心新概念被降级为 S
4. **引语残余盲区**：冗余信号词出现在段首 30 字的引语中仍可能误杀

## §2 L2 语义仲裁协议

Agent 在 `/audit` 的 Phase 2/3 中，必须对 L1 输出中的**所有 S 段**执行以下两项检查：

### 2.1 一句话压缩测试

对每个 S 段执行压缩：将其核心论点压缩为 ≤ 25 字的一句话。

- 如果压缩结果与**前一段**的压缩结果语义重叠 > 80% → 升级为 R，标注 `[L1-OVERRIDE: S→R]`
- 如果压缩后发现该段无法提取出任何独立论点（即"空洞段"）→ 升级为 R，标注 `[L1-OVERRIDE: S→R, HOLLOW]`

### 2.2 排比膨胀检测

扫描连续 S 段中是否存在以下 LLM 隐性膨胀模式：

- 三个以上以"我们……"开头的平行句式
- 三个以上以相同句法结构排列的因果链
- 使用不同修辞手法（类比 → 反问 → 感叹）论述同一个已知结论

命中以上模式 → 升级为 R，标注 `[L1-OVERRIDE: S→R, PARALLELISM]`

## §3 与 DD 豁免的联动

任何被 §2 升级为 R 的段落，在最终判定前**必须经过** `rule_cognitive_efficiency.md` §1.4 的可取困难豁免校验：

| 场景 | L2 判定 | DD 豁免结果 | 最终分类 |
|:---|:---|:---|:---|
| S→R（语义重叠） | 冗余 | 通过 DD-3 间隔重现 | `[GERMANE_LOAD]`，保留 |
| S→R（排比膨胀） | 冗余 | 通过 DD-2 交错对比 | `[GERMANE_LOAD]`，保留 |
| S→R（空洞段） | 冗余 | 未通过任何 DD | 确认为 R，建议删除 |

---

## §4 报告输出格式

Agent 在诊断报告中必须包含以下分层输出：

```
### IAR 分层诊断
- L1 自动化：IAR = X.XX | wIAR = X.XX (A:N S:N R:N)
- L2 语义仲裁：S→R 升级 M 段 | DD 豁免 K 段
- 修正后 wIAR = X.XX [L2-ADJUSTED]
```

---

## §5 禁止行为

- ❌ 在审计报告中仅引用 L1 的 IAR/wIAR 数值而不执行 L2 仲裁
- ❌ 将 wIAR ≥ 0.75 直接解读为"该模块信息密度合格，无需进一步审查"
- ❌ 在 L2 仲裁中将所有 S 段一律升级为 R（必须逐段执行压缩测试）
- ❌ 跳过 DD 豁免校验直接删除被 L2 升级的 R 段
