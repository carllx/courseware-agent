# 规则：标题编号统一 (Heading Numbering Convention)

> **核心原则**：逐字稿的 H3 标题编号必须使用阿拉伯数字，确保跨模块的视觉一致性和标题序列的可排序性。

---

## §1 编号格式

### ✅ 正确格式

```markdown
### 1.1 感知通道与带宽
### 1.2 前注意力加工
### 2.1 格式塔原则概述
```

### ❌ 禁止格式

```markdown
### 一、感知通道与带宽        ← 中文数字
### 0.1 前注意力加工            ← 0.x 前缀
### 第一节 格式塔原则概述       ← "第X节" 格式
### A. 感知通道                 ← 字母编号
```

## §2 编号规则

1. 每个 `##` (H2) 模块内的 `###` (H3) 标题从 `1` 开始递增
2. 二级编号使用点号分隔：`1.1`、`1.2`、`2.1`
3. **同一周次内不同模块的编号体系独立**——M01 从 1.x 开始，M02 也从 1.x 开始
4. H4 (`####`) 标题不强制编号，但如使用编号则必须遵循相同格式

## §3 豁免

- 模块标题本身（`## Module X: 标题`）不受此规则约束
- 引用块内部（`> [CASE STUDY]` 等标签块内的子标题）不受约束
- 用户通过 `<!-- HEADING_OVERRIDE -->` 注释显式标记的标题可豁免
