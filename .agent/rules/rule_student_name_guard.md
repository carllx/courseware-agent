# 学生姓名规范检查 (Student Name Guard)

当 Agent 在执行 `/write` 或日常撰写任务，且文本中涉及具体的学生点名、互动提问、案例分析或反馈评价时，必须强制遵守以下约定：

## 1. 唯一真实来源 (Source of Truth)
所有提及的学生姓名，必须从项目根目录的 `students_roster.yaml` 中进行提取和校验。
禁止依靠大模型幻觉编造不存在的学生（如“李华”、“小明”等占位符，除非用于纯虚拟假设语境并有明确声明）。

## 2. 防治同音异形错误
在将语音转文字（如 SRT 导入）或口述录音转化为文稿时，必须意识到同音字/近音字是最高频的错误来源。
- 例如：`李云聪` 必须修正为 `李云骢`，`林杨广` 必须修正为 `林良广`。
- 如果发音与花名册中某位学生高度相似，默认修正为花名册中的正确用字。

## 3. 消歧机制 (Disambiguation)
如果在文本中出现了未在 `students_roster.yaml` 中的名字，Agent 必须通过上下文（Context）主动判断：
- 这是一次**由于拼音相近导致的识别错误**（应静默修正）。
- 这是一位**行业公众人物/特定历史人物**（如“乔布斯”、“李飞飞”，应保持原样）。
- 这是一个**专有名词/地名**被误识别为人名。

在不确定的灰度情况下（声学相似，但语境判定存在分歧），应当在工件或代码注释中通过带有上下文片段的警告（例如 `[NAME_MISMATCH] 疑似识别错误`）来提示教师进行人工核查。
