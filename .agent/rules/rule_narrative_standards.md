# 规则：叙事与文字规范 (Narrative Standards)

## TL;DR (预检阶段专用)

为耳朵写：竹节结构(≤20字/逻辑单元) + 话题优先(非SVO) + 禁忌词(进行/实现/功能/相关的)。韵律 2+2 音步、四字格≤2/段。过渡禁"下面我们来看"——用悬念反问/递进对比/回环/时间跳切。语调: 成熟干练、修辞铺垫、技术-心理桥接、反CRUD。

**适用范围**: 所有课程的脚本文件 (`weeks/*/src/*.md`)。
**核心哲学**: 脚本是一场**为耳朵写的演出**，不是技术文档的朗读版。
