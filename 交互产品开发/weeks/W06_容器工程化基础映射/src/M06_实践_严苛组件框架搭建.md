## 模块 6: 实践 — 严苛组件框架搭建 (约 80 分钟)
<!-- BUDGET: 0 chars | SLIDES: ≥0 | TYPE: activity | STATUS: exempt -->

> [ACTIVITY]
> **Type**: `Practice`
> **Duration**: `80min`
> **Desc**: 实验2(Exp2) 实践：Figma 响应式组件框架搭建
>
> **目标**: 在 Figma 中，基于上节课画的状态流转，搭建 3 个核心页面的"极端严苛版"骨架。不允许使用任何绝对定位。
>
> **约束要求**:
> 1. **全容器化**: 页面内任何元素（无论是导航、卡片还是单个按钮），都必须置于 Auto Layout 的掌控之中。你不能手动拖放微调其具体位置。
> 2. **建立间距刻度**: 先在文件中建立一个 4px 基准的倍数参照系（例如：4/8/16/24/32/48）。然后整个页面的 Layout 内边距和间距必须全都选自这个刻度表中的数字。
> 3. **基础 Token 映射**: 为你的页面配置核心的 Color Styles 和 Spacing Variables，命名必须遵循语义化规范（如 `surface-primary`, `spacing-lg`），禁止出现色值的原生硬编码。
> 4. **响应式测试 (Stress Test)**: 选中你建立的页面顶层容器，横向及纵向拖拽改变外框宽度。你的界面必须能够按照合理的逻辑自动缩放或换行，不能散落一地。如果崩溃了，检查你的 Hug 与 Fill 规则配置。
>
> **交付物**:
> 具备完美自适应能力的 3 张关键态页面骨架，并附带你所建立的一套极简版本的 Local Variable（包含语义化的主色阶与间隙值体系）配置界面截图。
