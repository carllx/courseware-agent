# 课程核心架构与理论溯源 (Course Rationale & Knowledge Map)

## 1. 课程定位与基因 (Course DNA)
《交互产品开发》已从传统的“重文档瀑布流式 Web 开发”全面转型为**“AI 辅助的交互体验与系统设计”**。
课程专为数字媒体艺术 (DMA) 专业的学生量身打造，核心基因如下：
*   **体验先行，剥离重度工程**：废弃复杂的“微型 SaaS”或要求全栈数据流的管理后台项目。课程载体锁定在**“交互体验装置 / 单页面互动应用”** (如：情绪交互网页、生成叙事界面)。
*   **Vibe Coding (AI 人机协同协作)**：不再强求学生手写深层状态机或异步逻辑。学生扮演“产品经理/提示词工程师”，通过 v0/CodeGeeX 产出带有前沿视觉表现力 (如粒子、动效) 的单页应用。
*   **科学但不苛求的验证闭环**：抛弃虚假的 A/B 测试与留存率指标。采用最硬核但也最落地的 **Nielsen 启发式专家走查** 与 **出声思考法 (Think-Aloud)** 进行同辈之间的定性可用性测试。

## 2. 教材矩阵与理论映射网 (Theoretical Map)
本课程打破了对单一教材的依赖，采用“一主三辅”的结构，各自拥有清晰的时序边界与知识管辖权。

### 核心骨架 (贯穿全期)：《Interaction Design: Beyond HCI》(2023)
*   **定位**：提供认知科学、界面发展史与可用性验证的底层逻辑。
*   **提取关键模块**：
    *   **Week 1-3 (基础与认知)**：什么是交互设计；体验目标与可用性概念模型；注意力与记忆负荷分析。
    *   **Week 12-13 (评估)**：启发式走查法 (Heuristic Evaluation)；实验室可用性测试。
*   **解决的核心问题**：“为什么这个界面是好/坏的？”、“怎么科学地找出错误？”

### 阶段一：洞察与验证：《Lean UX》
*   **定位**：摆脱长篇大论的需求文档，用最快速度确认“问题方向”。
*   **提取关键模块**：
    *   **Week 3-4 (敏捷框架)**：抛弃重型 Persona，使用假设驱动 (Hypothesis-Driven) 方法快速定位核心痛点；框定 MVP (最小可行性概念)。
*   **解决的核心问题**：“我们在开发前，解决的是真问题还是伪需求？”

### 阶段二：系统与结构设计：《About Face 4: The Essentials of Interaction Design》
*   **定位**：在进入视觉和 AI 生成前，做严谨的信息架构支撑（防结构崩溃）。
*   **提取关键模块**：
    *   **Week 5 (流向与编排)**：目标导向设计 (Goal-Directed Design)；绘制单页面的状态轮转图 (Orchestration and Flow)。
    *   **Week 8 (防错)**：预防错误设定 (Preventing Errors)；极端状态与情境反馈。
    *   **Week 10 (动效)**：微交互四要素框架 (Trigger/Rules/Feedback/Loops)；动效六大目标。
*   **解决的核心问题**：“这个单页面到底有几个状态？用户点错了怎么办？”

### 阶段三：视觉重塑与生成依据：《Refactoring UI》
*   **定位**：将前期的干瘪架构穿上“极致审美”的外衣，为 AI 提供精准的 Prompt 词汇。
*   **提取关键模块**：
    *   **Week 7-8 (视觉战术)**：文字与层级的剥离；摒弃 HEX 使用 HSL 构建配色系统；用阴影建立界面深度；如何处理空状态 (Empty States)。
*   **解决的核心问题**：“如何让 AI 生成出来的东西具备现代高级感，而不是老旧的 Bootstrap 默认套件？”

## 3. 核心流转：从 Figma Tokens 到 Vibe 原型
课程建立了一条从视觉设计到代码生成的核心转换链路：
1.  **定义系统**：在 Figma 中不是“画图”，而是建立对应 CSS Flexbox 逻辑的 AutoLayout 骨架。
2.  **提取 Tokens**：基于《Refactoring UI》的方法，将色彩、间距、字重提炼为设计变量 (Tokens)。
3.  **组合 Prompt**：将《About Face》梳理的状态流图，加上上述提炼的视觉 Tokens，组合成结构化提示词。
4.  **v0 生成与修补**：将提示词喂给大模型提取 UI 壳。遇到深层逻辑崩溃卡壳，不要求硬拼代码，允许学生使用 Figma 连线做兜底的“混合保真度演示”。
