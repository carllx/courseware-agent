# 阴影高度体系与双阴影技法

> 来源: Refactoring UI — "Use shadows to convey elevation" + "Shadows can have two parts"

## 阴影传达高度 (Elevation)

阴影不只是装饰效果——经过精心设计，它能在虚拟 z 轴上定位元素，建立有意义的深度层级。

**核心规则**：
- **小阴影 + 紧凑模糊** → 元素微微浮起（按钮级）
- **中阴影 + 中等模糊** → 元素悬浮于 UI 之上（下拉菜单级）
- **大阴影 + 大模糊** → 元素强烈弹出（模态对话框级）

**越靠近用户的元素，越能吸引注意力。**

### 建立阴影系统 (Elevation System)

与颜色、字体、间距一样，阴影也需要预定义固定集合——通常 **5 级**即可：

1. 定义最小阴影和最大阴影
2. 中间线性递增填充
3. 保持一致性，加速设计决策

### 阴影与交互结合

阴影不仅用于静态定位，更是交互反馈的利器：
- **拖拽排序**: 点击时添加阴影 → 元素"弹起"于列表之上 → 暗示可拖拽
- **按钮按压**: 点击时切换为更小阴影或移除阴影 → 元素"按入"页面

**设计心法**: 不要想阴影本身，想元素应该在 z 轴的什么位置，然后分配对应阴影。

## 双阴影技法 (Two-Part Shadows)

专业级阴影往往由**两层阴影叠加**构成，各司其职：

### 第一层：直射光阴影
- 更大更柔和
- 明显的垂直偏移 + 大模糊半径
- 模拟**直射光源**在物体背后投下的阴影

### 第二层：环境光阴影
- 更紧凑更深
- 较小的垂直偏移 + 小模糊半径
- 模拟物体底部**环境光无法到达**的暗区

### 高度越高，环境光阴影越淡

随着元素远离表面（高度增加），底部的环境光阴影逐渐消失：
- **最低高度**: 环境光阴影清晰可辨
- **最高高度**: 环境光阴影几乎（或完全）不可见

双阴影赋予设计师更精细的控制——大阴影保持柔和微妙，同时边缘阴影依然锐利有定义。
