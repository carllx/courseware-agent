# 动效与微交互理论（Motion, Timing, Transitions & Microinteractions）

> **来源**: About Face 4 Ch11 (Motion, Timing, and Transitions) + Interaction Design Ch1 (Dan Saffer) + Web 调研
> **适用周次**: W10

## 1. 微交互四要素框架 (Dan Saffer)

Dan Saffer 将微交互（microinteraction）定义为「界面中一次性的小型交互动作」，并拆解为四个组成部分：

| 要素 | 定义 | 示例 |
|:--|:--|:--|
| **触发 (Trigger)** | 启动微交互的事件。可以是用户发起（点击/滑动）或系统发起（通知/时间事件） | 用户点击"点赞"按钮 |
| **规则 (Rules)** | 一旦触发后发生的事情序列——动画时长、条件分支、状态变化 | 心形图标放大→变红→弹回原尺寸（200ms ease-out） |
| **反馈 (Feedback)** | 向用户传达结果的感官信号——视觉、听觉或触觉 | 图标颜色变化 + 轻微振动 + 计数+1 |
| **循环与模式 (Loops & Modes)** | 微交互的持续行为——是否重复、如何随时间变化、在不同条件下如何改变 | 长按触发连续递增；夜间模式下动效降级 |

## 2. 动效的六大目标 (About Face 4)

Cooper 引用 Saffer 指出，动画与过渡应当服务于以下目标：

1. **聚焦用户注意力** — 将视线引导到正确的位置
2. **展示对象间关系** — 通过运动揭示从属/因果
3. **维持上下文** — 在视图或状态转换中保持用户方位感
4. **传达进度感知** — 进度条、加载动画传递"系统在工作"
5. **创建虚拟空间** — 引导用户在状态之间流畅移动
6. **鼓励沉浸与参与** — 让用户愿意继续探索

## 3. 动效的三大品质 (About Face 4)

1. **短快响应 (Short, Sweet, Responsive)** — 动画不应拖慢交互，保持在 1 秒以内
2. **简单有意义 (Simple, Meaningful, Appropriate)** — iOS 7 "杀"App 的手势从复杂模式变为一次上滑
3. **自然流畅 (Natural, Smooth)** — 模拟物理属性（惯性、弹性、重力）

## 4. 延迟感知四级阈值 (Miller, 1968 / About Face)

| 阈值 | 用户感知 | 设计策略 |
|:--|:--|:--|
| < 0.1s | **瞬时** — 直接操控感 | 无需反馈 |
| < 1s | **响应式** — 注意到延迟但思维不中断 | 微妙视觉提示 |
| < 10s | **缓慢** — 注意力漂移 | 进度条必须 |
| > 10s | **断裂** — 用户离开 | 后台执行 + 完成通知 |

## 5. 物理隐喻的演进 (About Face)

- Mac 初代：窗口从图标"弹开"，菜单"下拉"
- 后期 macOS/Windows：对话框滑入、可展开抽屉/面板
- **iPhone 转折点**: 多点触控 + 动画过渡让移动端交互实现前所未有的沉浸感——"几乎忘记屏幕上只是像素"
- **iOS 7 教训**: 过度视差和缩放动画导致部分用户眩晕（前庭敏感）

## 6. 声音强化节奏

动效最成功时具有**节奏性 (rhythmic quality)**——时间节奏帮助用户预期下一步。声音可以配合：
- **操作确认** — iOS 按钮"嗒"声
- **选择变化** — PS3 主菜单的"咔哒"声
- **过渡伴随** — 滑动手势的"嗖"声
