# 色彩无障碍与多通道冗余 (Refactoring UI: Color Accessibility)

> 来源: Refactoring UI (Wathan & Schoger, 2018) — ch34-ch35

## 1. WCAG 对比度标准

- 普通文字 (<18px): 最低 **4.5:1** 对比度
- 大号文字 (≥18px): 最低 **3:1** 对比度
- 深色文字+浅色背景容易达标；白色文字+彩色背景往往需要背景色非常深

## 2. 翻转对比策略 (Flipping the Contrast)

当白字+深色背景的组合造成视觉层级问题时（深色块过于抢眼）：

- **翻转**: 改用深色彩色文字 + 浅彩色背景
- 颜色仍在，但不再喧宾夺主
- 适用于非主要关注区的彩色元素（如标签、徽章、提示条）

## 3. 色相旋转解锁无障碍

彩色背景上的彩色次要文字难以达到对比度标准时：

- 单纯调亮度会趋近纯白，主次文字难以区分
- **解法**: 将次要文字色相向更亮的色相旋转（青/品红/黄），在保持彩色的同时提高对比度

## 4. 颜色不能作为唯一信息通道 (Don't Rely on Color Alone)

- 红绿色盲用户无法区分红色"下降"和绿色"上升"
- **修正**: 始终配合图标、文字或对比度等非颜色通道来传递信息
- 折线图用不同颜色区分？→ 改用**对比度差异**（深浅），色盲用户更易分辨明暗差异

原则: **颜色只能增强信息，不能独占信息通道。**
