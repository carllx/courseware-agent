# 前端 CSS 盒模型 (CSS Box Model)

这是 Web 页面布局的物理基石。在前端工程中，所有 HTML 元素都被视为“盒子”。

## 四大核心属性
- **Content (内容)**: 元素的实际内容（文本、图片等）。
- **Padding (内边距)**: 内容与边框之间的透明距离，缓冲空间。
- **Border (边框)**: 围绕内边距和内容的物理界线。
- **Margin (外边距)**: 盒子与其他元素盒子之间的距离，决定外部推开的排斥力。

## 意义
当设计师在 Figma 等画板中自由拖拽绝对坐标元素时，容易忽略一旦进入浏览器，这些元素将受到盒模型的挤压与推拉。理解盒模型是从“画图思维”转向“容器工程思维”的觉醒点。
