# 扁平化深度与重叠分层

> 来源: Refactoring UI — "Even flat designs can have depth" + "Overlap elements to create layers"

## 扁平设计的深度策略

"扁平设计"通常指不使用阴影、渐变或任何模拟光影的效果。但**最有效的扁平设计仍然传达深度**——只是方式不同。

### 用颜色创造深度

**浅色前进，深色后退** (尤其是同色系色阶)：
- 元素比背景**更浅** → 感觉浮起（凸出）
- 元素比背景**更深** → 感觉凹陷（嵌入）

这一技法不限于扁平设计，在任何风格中都是传达距离的有效工具。

### 实心阴影 (Solid Shadows)

在扁平设计中传达深度的另一种方式：
- 短距离垂直偏移
- **零模糊半径**
- 使卡片或按钮在不牺牲扁平美学的前提下微微弹出

---

## 重叠分层 (Overlap to Create Layers)

最有效的深度创造手段之一是**让元素互相重叠**，产生"多层"视觉感。

### 背景过渡重叠
- 让卡片**跨越两种不同背景**的交界线（偏移而非完全包含）
- 或让元素比父容器更高，两侧均溢出

### 小组件中的重叠
重叠同样适用于小型组件，如轮播图的控制按钮叠加在图片边缘。

### 图片重叠的注意事项
图片重叠容易产生视觉冲突。解决方案：
- 为图片添加与背景色相同的**"隐形边框"**
- 图片之间保持间隙，避免混杂
- 仍能创造层次感，但无丑陋碰撞
