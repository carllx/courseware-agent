# 本地大模型辅助代码阅读与排障 (LLM-Assisted Code Reading & Debugging)

> **来源**: Web 调研综合 (Cursor AI workflows, v0 debugging, 2024-2025)
> **适用周次**: W11 逻辑排障与兜底策略

## 核心前提：设计师不需要"会写代码"，但需要"能读懂代码在说什么"

在 Vibe Coding 工作流中，AI 为你生成了代码。但当代码出 bug 时，你需要做的不是自己修——而是**让 AI 帮你理解问题出在哪里，然后告诉 AI 怎么修**。

## Read → Explain → Fix 三步排障法

| 步骤 | 操作 | 示例 Prompt |
|:--|:--|:--|
| **Read** (阅读) | 选中报错代码或出问题的组件，问 AI "这段代码在做什么？" | `"解释这个 onClick handler 的逻辑流"` |
| **Explain** (归因) | 把错误现象描述给 AI，让它分析可能的原因 | `"点击按钮后页面白屏，控制台报 'Cannot read properties of undefined'，可能是什么原因？"` |
| **Fix** (修复) | 确认 AI 的归因后，让它生成修复方案 | `"帮我修复这个 null 检查问题，加上边界防御"` |

## 前端常见错误类型 Taxonomy

### 1. 状态不同步 (State Desync)
- **现象**: 界面显示的数据与实际数据不一致，或操作后界面不更新
- **根因**: useState 更新异步、useEffect 依赖数组遗漏
- **AI 排障关键词**: `"为什么 state 更新后 UI 没变？"` `"检查 useEffect 依赖项"`

### 2. 事件监听泄漏 (Event Listener Leak)
- **现象**: 组件卸载后仍在触发事件、内存占用持续增长
- **根因**: addEventListener 未在 cleanup 中移除
- **AI 排障关键词**: `"组件卸载后仍有事件触发"` `"useEffect cleanup"`

### 3. CSS 层叠覆盖 (CSS Cascade Conflict)
- **现象**: 样式"不听话"——明明写了却不生效，或被其他样式覆盖
- **根因**: 选择器优先级冲突、!important 滥用、Tailwind 类名冲突
- **AI 排障关键词**: `"为什么我的样式被覆盖了？"` `"检查 CSS specificity"`

### 4. 组件未渲染 / 条件渲染失败 (Render Failure)
- **现象**: 组件"消失"了——页面上看不到预期的元素
- **根因**: 条件渲染的布尔值判断错误、key 属性冲突导致 React 复用错误节点
- **AI 排障关键词**: `"组件没有渲染出来"` `"conditional rendering debug"`

### 5. API / 数据获取失败 (Data Fetch Failure)
- **现象**: 数据加载永远转圈、或显示空白
- **根因**: CORS 跨域、fetch URL 拼写错误、JSON 解析失败
- **AI 排障关键词**: `"网络请求返回 404"` `"CORS error 怎么处理"`

## Cursor / v0 Chat 排障实操模式

### 模式 A：选中代码 → 内联问答
在 Cursor 中选中报错代码段，按 Cmd+K 打开内联编辑，直接描述问题。AI 会在上下文感知的前提下给出修复建议。

### 模式 B：控制台日志喂给 AI
1. 打开浏览器 DevTools Console
2. 复制错误信息（红色报错文本）
3. 粘贴到 Cursor Chat，附加描述：`"浏览器控制台报了这个错，帮我定位问题"`
4. AI 会结合项目代码库分析根因

### 模式 C：截图 + 自然语言描述
对于视觉类 bug（布局错乱、颜色不对），可以截图粘贴到 AI 对话中，用自然语言描述"期望效果 vs 实际效果"。

## 关键边界：AI 修不好的

| 情况 | 正确做法 |
|:--|:--|
| AI 反复生成的修复都不对（超过 3 轮） | 停止迭代，回退到上一个可用版本 |
| 问题涉及跨文件复杂状态管理 | 先用 AI 画出状态流转图，理解全局后再修 |
| 性能问题（卡顿、内存泄漏） | 超出 Vibe Coding 范畴，降级为 Figma 演示 |

## 与 W09 AI 约束边界的呼应

W09 讲的「AI 代码生成六大约束」中的"差不多对"约束在 W11 排障中最为典型——AI 生成的代码在 90% 的路径上正确，但在边界条件下崩溃。排障的核心就是找到那 10% 的裂缝。
