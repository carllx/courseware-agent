# 色彩进阶技巧 (Refactoring UI: Color Advanced)

> 来源: Refactoring UI (Wathan & Schoger, 2018) — ch32-ch33

## 1. 饱和度随亮度补偿 (Don't Let Lightness Kill Your Saturation)

在 HSL 色彩空间中，亮度接近 0% 或 100% 时，**饱和度的视觉效果会被削弱**。

- 同样 S=80% 的蓝色，在 L=50% 时鲜艳，在 L=90% 时洗白
- **修正法则**: 当亮度偏离 50% 时，必须同步提高饱和度以补偿

## 2. 感知亮度与色相旋转 (Perceived Brightness & Hue Rotation)

### 感知亮度公式

人眼对不同色相的亮度感知不同。黄色（60°）感知最亮，蓝色（240°）感知最暗。

三个感知亮度峰值: 黄 (60°)、青 (180°)、品红 (300°)
三个感知亮度谷值: 红 (0°)、绿 (120°)、蓝 (240°)

### 色相旋转调明暗

调整颜色明暗的第二种武器（除了调 Lightness）：

- **调亮**: 将色相向最近的高亮度色相旋转 → 60°/180°/300°
- **调暗**: 将色相向最近的低亮度色相旋转 → 0°/120°/240°
- **旋转幅度 ≤ 20-30°**，否则看起来像完全不同的颜色

实际用途: 用黄色构建调色板时，深色阶向橙色旋转（而非直接降亮度），避免深色阶变成浑浊的棕色。

## 3. 灰阶不必是"灰"的 (Greys Don't Have to Be Grey)

- 纯灰 = S:0%，但实际 UI 中的"灰"往往带有明显饱和度
- **冷灰**: 注入蓝色色相 → 科技感、专业感
- **暖灰**: 注入黄色/橙色色相 → 亲切感、自然感
- **一致性原则**: 浅/深灰阶也要同步增加饱和度，否则与中间灰阶的温度感脱节
