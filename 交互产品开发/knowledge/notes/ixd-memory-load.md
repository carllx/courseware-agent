# 记忆负荷与认知 (Memory Load & Cognition)

## 核心要点
* **人的工作记忆瓶颈**：人类的工作记忆容量极为有限（著名的“7±2”法则），无法在短时间内同时处理和记住大量新信息。这是引发数字产品用户认知挫败感（Cognitive Overload）的生理根源。
* **识别胜于回忆 (Recognition over Recall)**：这是交互设计中一条金科玉律。
    * **回忆 (Recall)**：需要用户从长期记忆中主动提取信息，耗费大量脑力（例如：命令行界面需要回忆出具体的命令拼写，如 `grep -r "error" .`）。
    * **识别 (Recognition)**：当信息呈现在眼前时，用户只需要辨认即可（例如：图形界面中，看到一个“垃圾桶”图标或“设置”齿轮，然后点击）。
    * **设计启示**：优秀的界面设计应尽量减少用户的记忆负担，利用菜单、提示词、面包屑导航（Breadcrumbs）等视觉线索，将隐性的记忆需求转化为显性的识别任务。
* **情境依赖 (Context-dependent)**：人对信息的记忆高度依赖于初次学习时的情境。如果在不同的上下文中提供相似的线索，用户的回想速度和准确率都会提升。

## 可用叙事角度
* 用命令行（Command Line）与图形界面（GUI）的历史变迁作为引入：从黑框绿字的回忆时代，跨入全图形的识别时代，解释 GUI 为什么在 80 年代掀起革命。
* 密码输入 vs 面容或指纹识别：用日常频繁遭遇的“密码遗忘”来痛斥“以系统为本而非以人为本的强制回忆”。

## 与课程的关联
W02 - 人类认知与心智摩擦。重点解释心智摩擦的“内存”原理。任何违背“识别胜于回忆”的设计，都在透支用户的脑皮层工作记忆，导致“摩擦生热”。
