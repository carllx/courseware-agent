## 一、项目定位

本项目是全课程的**终极综合落地输出（实验 4）**，采用双轨试卷的模式对学生本学期的交互与前端全栈能力进行考核。你必须将前序实验产出的架构和视觉图纸，通过现代的前端开发流与人机协同工具，最终转换为浏览器可直接运行的代码产物。

作品评判的核心标准是：
> **你是否能独立使用前端三大基石（HTML、CSS、JS），构建出一个视觉精致、响应流畅、无明显死链和报错的高保真多页面网站？**

## 二、期末双轨试题 (A/B 卷)

按照教务与大纲部署，本次期末考核分为 A、B 卷。

### 📌 默认执行：A 卷（个人作品集网站开发）

- **项目命题**：制作一个属于你自己的高质量个人作品集网站 (Personal Portfolio Website)。
- **核心要求**：
  1. 必须使用纯原生的 **HTML、CSS 和 JavaScript** 进行开发。
  2. 网站包含**至少 4 个完整的相互跳转页面**（建议为：首页 / 个人简介 / 核心作品库 / 联系方式与履历）。
  3. 各页面间跳转逻辑必须完全畅通，无 404 死链。

### ⏸️ 储备备用：B 卷（商业区/村庄店铺年轻化改造）
*(注：本学期默认不启动 B 卷，仅作题库储备)*

- **项目命题**：为传统的商业街或具有特色的村庄店铺制作一套年轻化的门店网页。
- **核心要求**：多门店、多层级的门户交互设计，吸引年轻客流量驻足的交互动效。

## 三、代码与技术规范 (A 卷必看)

不要停留在 Figma 的画板阶段，你需要运用 Vibe Coding 与前沿 AI 助手跨越工程门槛。

```text
层 1 — 结构化语义 (HTML)
    代码骨架是否清晰合理？容器划分是否采用了正确的语义化标签（如 <nav>, <main>, <section>）？
    
层 2 — 视觉规范与响应式 (CSS)
    是否提取了统一的色板和排版 Token？是否抛弃了内联样式，转而使用高复用的类名组合？
    页面是否具备基础的适配与排版美感？
    
层 3 — 交互体验与动效 (JavaScript / CSS3)
    是否设计了精致的 Hover 态和过渡效果？是否有跟随特效、平滑滚动或其他微交互来提升整体 Vibe？
```

> [!WARNING]
> **禁止行为**：
> 1. 严禁单纯用一张包含所有视觉的大图片代替 HTML 布局排版。
> 2. 严禁直接套用现成的沉重建站模板引擎而无法说明自身逻辑。
> 这两项将直接导致期末卷面代码分清零。

## 四、开发工作流建议

建议运用以下人机协同的工作流完成原型到代码的跳跃：

```text
Step 1  →  通过设计工具确认网站的 4 个页面的视觉布局和跳转关系。
Step 2  →  提取严苛的视觉 Token（字重、比例、HSL 色彩、间距）。
Step 3  →  利用结构化 Prompt 引导 AI 前端生成工具（如 v0 / CodeGeeX）输出页面的基础 HTML/CSS 骨架。
Step 4  →  拆分与整理代码结构，在 VS Code 等编辑器中手动调整 CSS 模块。
Step 5  →  为核心作品或交互焦点引入 JavaScript 动态效果。
Step 6  →  执行浏览器本地测试，修复响应式布局错乱与断链。
```
