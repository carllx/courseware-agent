## 一、项目定位

本项目是全课程的**终极综合落地输出（实验 4）**，采用双轨试卷的模式考核学生本学期的「人机共生设计」与「价值叙事」能力。你必须将前序实验产出的架构和视觉图纸，通过与 Agent 的高频对话，转换为浏览器可直接运行的数字形态。

作品评判的核心标准是：
> **你是否能通过精准的语言模型（Agent）指挥，构建出一个立意深刻、视觉精致、响应流畅的多页面互动叙事空间？**

## 二、期末双轨试题 (A/B 卷)

按照教务与大纲部署，本次期末考核分为 A、B 卷。

### 📌 默认执行：A 卷（数字身份与社会化叙事）

- **项目命题**：突破传统简历的刻板，打造一个展现你作为“青年设计师”思维深度与哲学观的个人数字展馆。
- **核心要求**：
  1. 由 Agent 完全接管底层逻辑生成，你只需专注于视觉意图和人文理念的传递。
  2. 网站包含**至少 4 个相互跳转的核心页面**，体现“我是谁”、“我如何思考世界”的逻辑闭环。
  3. 叙事跳转逻辑必须完全畅通，防错无死链，并带有情感牵引。

### ⏸️ 储备备用：B 卷（数字返乡与在地文化重塑）
*(注：本学期默认不启动 B 卷，仅作题库储备)*

- **项目命题**：针对日益老龄化的传统商业街或村庄特产店，通过数字化交互手段重新连接年轻消费群体。
- **核心要求**：
  1. 建立具有在地文化关怀的数字化消费门户，用现代美学重塑传统价值。
  2. 通过微动效与跨端自适应设计，拉近传统业态与现代青年的距离。

## 三、人机协同与体验规范 (A/B 卷必看)

不要停留在 Figma 的静态画板阶段，你需要运用 Vibe Coding 与 Agent 跨越工程鸿沟。你无需懂得内部代码是如何编写的，Agent 会替你处理所有技术细节。你的考核点在于对以下体验层的把控：

```text
层 1 — 叙事与结构逻辑
    页面骨架是否支撑了你的核心主题？信息的呈现顺序是否符合读者的认知心理？
    
层 2 — 视觉规范与多屏幕自适应
    无论 Agent 在底层使用了什么框架，最终在宽屏显示器或手机上，排版是否都保持了绝佳的美感和严苛的比例？
    
层 3 — 互动体验与情绪流 (Vibe)
    是否通过 Agent 注入了恰到好处的过渡动画和 Hover 反馈？是否让访问者产生了情感共鸣？
```

> [!WARNING]
> **禁止行为**：
> 1. 严禁单纯用一张包含所有视觉的大图片代替界面布局。
> 2. 严禁直接套用现成无代码建站平台（如 Wix）或老旧的 CMS 模板。必须通过自然语言（Prompt）亲自指挥 Agent 生成、调整并拼装。
> 这两项将直接导致期末成绩清零。

## 四、人机协同工作流建议

建议运用以下 Agent 协作流完成设计原型到数字形态的跳跃：

```text
Step 1  →  通过设计工具梳理网站的 4 个核心叙事页面及其跳转关系。
Step 2  →  提取严苛的视觉 Token（字重、比例、色彩基调、间距）。
Step 3  →  将你的设计构思转化为结构化 Prompt，指挥 Agent 生成初始的页面交互原型。
Step 4  →  在浏览器中亲自走查各页面的响应式表现与过渡体验。
Step 5  →  若发现错位或不符合预期，通过追加自然语言指令要求 Agent 注入微动效或修复排版，直至达到商用质感。
Step 6  →  执行多设备测试，确保叙事逻辑顺畅无死链。
```
