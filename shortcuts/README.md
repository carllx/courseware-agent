# 🚀 Shortcuts 课程桌面快捷指令库 — 使用指南

这份指南介绍了如何使用 `shortcuts` 目录下的系列快捷指令。经过最新的 UX 体验重构，这套工具链致力于提供**0门槛、不打断心流**的自动化支持，让你能更专注于课程内容的创作。

> 💡 **所有 `.command` 文件均可直接在 macOS 中双击运行**，无需打开终端环境。

## 🧠 核心体验设计：空间感知 (Space-Aware)

你不再需要繁琐地每次选择或输入课程编号！
所有的工具脚本都具备基于最新修改时间 (mtime) 的**「空间感知」**能力。脚本会自动探测并推导你**刚刚编辑过**的最活跃课程。只需看到类似下面的提示后轻敲「回车键」，即可切入沉浸式工作流：

`检测到最近活跃课程 [信息可视化]（2 分钟前有变动），继续？(Y/n)`

*(如果无法判断或有另外锁定需求，系统也会提供备用数字菜单供你手动选择。)*

---

## 🛠️ 工具速览 (Tools Overview)

快捷指令按使用场景分为两类：**信息获取**（体检 / 数据统计）与 **副作用产出**（开启预览 / 生成文件）。

### 1. 📱 H5预览.command
**【核心功能】** 将 Markdown 开发脚本即时转换为可交互的高保真 H5 课件，并在浏览器自动打开。
**【UX 特性】** 
- ⚡️ **智能跳编**：若你仅想随时确认样式，系统侦测到源文件未变动时将1秒闪跨编译，直接启用 Vite 热重载服务器。
- 🟡 **增量感知与全量重编**：如果它探测到你新增了 `.md` 文件或调整了宏观结构，将自动重走 Python 全量解析流程，确保预览永不错位。

### 2. 🔍 快速审计.command
**【核心功能】** 一键运行全景体验扫描：`项目结构质量` + `标准合规性规范` + `视觉素材断链验证` + `时长预估退化检测`。
**【UX 特性】**
- 📋 **全景仪表盘**：遭遇报错不会立刻中止剥夺视线。脚本坚持跑完全程，最终为你输出一张红绿相间的直观状态面板（Dashboard）。
- ⏸️ **报告阅览缓冲**：结束时窗口强驻留，供你检阅详情并根据诊断开方修 Bug。

### 3. 📊 时长估算.command
**【核心功能】** 解构各个章节，单独测算评估「模块字数 / 时长预估 / 素材填充率」。
**【UX 特性】** 呈现透明度极高的纯文字统计报表，助你精确拿捏课堂容量节奏（窗口保留等待阅读）。

### 4. 🔗 视觉断链检查.command
**【核心功能】** 交叉比对脚本引用图片指令与本地硬盘真实文件，抓出 `[VISUAL]` 引用的幽灵链接。
**【UX 特性】** 自动化扫雷，轻松检出拼写错误（比如 `.jpg` 误作 `.png` 或空文件），无需逐行翻找脚本。

### 5. 📄 导出审阅Word.command
**【核心功能】** 一键抽取全套撰写脚本，导出为便携、适用广、支持审改批注的结构化 Word (`.docx`) 文档。
**【UX 特性】** 运行全绿后，不仅会自动存放至对应目录，还会贴心抛引 `是否在 Finder 中打开输出目录 (Y/n)`，回车即触达归档位。

### 6. 📝 导出TTS文本.command
**【核心功能】** 剥离代码、视觉指令与标记，针对 Doubao 、 剪映 等媒体配音工具析出纯净无杂质的盲读文本。
**【UX 特性】** 文件统一落户至 `$COURSE/build/tts`，且生成后触发「3 秒无感销毁」机制，丝滑不留痕。

## 👩‍🏫 典型工作流指南 (Typical Flow)

- **日常码字**：双击 📱 `H5预览.command`。将浏览器与编辑器分屏，即改即现，实时呈现高保真课程布局。
- **阶段冲刺结束**：双击 🔍 `快速审计.command` 进行全身体检（如果发现红灯，利用剩余检查脚本定位问题）。
- **定稿交付 / 协同**：逐次双击 📄 `导出审阅Word` 与 📝 `导出TTS文本`。一键生成供教研检查的文字底稿与供视频切片的配音底稿。
