# 🚀 Shortcuts 课程桌面快捷指令库 v2

这套工具链经过 UX 架构重设计，从 6 个原子工具整合为 **4 个场景化管线入口**，按开发者心流的自然断点组织——**写作 → 确认 → 导出 → 发布**。

> 💡 **所有 `.command` 文件均可直接在 macOS 中双击运行**，无需打开终端环境。

## 🧠 核心设计原则

- **场景驱动**：每个入口对应一个完整的开发场景，内部自动编排管线
- **空间感知**：基于文件 mtime 自动锁定活跃课程，回车即进入心流
- **管线内聚**：清理、校验、构建等步骤自动串联，不需要手动跑前置命令
- **渐进披露**：默认走快速路径，高级选项通过交互菜单展开

---

## 🛠️ 工具矩阵

| 快捷方式 | 场景 | 核心能力 |
|:---|:---|:---|
| **📱 预览** | 日常编码 | 空间感知增量生成 → Vite 热重载预览 |
| **🔍 体检** | 阶段性检查 | 6 维全景仪表盘 + 废弃资产清理 |
| **📦 导出** | 交付协作 | 质量门禁 → Word/TTS 统一导出 |
| **🚀 发布** | 上线部署 | 清理→构建→验证→dist 全管线 |

---

### 📱 预览.command
**【场景】** 日常码字时的即时预览，即改即现。

- ⚡️ **空间感知增量**：默认只生成当前活跃课程的 JSON，启动快 3-5x
- 🔄 **mtime 智能跳编**：源文件未变动时 1 秒跳过编译
- 🌐 **自动打开浏览器**：`http://localhost:5173`
- 按 `A` 切换全课程模式

### 🔍 体检.command
**【场景】** 阶段冲刺结束后的全身体检。

**6 维检查**：
1. 项目结构验证
2. 规范合规性
3. 视觉素材完整性（断链检查）
4. 时长 & 退化检测
5. 废弃资产扫描（新增！）
6. 构建新鲜度（新增！）

输出全景仪表盘 + 磁盘占用报告。发现废弃资产时自动提示清理。

### 📦 导出.command
**【场景】** 将脚本交付给教研组审阅或生成 TTS 配音底稿。

- 🛡️ **质量门禁**：导出前自动执行断链 + 规范快检，拦截问题脚本
- 📋 **交互式选择**：`[1] Word  [2] TTS文本  [3] 全部`
- 📂 **Finder 集成**：导出后提示打开输出目录

### 🚀 发布.command
**【场景】** 将课件构建为生产级 dist/ 产物。

- 🧹 **构建前清理**：自动检测废弃资产，可选清理
- 📦 **SSG 全管线**：生成 JSON → Vite 打包 → 图片转 WebP → 音频转 MP3
- ✅ **产物验证门禁**：WebP/MP3/JSON 定量门禁，不通过禁止部署
- 📋 **后续引导**：构建完成后提示 Agent 部署命令
