# 视觉系统样式对照参照规范 (Visual Layout Catalog)

> **核心指引**：本文档为 12 种语义布局预设（Semantic Layouts）提供**“输入字典”（Markdown 语法）**与**“输出字典”（H5 最终视觉呈现）**的严格对照。
> 作者在编写脚本时，请直接复制对应的 `Markdown 语法` 模板并替换内容。

---

## 1. 单焦点与版式声明 (Center 系)

基于 `Center` 基础空间，屏幕核心焦点水平与垂直居中，不含左右结构分割。

### 1.1 `Center` (居中排版)
**场景**：封面、章节大标题、大号金句强调、核心概念陈述。
**语法模板**：
```markdown
> [VISUAL]
> **Slide**: W01_Intro_Concept
> **Layout**: `Center`
> **Scene**: 极简留白的文字排版，表达核心概念
> **Text**: 这是一句需要让学生全神贯注看到的结论
```
**H5 呈现结果**：
*   **空间**：绝对居中，两侧留出大量负空间（空白）。
*   **内容**：若提供了 `Text` 会以超大号加粗字体（如 Headline 级别）显示。没有其他干扰元素。

### 1.2 `CTA` (行动号召)
**场景**：课程收尾、重要总结致谢、促使学生课后行动（Call To Action）。
**语法模板**：
```markdown
> [VISUAL]
> **Slide**: W01_Ending_Homework
> **Layout**: `CTA`
> **Scene**: 结束页，引导学生进行思考
> **Text**: 课后作业：卸载你手机上最难用的一个 App
```
**H5 呈现结果**：
*   **样式覆盖**：背景反色（由白转黑/深色），文字反白。
*   **视觉感受**：强烈的视觉阻断，标志着一个教学阶段或全课的彻底结束。文字排版与 `Center` 相同但具有强调按钮质感。

### 1.3 `Agenda` (大纲目录)
**场景**：开场后展示本节课的结构，或章节过渡时提示当前进度。
**语法模板**：
```markdown
> [VISUAL]
> **Slide**: W01_Class_Agenda
> **Layout**: `Agenda`
> **Scene**: 课程核心大纲概览
> **List**: 1. 软件简史 / 2. 用户体验模型 / 3. 认知摩擦
```
**H5 呈现结果**：
*   **内容触发**：检测到 `List`，自动启用**编号列表组件**。
*   **空间布局**：列表居中偏左对齐排列，行距加宽，带有清晰的大纲图标或数字着重编号，标题可能置于最顶部。

## 2. 图文双拼 (Split 系)

基于 `Split` 基础空间，屏幕从中间切分（通常 5:5 或 4:6），支持并置两种不同类型的内容。

### 2.1 `Split` (极简双栏)
**场景**：左侧文字解释，右侧原理配图；或左侧代码，右侧输出结果。
**语法模板**：
```markdown
> [VISUAL]
> **Slide**: W01_Cognitive_Model
> **Layout**: `Split`
> **Scene**: 人的认知过程模型图
> **List**: 表现模型 / 心理模型 / 实现模型
> **Asset**: `cognition_process.png`
```
**H5 呈现结果**：
*   **内容触发**：自动推断 `List` 和 `Asset` 分列两侧。
*   **视觉**：一侧是垂直居中的文字列表/段落，另一侧是自适应高度的图片组件，中间有柔和的分割线或安全距。

### 2.2 `Quote` (金句展示)
**场景**：引用名人名言、经典文献段落，并附带人物头像或背景。
**语法模板**：
```markdown
> [VISUAL]
> **Slide**: W01_Cooper_Quote
> **Layout**: `Quote`
> **Scene**: Alan Cooper 头像肖像
> **Text**: 无论系统多好，只要用户觉得难用，它就是烂的。
> **Asset**: `alan_cooper.jpg`
```
**H5 呈现结果**：
*   **样式覆盖**：激活「引言组件（Quote Component）」，包裹巨大的左边距引号（"）。
*   **视觉**：`Asset` 自动处理为圆形头像或带遮罩的侧边图，文字使用斜体或特定的衬线字体传达经典感。

### 2.3 `Workshop` (指导工坊)
**场景**：教学转换为实操时间，给出操作要点。
**语法模板**：
```markdown
> [VISUAL]
> **Slide**: W01_Live_Practice
> **Layout**: `Workshop`
> **Scene**: Figma 界面线框图搭建动图
> **List**: 1. 打开文件 / 2. 创建 Frame / 3. 命名图层
> **Asset**: `figma_wireframe_demo.gif`
```
**H5 呈现结果**：
*   **样式覆盖**：触发工坊模式，屏幕四周边缘显示高亮强调色（如顶部黄色警示条“正在实操”）。
*   **空间**：`List` 会被渲染为带 Checkbox 或者步骤强调器的组件，暗示学生需要一步步跟随。

## 3. 沉浸全屏 (Full 系)

取消正常的安全边距留白（Padding: 0），内容延展直至设备屏幕的物理边缘。

### 3.1 `Full` (沉浸满屏)
**场景**：强视觉冲击力的大图展示（摄影作品、复杂的系统全局架构面貌）。
**语法模板**：
```markdown
> [VISUAL]
> **Slide**: W01_Architecture_Map
> **Layout**: `Full`
> **Scene**: 复杂的云原生架构设计拓扑图
> **Text**: 现代 Web 架构范式
> **Asset**: `modern_web_arch.jpg`
```
**H5 呈现结果**：
*   **内容触发**：`Asset` 以 `background-size: cover` 占满 100% 视口。
*   **叠加态**：若提供了 `Text`，底部自动添加黑色半透明渐变遮罩层（Scrim），将白色 `Text` 叠在画面底部，确保可读性。

### 3.2 `Screenshot` (带设备的截图)
**场景**：具体软件的界面演示、网页截图。
**语法模板**：
```markdown
> [VISUAL]
> **Slide**: W01_Bad_UX_Example
> **Layout**: `Screenshot`
> **Scene**: 非常难用的售票网站填表界面
> **Asset**: `bad_ticket_ui.png`
```
**H5 呈现结果**：
*   **样式覆盖**：底层渲染 `Full`，但引擎检测到 `Screenshot` 后，自动为纯平图片 `Asset` 套上一个“macOS 浏览器窗框”或“iPhone 设备壳”，外加柔和的拟物阴影，瞬间提升界面演示的专业感。

### 3.3 `Poll` (互动轮询)
**场景**：学生扫码填问卷、现场互动答题。
**语法模板**：
```markdown
> [VISUAL]
> **Slide**: W01_Survey_QR
> **Layout**: `Poll`
> **Scene**: 包含微信扫码互动页面的二维码
> **Text**: 扫码进行随堂小测验
> **Asset**: `quiz_qrcode.png`
```
**H5 呈现结果**：
*   **样式覆盖**：针对二维码特调的组件，`Asset`居中展示，四周无杂讯。背景通常为动态纯色。文字置顶为互动横幅。

## 4. 多列网格 (Grid 系)

以二维矩阵阵列排列要素，通常装载多个项目并列呈现。

### 4.1 `Grid` (常规矩阵)
**场景**：枚举 3 个以上的特征、分类四象限、展示人物卡片墙。
**语法模板**：
```markdown
> [VISUAL]
> **Slide**: W01_Features_List
> **Layout**: `Grid`
> **Scene**: 四种常见产品的 Icon 网格
> **List**: 硬件 / 软件 / SaaS / 组合服务
```
**H5 呈现结果**：
*   **算法分配**：引擎依据 `List` 的项目数（如 4 项），自动计算开启 2x2 网格组件，为以等宽高区块绘制出四张独立的白色卡片（Card）。

### 4.2 `Comparison` (红绿对比)
**场景**：正反例对比、好坏设计对比、不同方案之争。
**语法模板**：
```markdown
> [VISUAL]
> **Slide**: W01_Good_Bad_UX
> **Layout**: `Comparison`
> **Scene**: 错误弹窗的写法 vs 友好弹窗的写法
> **List**: ❌ 错误：Error Code 404 / ✅ 正确：页面似乎迷路了，点击这里返回
```
**H5 呈现结果**：
*   **样式覆盖**：检测到 `Comparison` 宏，引擎强制开启双列等分网格。
*   **语义解析**：系统解析以 ❌/✅ 开头的列表项，左列整体赋予防御性告警色（如浅红底+红边），右列赋予正面建设性颜色（如浅绿底+绿边），视觉区隔极其强烈。

## 5. 线性定向 (Flow 系)

不再是普通图文，而是具有明显“时间先后”或“因果箭头”关联的内容。

### 5.1 `Flow` (节点流线)
**场景**：工作流说明（步骤1-2-3）、时间上的编年史。
**语法模板**：
```markdown
> [VISUAL]
> **Slide**: W01_Design_Process
> **Layout**: `Flow`
> **Scene**: 标准的双钻设计模型流线
> **List**: 发现问题 / 定义问题 / 探索方案 / 确定方案
```
**H5 呈现结果**：
*   **内容触发**：检测到 `List` 和 `Flow` 强耦合，不再使用普通的纵向原点列表，而是调用 `步骤条/时间线组件 (Timeline Component)`，从左至右将文案排列在一条贯穿屏幕视觉重点的带有箭头指示的轴线上。
