# 数字媒体艺术专业排课计划审计指南 (Guideline)

本文件作为长期指导文件，规定了数字媒体艺术专业历年秋季排课数据提取时的严格防混淆与精准映射核查机制。

## 1. 专业定性防混淆机制
在任何排课数据提取操作前，必须对源文件（Excel/PDF/Word）执行命名与内部表头的硬校验：
- **必含关键字**：`数字媒体艺术` 或 `数艺`
- **排他关键字**：绝不允许包含 `数字媒体技术` 或 `数媒技`
所有参与分析的文件必须 100% 确认归属于设计学院/数字媒体艺术专业，防止跨专业数据的错误污染。

## 2. 学期精确映射机制 (秋季)
针对 Fall 对应的秋季排课提取，必须脱离“智能猜测”，使用底层数据锚定：
- 在标准人培矩阵表格（如 `附表一：课程计划进程表`）中，秋季学期严格对应于**单数学期列**。
- **锚定规则**：
  - 第 1 学期（大一秋）：锚定列内学分有效值。
  - 第 3 学期（大二秋）：锚定列内学分有效值。
  - 第 5 学期（大三秋）：锚定列内学分有效值。
  - 第 7 学期（大四秋）：锚定列内学分有效值。
- 只有在明确对应列下出现有效学时/学分的行，才被提取为秋季课程，杜绝将春季课程（双数列）混入。

## 3. 边缘年级容错策略 (Fallback)
若遇目标群体未在标准学期映射图谱中（例如“未按期毕业的专升本”等），强行推断学期对应关系属于违规操作。
- **应对措施**：必须启动 Fallback 机制。提取该年级（学制）下《人才培养方案》所包含的**全量课程底库**。
- **交付要求**：在生成的数据报告中，对全量数据添加 `> 【审查说明：人工筛选注意】` 高亮块引用，移交最终人工教务进行过滤，确保不错漏。
