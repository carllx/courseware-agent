# 强制交叉检查规则 (Anti-Amnesia Rules)

**此文件为强约束规则，任何负责撰写或审核《情况说明》的 Agent（包括主控 Agent 和 QA Subagent）在生成或检查输出草稿（View）时必须强制执行以下校验：**

## Rule 1: 课时构成闭环校验
- 必须包含 `timeline.yaml` 中产生学时的所有记录：
  - 36 学时（4.29-6.14）
  - 4 学时（6月15日）
  - 12 学时（6月17日）
  - 8 学时（7月5日）
- 必须明确计算出总额 **60 学时**，证明绝对没有偷工减料。

## Rule 2: 关键动机不可裁剪
- 必须明确提及 `stakeholders.yaml` 中记录的“班委反馈学生希望16周前结课”这一关键动机。
- 必须明确提及“7月5日差异化考勤策略”，以证明教师的人性化解困意图。

## Rule 3: 佐证证据全覆盖
- 生成的文章附录或正文中，必须显式引用或包含 `evidence_index.yaml` 中的所有核心证据 ID 所对应的文件说明。
