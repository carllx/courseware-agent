# W04 实践指南：AI 辅助的 D3.js 视觉通道映射

欢迎来到第四周的实践环节！🎉 

我知道一听到要写代码（特别是 D3.js），大家可能会觉得有点紧张。**别担心！** 在这节课中，我们不需要你从头手敲哪怕一行复杂的逻辑代码。我们将通过 AI 辅助的“填空题”方法，轻松搞定数据可视化！

---

## 🧭 第一步：召唤 AI 的“填空题”魔法（Mad Libs Prompt）

在可视化设计中，我们学过了 Munzner 的**视觉通道（Visual Channels）**理论。现在，我们要把这些理论变成 AI 能听懂的咒语。

请复制下面的“填空模板”，替换掉括号里的大写内容，然后发给你的 AI 助手（比如 ChatGPT / Claude / 豆包 等）：

> [!TIP]
> **🤖 AI D3.js 咒语模板（请填空）：**
>
> "你好！我正在学习数据可视化。请帮我用纯前端代码（HTML + D3.js v7）写一个图表。
> 我有一份关于 **[你的数据主题，例如：全球咖啡消费量]** 的数据。
> 
> 请使用 Munzner 的视觉通道理论进行映射：
> 1. 用 **[图表类型，例如：柱状图/散点图]** 展现数据。
> 2. 将 **[数据字段A，例如：国家名称]** 映射到 **[视觉通道：X轴（空间位置）]**。
> 3. 将 **[数据字段B，例如：消费量]** 映射到 **[视觉通道：Y轴（空间位置）]**。
> 4. 将 **[数据字段C，例如：地区]** 映射到 **[视觉通道：颜色色相 (Color Hue)]**。
> 5. （可选）将 **[数据字段D，例如：人口]** 映射到 **[视觉通道：大小 (Size)]**。
> 
> 【关键安全要求】：由于我只会直接双击打开本地 HTML 文件，为了避免触发浏览器的 CORS 跨域报错，**请绝对不要使用 `d3.csv` 去请求外部文件！** 你必须直接提供一组模拟数据，以硬编码的方式（如 JSON 数组或 CSV 字符串常量）直接写死在代码里。请确保模拟数据量足够大（至少40条以上），以便呈现出视觉规律。
> 
> 请在代码顶部提供一个清晰的、没有复杂嵌套的 `CONFIG` 列表，把颜色、尺寸、边距等属性参数设定放在最前面，方便我修改。
> 
> 【进阶交互要求】：请在图表左侧生成一个深色极客风格的 **交互控制面板 (Control Panel)**，里面必须包含：
> 1. 一个控制圆点 Size 通道基准大小的 HTML 滑块 (Slider)；
> 2. 一个过滤幸存率阈值的滑块（低于该值的数据点透明度变为0）；
> 3. 一个名为“Freeze Time (冻结时间)”的按钮，用于随时暂停/恢复 D3 入场动画和悬停效果，方便我从容地检查边缘数据。
> 
> 代码需要写在一个可以直接双击浏览器运行的单一 `.html` 文件中。"

只要把这段咒语里的 `[...]` 替换成你想做的内容，AI 就会为你生成一份完整的可视化代码！

## 🛠️ 第二步：安全修改 `CONFIG` 配置块

拿到代码并运行后，你一定会想要调整图表的颜色、大小或者间距。这时候，**请不要去动那些复杂的图表绘制逻辑！** 

在 AI 生成的代码顶部，你会找到一个类似这样的 `CONFIG` 区域。**这里是你的安全乐园！**

```javascript
// ==========================================
// 🎨 CONFIG: 图表安全配置区 (请随意修改这里的值！)
// ==========================================
const CONFIG = {
    canvasWidth: 800,         // 画布宽度 (像素)
    canvasHeight: 600,        // 画布高度 (像素)
    
    // 视觉通道变量干预
    colorWing: "#38BDF8",         // 🪽 机翼颜色
    colorTail: "#A78BFA",         // 🦚 尾翼颜色
    colorCockpit: "#F472B6",      // 👨‍✈️ 驾驶舱颜色
    colorFuselage: "#34D399",     // 🚀 机身颜色
    radiusMax: 18,                // 最大损伤圆点半径
};
// ==========================================
```

> [!IMPORTANT]  
> **安全修改指南**  
> 1. **只在这个 `CONFIG` 块内修改数值。** 所有的配置都是简单的属性参数列表，没有复杂的嵌套结构！比如把 `canvasWidth` 从 `800` 改成 `1000` 看看画布变宽的效果。
> 2. **颜色修改：** 你可以去取色网站找喜欢的 HEX 颜色代码（例如 `#FF0000` 表示红色），替换掉对应分类的颜色值。
> 3. **文字修改：** 修改引号 `""` 里的内容来改变标题。

通过这种“变量干预”的方式，你既掌握了图表的视觉控制权，又完全不用担心把代码改坏啦！

## ⏸️ 第三步：掌握“Freeze Time”超能力

在复杂的图表中，AI 往往会添加一些酷炫的入场动画（比如数据点一个个飞入屏幕）。但有时候，这些动画跑得太快，可能会让你感到手忙脚乱，难以看清数据到底在哪儿。

**不用慌张！** 我们在咒语中特意让 AI 为你加入了一个 **“Freeze Time (冻结时间)”** 按钮。

> [!NOTE]  
> **如何使用 Freeze Time**
> - 当你刷新页面、动画开始播放时，如果觉得速度太快看不清细节，立刻点击页面上的 **“Freeze Time”** 按钮。
> - 所有动画都会瞬间停住！
> - 在这静止的时间里，你可以从容不迫地将鼠标悬停在图表的各个元素上，仔细检查工具提示（Tooltip）里的数据，确认 X轴、Y轴、颜色和大小的映射是否准确。
> - 确认无误后，再次点击即可让时间恢复流动。

这是属于我们文科生的安全感设计：**控制节奏，做代码的主人。**

## 💡 第四步：发现你的 Aha Moment

在不断调整 `CONFIG` 中的颜色和映射时，你可能会突然发现：
“哇！当我把‘温度’映射到**颜色亮度（Luminance）**，而不是**色相（Hue）**时，数据的冷暖对比瞬间就变得直观了！”

这就是可视化的魅力。我们不需要成为硬核程序员，我们是**视觉通道的指挥家**。利用 AI 生成脚手架，利用 `CONFIG` 控制细节，让数据展现出它该有的故事。

> [!NOTE]  
> **练习目标**
> 1. 成功生成代码，并使用“Freeze Time”按钮暂停动画，感受掌控时间的乐趣。

加油！勇敢地在 `CONFIG` 区里探索吧，你不会弄坏任何东西的！🌟
