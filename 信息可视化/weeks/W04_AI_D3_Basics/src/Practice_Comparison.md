# W04 实践活动：D3.js 三阶创作递进

## 🎯 教学目标与 DMA 核心基调

根据数字媒体艺术（DMA）专业"视觉表达优于底层工程"的设计原则，本次实践**不追求让学生背诵 D3 API 或掌握底层代码架构**。相反，我们的核心目标是让学生通过三阶递进式体验，从「零接触」逐步进化到「资产提取」，建立与 AI + D3 协同工作的直觉。

---

## 🥉 第一阶：一键出图（Vibe Coding 起手式）

### 🎨 活动策划
*   **形式**：Prompt 竞速（Prompt Battle）与视觉盲盒。
*   **任务**：提供一份真实数据（例如"全国 31 个省份的人均 GDP"），要求学生使用 Prompt 指令 AI 生成一个 D3.js 基础柱状图的完整单页 HTML。
*   **操作要点**：学生完全不修改生成的底层代码。如果图形报错或不好看，只能通过修改 Prompt 增加视觉关键词（如"深色主题""圆角柱状""渐变填充"）重新抽卡。

### 🌟 学习意义与 DMA 价值
*   **Vibe Coding 初体验**：感受 AI 生成 SVG 图表的即时性，理解"自然语言即接口"的基本概念。
*   **意图翻译训练**：锻炼将抽象的视觉意图转化为 AI 可执行指令的能力。
*   **降低门槛**：让学生意识到，即使没有任何代码基础，也能通过 Prompt 直接生成可用的图表。

---

## 🥈 第二阶：解剖微调（DevTools 外科手术）

### 🎨 活动策划
*   **形式**：SVG 属性微操竞速。
*   **任务**：基于第一阶生成的 D3 图表，按 F12 打开浏览器 DevTools，在 Elements 面板中直接修改 SVG 元素的属性。例如：将 `fill="steelblue"` 改为 NFU 品牌色系 `fill="#1B5E20"`；把 `r="5"` 改为 `r="20"` 让散点变得巨大；给 `<rect>` 加上 `rx="8"` 实现圆角效果。
*   **操作要点**：学生不修改源代码，只在 DOM 树中实时调整视觉效果。目标是体会 SVG 的透明可检查性（对比 Canvas 的不透明）。

### 🌟 学习意义与 DMA 价值
*   **SVG 透明性直觉**：亲手体验"每个像素都可以在 DevTools 中检查和修改"的强大优势。
*   **排错直觉培养**：当图表出错时，学生已知道可以在 DOM 树中定位问题元素，而不是在代码中大海捞针。
*   **视觉微调能力**：学会用最小的修改量实现最大的视觉提升。

---

## 🥇 第三阶：艺术提取（SVG → Illustrator 工作流）

### 🎨 活动策划
*   **形式**：跨软件创作工作坊。
*   **任务**：使用 SVG Crowbar 等浏览器插件，将 D3 渲染的图表作为极清的 SVG 矢量图导出。将其拖入 Adobe Illustrator 或 Figma 进行二次包装——添加标题、调整配色、设计版式，最终产出展览级视觉海报。
*   **操作要点**：在 AI 中加入排版和配色的设计指令，让 D3 生成的图表最大程度接近最终设计稿。然后在设计软件中完成最后的视觉抬升。

### 🌟 学习意义与 DMA 价值
*   **打通跨界工作流**：在 DMA 领域，代码产物往往需要进入后期流程。学会提取 D3 渲染的 SVG，将其拖入 Illustrator 进行二次包装，完美闭环了从"数据生成"到"视觉设计"的全链路。
*   **去神话化与祻魅**：破除对硬核数据引擎的恐惧，即使写不来 D3 的底层算法，也能通过"AI 生成 + DevTools 排错 + 矢量提取"获得极具张力的设计底稿。
*   **作品集赋能**：最终产出的视觉海报可直接用于个人作品集展示。

---

## 💡 总结矩阵 (TL;DR)

| 核心维度 | 🥉 第一阶（一键出图） | 🥈 第二阶（解剖微调） | 🥇 第三阶（艺术提取） |
| :--- | :--- | :--- | :--- |
| **学生角色** | 纯观察者 | DOM 外科医生 | 跨界创作者 |
| **代码介入** | 零 | DevTools 实时修改 | AI Prompt + Illustrator |
| **排错与干预** | 调整 Prompt，让 AI 重新生成 | 在 DOM 树中定位并修改属性 | 设计软件中精调色彩与版式 |
| **最终产物** | 浏览器截图 | 微调后的实时渲染 | 极清矢量设计稿 |
| **DMA 赋能方向** | Vibe Coding 入门与意图翻译 | SVG 透明性与排错直觉 | Code → Design 全链路闭环 |
