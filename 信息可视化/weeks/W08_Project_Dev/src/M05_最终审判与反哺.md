各位同学，此刻我们来到了这门课程最后的、也是最具仪式感的环节。你们已经在上一模块完成了作品的最终上线部署，拿到了通向互联网大门的密钥。接下来的五十分钟，你们将接受来自同伴的专业评审，并分享你们在整个 Vibe Coding 旅程中最关键的一条 Prompt 洞察。

> [TEACHING MOMENT]
> 八周前，我们从一个问题开始：为什么需要可视化？八周后，你们用自己的作品回答了这个问题。可视化不是让数据变得"好看"，而是让数据变得"可被感知"。技术栈会更新换代，AI 工具会不断迭代，但有一件事永远不会改变：人类需要看到抽象数字背后的人性故事。你们今天部署上线的每一件作品，都是这个信念的一次实践。

> *   **List**: "① 陈述意义：'我感受到了……'\n② 创作者提问：'你觉得这里的节奏如何？'\n③ 中性提问：'你选择这个色阶考虑了什么？'\n④ 许可意见：'我可以就 XX 给建议吗？'"

请大家注视大屏幕上的评审雷达与流程框架。这套流程将保证我们的专业交流不会滑向人身攻击，而是建设性地提升每组项目的设计逻辑。准备好你的观察。

> [ACTIVITY]
> *   **Type**: `Discussion`
> *   **Duration**: `30min`
> *   **Desc**: Peer Critique 互评大会
> 
> **评审规则**：
> 采用 **Liz Lerman 四步 Critical Response Process**：
> 
> **Step 1: 陈述意义 (1 分钟/组)**
> - 每位评审者描述作品给自己留下的印象和感受
> 
> **Step 2: 创作者提问 (2 分钟/组)**
> - 创作团队就自己不确定的部分向评审者提问
> 
> **Step 3: 中性提问 (1 分钟/组)**
> - 评审者用不带判断的问题引导讨论
> 
> **Step 4: 许可意见 (2 分钟/组)**
> - 需先征得同意：「我可以就交互逻辑方面给一个建议吗？」然后给出建议。
> 
> **五维评价打分**（每维 1-5 分）：
> - **数据故事**：洞察是否清晰？
> - **数据抽象**：来源是否可靠？
> - **视觉编码**：通道选择是否有效？
> - **交互设计**：是否支撑叙事推进？
> - **艺术封装**：排版/留白是否提升质感？
> 
> **组织方式**：每组展示 3 分钟 + 评审 3 分钟，共轮转。

> [ACTIVITY]
> *   **Type**: `Discussion`
> *   **Duration**: `10min`
> *   **Desc**: Best Prompt 洞察大会
> 
> **规则**：
> 1. 每组推选一条在 Vibe Coding 过程中**最关键的 Prompt**
> 2. 分享时必须回答三个问题：
>    - 这条 Prompt 为什么有效？
>    - 它如何帮助 AI 理解了你的意图？
>    - 这条 Prompt 反映了你对问题本质的什么理解？
> 3. 全班投票选出 **"Best Final Killer Prompt"**
> 
> > 分享 Best Prompt 的目的不是炫技，而是**元认知的外化**：你对问题的理解越深，你给 AI 的指令就越精准。

> **教师结语深度延展要点**：
> 1. **回溯成长坐标系**：从第一周面对认知心理学的迷茫，到第五周与 D3.js 底层死磕，再到今天面对服务器终端自信敲下部署命令。你们不再是视觉美工，而是具备全链路数字工程视野的交互叙事师。
> 2. **AI 与人的博弈**：在这个学期的 Vibe Coding 中，你们应该明白，AI 可以为你敲下万行代码，但它无法定义一个关于留守儿童或者气候变暖的核心观点。算法是廉价的，但你对这个世界深切的悲悯之心、对社会弱势群体的洞察力是无价的。这就是我们说的“反哺”——用最前端的技术，去反哺最古老的人文关怀。
> 3. **终身的作品集意识**：课程结束了，但作品的生命周期才刚开始。不要让你的 Vercel 链接变成死链。未来在找工作时，随时基于最新的数据源去更新你的 GitHub 代码，让它成为一个活的、伴随你职业生涯共同成长的开源资产。
> 4. **最后的任务要求**：
>    - 课后 24 小时内，请确保你们的 `README.md` 中所有引用声明无误。
>    - 将本节课票选出的 Best Prompt 汇编总结，上传至课程学习平台作为反思日志。
> 
> 最后，用这门课第一讲的一句话送给大家结束本学期：“我们不画图表，我们用数据雕刻真理。” 下课，祝大家未来一切顺利！
