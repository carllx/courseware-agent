实验二实践指南：打破图表崇拜——基于 RawGraphs 的原子语法初探

定位：本次实践是你接触“原子语法（Marks & Channels）”理论的重要环节。 实践目标：通过复杂图表（流向图、小提琴图、蜂群图）的生成体验，你将亲身感受底层通道语法如何揭示隐藏的数据真相。只要掌握了这套方法，你就不再是图表模板的搬运工，而是数据世界的造物主。 工具：RawGraphs 2.0

📁 数据源准备 (Data Context)

本次实践你可以从以下数据源中选择： 1. 使用预置数据：一份名为 student_data_expanded.csv 的虚拟采样数据（专门为暴露“群体断层”与“极端异常值”而设计），包含：学生ID（分类）、年级（分类）、学院（分类）、课后首选去向（分类）、周均图书馆时长（定量）、月均食堂消费（定量）。 2. 导入自有数据：自己准备并导入一份感兴趣的 CSV/Excel 数据集。 3. 使用示例数据：使用 RawGraphs 平台内置的示例数据模板（点击 ‘Try our samples!’）。

🚀 选项一：流向图 (Alluvial Diagram) —— 发现消失的支流

流向图（桑基图的变种）极其适合表现群体的分流与汇聚。它能帮你揭示多维度分类数据（如跨越年级和专业）的“空间壁垒”。

Steps (节点/X轴位置) 【Aa 学院】
【Aa 课后首选去向】
【Aa 年级】		 按顺序拖入。决定河流从左到右流经的三个节点分类。
Size (厚度/面积) （留空自动计算） 自动按各分支的人数比例计算河流的厚度（面积通道）。

3. 数据洞察与分析 (Analysis)

🔍 你的分析任务： 生成图表后，请在实验报告中撰写你的数据洞察。你可以参考以下观察视角： * 不可逾越的“空间壁垒”：观察最底部的去向节点（如【工作室】），看看它是被所有学院均分，还是被特定学院绝对垄断？其他学院的河流是否在这里遭遇了断流？ * 群体的“命运收束”：顺着最右侧的【大四】节点往左倒推，观察流量的来源。是否存在某些特定的去向全盘接管了大四学生的命运路线？

🎻 选项二：小提琴图 (Violin Plot) —— 看透群体的身材

小提琴图的伟大之处在于它不盲目相信“平均数”，而是通过身材的宽窄（核密度估计），扒光人群真实的分布规律。

2. 变量映射配置 (Mapping)

注意：在第一步 Load Data 时，必须确认数值型字段（如【周均图书馆时长】）为 # Number 类型，否则会报错。

RawGraphs 变量名 绑定的数据维度 映射说明 (底层通道解析)
X Axis (分组位置) （留空） 小提琴图自带分组机制，勿填。
Size (Y轴/高度) 【# 周均图书馆时长】 决定小提琴在垂直方向的高度延展。
Groups (分类分组) 【Aa 学院】 将数据拆分为代表不同组别的小提琴。
Color (身份识别) 【Aa 学院】 赋予各组专属颜色，加强视觉辨识。

3. 数据洞察与分析 (Analysis)

🔍 你的分析任务： 生成图表后，请在实验报告中撰写你的数据洞察。你可以参考以下观察视角： * 分布形态的差异：对比不同组别的小提琴形状。是否存在像“大水滴”一样的标准正态分布？是否存在中间细、两头粗的“双峰分布”？或者带有长长尾巴的“右偏分布”？ * 平均数的骗局：如果一个组别呈现“双峰分布”（如极高和极低两群人），它计算出的平均数在现实中代表了什么？这个平均数是否掩盖了内部的分裂真相？

🐝 选项三：蜂群图 (Beeswarm) —— 对个体的终极尊重

在流向图里看汇聚，在蜂群图里看个体。蜂群图是体验“0D 点标记（Point Mark）”与通道叠加威力的终极武器。

2. 变量映射配置 (Mapping)

RawGraphs 变量名 绑定的数据维度 映射说明 (底层通道解析)
X Axis (量化通道) 【# 月均食堂消费】 决定圆点在横轴的位置，越靠右数值越高。
Size (面积/大小) （留空） 保持克制，全员等大。
Color (身份通道) 【Aa 学院】 识别每个点的组别身份。

Groups (Y轴分类) 【Aa 课后首选去向】 在 Y 轴拉出平行的物理空间跑道。

3. 数据洞察与分析 (Analysis)

🔍 你的分析任务： 生成图表后，请在实验报告中撰写你的数据洞察。你可以参考以下观察视角： * 属性决定阶层（看 X 轴漂移）：观察不同跑道上的蜂群在 X 轴上的分布。特定的去向是否与特定的消费水平高度绑定？ * 穿透跑道的“色彩结界”：观察某一条跑道内部的颜色构成。是否存在某个物理空间被单一颜色的点完全垄断的现象？ * 寻找极端的离群个体：在茫茫点海中寻找偏离大部队的孤立圆点。思考：为什么说 0D 点标记呈现了群体的趋势，但又不抹杀个体的尊严？

🎓 实验反思：回归原子语法

当你看着满屏的数据图形时，请反思： > 只要你掌握了底层的通道指令（比如用 X轴代表数值，用 Y轴代表空间，用颜色代表身份），这些数据标记就会忠实地呈现出全维度的生态。 > 图表的本质并非美化，而是利用 视觉通道（Marks & Channels） 揭示真相。
