### 犯罪标本制作规格

#### 标本 A：3D 饼图（对应 M03 Stevens 定律）

1. 在 Excel 中打开 `starbucks_teaching_subset.csv`
2. 按品类汇总平均卡路里：黑咖啡(5) / 经典浓缩(111) / 招牌特调(260) / 茶饮(167) / 果昔(275) / 星冰乐(253)
3. 插入 → 饼图 → **3D 饼图**
4. 保持默认的渐变颜色和阴影效果
5. 另存为 SVG → `Black_Museum_Case_A_PieChart3D.svg`

**故意犯的错**：
- 面积通道 Stevens 系数仅 0.7，人眼严重低估差异
- 角度比较是通道排名倒数第三
- 3D 透视导致前方扇区视觉放大，后方扇区被遮挡

#### 标本 B：雷达图（对应 M01 时空隐喻 + M02 表达性原则）

1. 选取数据中的「Java Chip 星冰乐」一行
2. 以 5 项指标（卡路里/脂肪/含糖量/咖啡因/蛋白质）为 5 个轴
3. 插入 → 雷达图
4. 另存为 SVG → `Black_Museum_Case_B_RadarChart.svg`

**故意犯的错**：
- 雷达图的闭合结构暗示各指标之间存在"循环平衡关系"——但卡路里和脂肪是独立指标
- 极坐标面积变形增加了两层认知解码负荷
- 违反表达性原则：独立连续指标被强行映射为放射状分类轴

#### 标本 C：3D 堆叠柱状图（对应 M04 Data-Ink Ratio）

1. 选取 5 款饮品（黑咖啡/拿铁/焦糖玛奇朵/Java Chip 星冰乐/草莓果昔）
2. 以含糖量和脂肪为两个堆叠维度
3. 插入 → 柱状图 → **3D 堆叠柱状图**
4. 添加：渐变背景、粗网格线、3D 地板、阴影效果、图例框
5. 另存为 SVG → `Black_Museum_Case_C_StackedBar3D.svg`

**故意犯的错**：
- 后排柱子被前排 3D 厚度完全遮挡（Occlusion）
- 透视失真导致近大远小（Perspective Distortion）
- Chartjunk 四大常客齐聚：渐变背景 + 冗余网格线 + 3D 地板 + 阴影效果

## P2：法医解剖——通道审计（30 分钟）

> **对应逐字稿**：M05 §5.1
> **教学目标**：拆解 SVG 标本中的每个视觉元素，识别通道映射错误

### Figma 操作 SOP

| 步骤 | 操作 | 快捷键 | 目的 |
|------|------|--------|------|
| 1 | 将 3 份 SVG 拖拽到 Figma 画布 | 直接拖放 | 每个 `<path>/<rect>/<text>` 自动成为独立图层 |
| 2 | 选中所有元素 → **Flatten Selection** | `⌘+E` | 将复合路径打散为基础几何原子 |
| 3 | 反复 **Ungroup** | `⌘+Shift+G` | 暴露每个独立节点（执行到无嵌套组为止） |
| 4 | 逐个点击几何原子 | 鼠标点击 | 查看右侧面板 Fill（颜色）、W/H（尺寸）、X/Y（位置） |
| 5 | 对照 Munzner 通道量表填写审计表 | — | 每个元素：数据字段 → 通道类型 → 有效性排名 |
| 6 | 用红色矩形 + 文字标注致命错误 | `R`（矩形）+ `T`（文字） | 产出"犯罪现场诊断日志" |

### 通道审计表模板

每份标本填写一张：

| 数据字段 | 原始通道 | Munzner 排名 | 错误描述 | 建议修正通道 | 理论依据 |
|---------|---------|-------------|---------|-------------|---------|
| 品类名称 | 颜色+角度(饼图) | 角度=倒数第3 | 面积系数0.7+角度难以精确比较 | 空间位置(柱状图X轴) | Stevens 定律 |
| 卡路里 | 扇区面积 | 面积=第5 | 3D透视导致前方扇区视觉放大 | 长度(柱状图高度) | No Unjustified 3D |
| ... | ... | ... | ... | ... | ... |

## P3：通道重建——图表外科手术（40 分钟）

> **对应逐字稿**：M05 §5.2
> **教学目标**：从零构建正确的图表形态，掌握 SWD 四次迭代法

### SWD 四次迭代法操作路径

> 参考视频 `CJn9NaqNNgo` 的核心方法论，映射到 Figma 操作：

```
  ┌──────────────┐     ┌──────────────┐     ┌──────────────┐     ┌──────────────┐
  │   STEP 1     │     │   STEP 2     │     │   STEP 3     │     │   STEP 4     │
  │  降噪清除    │ ──→ │  形态替换    │ ──→ │  骨架构建    │ ──→ │  冗余注入    │
  │              │     │              │     │              │     │              │
  │ 删除3D/渐变/ │     │ 饼图→柱状图  │     │ 坐标轴+刻度  │     │ 高亮+基准线  │
  │ 网格/阴影/   │     │ 雷达图→折线图 │     │ +数据标记+   │     │ +结论标注+   │
  │ 数据表格图层 │     │ 3D堆叠→2D   │     │ Direct Label │     │ 叙事性标题   │
  └──────────────┘     └──────────────┘     └──────────────┘     └──────────────┘
       (5 min)              (5 min)             (20 min)             (10 min)
```

### 逐步操作指令

#### STEP 1：降噪清除（5 分钟）

| 操作 | Figma 命令 | 说明 |
|------|-----------|------|
| 删除 3D 厚度层 | 选中 → `Delete` | 找到构成 3D 效果的侧面/底面路径，全部删除 |
| 删除渐变背景 | 选中背景矩形 → `Delete` | 背景改为纯白或不设置 |
| 删除冗余网格线 | 选中 → `Delete` | 只保留坐标轴本身 |
| 删除数据表格图层 | 选中 → `Delete` | 如果标本中有内嵌的数据表格，删除它 |

> 💡 **SWD 原则**："每一滴墨水都必须是数据墨水。如果删掉这个元素，图表的信息量不变，那它就是 Chartjunk。"

#### STEP 2：形态替换（5 分钟）

| 原始图表 | 替换为 | 理由 |
|---------|--------|------|
| 3D 饼图 | **水平条形图**（品类作为 Y 轴分类标签，卡路里映射为条形长度） | 长度通道排名第 2，远优于角度/面积 |
| 雷达图 | **水平分组条形图**或**平行坐标图** | 独立指标不应闭合连接 |
| 3D 堆叠柱状图 | **分组柱状图**或**上下拆分面板图** | 消除遮挡，每个数据系列完全可见 |

#### STEP 3：骨架构建（20 分钟）

以**标本 A → 水平条形图**为主要练习对象：

| 步骤 | Figma 操作 | 具体参数 |
|------|-----------|---------|
| 1 | 新建 Frame | `F` → 1200×800px |
| 2 | 画 Y 轴 | `L`（Line）→ 按住 `Shift` 画垂直线 → Stroke: 1px, `#333333` |
| 3 | 标注品类标签 | `T`（Text）→ 在 Y 轴左侧标注：黑咖啡 / 经典浓缩 / 招牌特调 / 茶饮 / 果昔 / 星冰乐 → Inter 或思源黑体, 12pt |
| 4 | 画 X 轴 | `L` → 水平线 → 底部标注"平均卡路里 (kcal)" |
| 5 | 绘制条形标记 | `R`（Rectangle）→ 宽度 = 数据值 × 比例因子（如 1kcal = 2px），高度统一 30px |
| 6 | 统一灰色 | 所有条形 Fill: `#BFBFBF` |
| 7 | Direct Label | `T` → 在每根条形右端标注精确数值（如"253 kcal"）→ **替代图例** |
| 8 | 冻结 | 复制当前 Frame → 重命名为 `v2_Minimal` |

> 💡 **SWD 原则**（视频 `Gb8VLfX140o`）："Never use a default legend again. 直接在数据点旁边标注名称。"

#### STEP 4：冗余决策实验（10 分钟）

在**原 Frame**（非 v2 副本）上继续操作：

| 步骤 | Figma 操作 | 设计决策 |
|------|-----------|---------|
| 1 | 焦点高亮 | 将「星冰乐(咖啡)」和「星冰乐(奶油)」的条形改为橙红色 `#E8553A`，其余保持灰色 `#BFBFBF` |
| 2 | 参考基准线 | `L` → 垂直虚线，标注"WHO 每日游离糖推荐上限 25g" → Stroke: 1px dashed, `#999999` |
| 3 | 结论标注 | `T` → "⚠️ 一杯 Java Chip 星冰乐含糖 62g = 2.5 倍 WHO 每日上限" → 14pt, Bold |
| 4 | 命名 | 将 Frame 命名为 `v3_Guided` |

### 产出物标准

```
┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│ v1_Anatomy   │  │  v2_Minimal  │  │  v3_Guided   │
│ (原始犯罪标本)│  │ (灰阶骨架版) │  │ (焦点引导版) │
│              │  │              │  │              │
│ • 3D 饼图    │  │ • 水平条形图  │  │ • 橙红高亮   │
│ • 渐变背景   │  │ • 直接标签   │  │ • WHO 基准线  │
│ • Chartjunk  │  │ • 纯灰阶    │  │ • 结论标注   │
└──────────────┘  └──────────────┘  └──────────────┘
```

## P4：美学与叙事增强（30 分钟）

> **对应逐字稿**：M05 §5.3
> **教学目标**：掌握色板安全验证、无障碍测试、叙事性标题撰写

### 操作步骤

| 步骤 | 时间 | 操作 | 工具 |
|------|------|------|------|
| 1 | 5min | 将 v3 的默认字体全部替换为 **Inter**（英文）或**思源黑体**（中文） | Figma Text 面板 |

| 5 | 5min | 撰写**叙事性标题**（传达结论而非描述）| 手写 |
| 6 | 5min | 整体排版微调：对齐网格、检查间距、添加数据来源脚注 | Figma |

| 步骤 | 时间 | 内容 |

### 同行审查评价框架

评审者需要回答：
1. 修正后的图表是否消除了原始标本的**全部**通道映射错误？
2. v3 的焦点高亮是否有效引导了视觉弹出（Popout）？
3. v4 的色板是否通过了无障碍测试？
4. 叙事性标题是否传达了数据的核心张力？

## 附录：数据速查

### 星巴克教学数据集张力点速览

| 品类 | 代表饮品 | 含糖量 | 方糖等价 | 张力标签 |
|------|---------|--------|---------|---------|
| 黑咖啡 | Brewed Coffee | **0g** | 0 颗 | 🟢 零糖基准 |
| 经典浓缩 | Cappuccino | 10g | 2.5 颗 | 🟡 轻度 |
| 招牌特调 | Caramel Macchiato | 32g | 8 颗 | 🟠 中度 |
| 茶饮 | Green Tea Latte | **56g** | **14 颗** | 🔴 隐形炸弹 |
| 果昔 | Strawberry Banana | 41g | 10 颗 | 🟠 中度 |
| 星冰乐 | Java Chip Frappuccino | **62g** | **15.5 颗** | 🔴 **终极炸弹** |

> 💡 **张力叙事**：小林以为绿茶拿铁和果昔是"健康选择"，但它们的含糖量分别是 56g 和 41g，远超 WHO 每日游离糖推荐上限 25g。而她眼中"不健康"的美式咖啡，含糖量是 0g。

### WHO 参考基准线

- **WHO 强烈建议**：每日游离糖摄入 < 总能量的 10%，约 **50g**
- **WHO 条件建议**：进一步降至 < 5%，约 **25g**（教学中使用此标准作为基准线）
