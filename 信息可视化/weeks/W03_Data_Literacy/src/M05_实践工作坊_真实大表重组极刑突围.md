### 5.3 最终挑战：数据游侠（抓取豆瓣 Top250 并分析）

经历了数据宽表重组的洗礼后，我们来尝试主动出击获取数据。

**1. 理论导入 (Why)：相关性探索**
在数据分析中，我们经常需要探究两个变量之间的关系，即**相关性探索 (Correlation)**。例如在豆瓣电影 Top 250 中，电影的“评分”和“评价人数”之间是否存在正相关？或者上映年份与评分是否有联系？为了验证这个假设，我们需要获取真实的结构化数据。

**2. 实战操作与数据抽象 (What)：暴力拷贝 + AI 结构化法**
与其被复杂的反爬虫机制和代码报错折磨，我们直接利用大模型强大的视觉解析力。打开豆瓣 Top 250 网页，直接用鼠标拖拽全选网页上的书籍列表文字，`Ctrl+C` 复制，然后贴给大模型。
在 Prompt 中下达指令：“我刚从豆瓣复制了一批杂乱的书籍数据。请你帮我提取出每本书的书名、评分、评价人数和价格，并输出为标准的 JSON 格式。”
这种“暴力拷贝法”能 100% 免疫任何网站的反爬虫封禁，让你所见即所得地获取纯净的 JSON 燃料。
获取到 JSON 后，我们必须对其进行 **What（数据抽象）** 的审查：这批数据构成了**表格 (Table)** 数据集；每一本书是一个独立实体 **(Item)**；而评分和评价人数则是**定量属性 (Quantitative Attribute)**。

**3. 数据派生 (Derive)：创造新的分析维度**
永远不要只画你拿到的原始数据！在 JSON 提取完成后，继续向 AI 下达进阶指令：“请帮我把【评分】除以【价格】，派生出一个新的属性列，叫做『性价比』。”
这就是 Tamara Munzner 理论中极具价值的 **Derive（派生）** 操作。它能直接将你的分析降维，把复杂的数学关系转化为直观的单列数据。

**4. 视觉映射 (How)：Munzner 理论审查**
拿到带性价比的 JSON 数据后，让 AI 根据你的白话文 Prompt 自动生成一个散点图，或者直接导入可视化工具（如 RAWGraphs）。
**重点审查**：生成图表后，必须使用 Tamara Munzner 的理论审查图表的“标记与通道 (Marks & Channels)”。对于相关性分析，散点图的标记 (Mark) 是点，通道 (Channel) 必须是：X 轴位置 (Position) 映射“价格”，Y 轴位置映射“评分”，点的大小 (Size) 映射“评价人数”。如果 AI 错误地将评分映射为了颜色 (Color Hue)，你要能用理论词汇严厉指正并要求其修正。

> [扩展阅读] **正规数据抓取方案的进阶**
> 虽然“暴力拷贝 + AI 注入法”非常便捷，但面对海量自动翻页任务时，我们需要正规军：
> 1. **Python 方案 (Pandas / Requests / BeautifulSoup)**：适合大规模并发抓取与深度数据清洗。
> 2. **NodeJS 方案 (Puppeteer / Playwright)**：基于无头浏览器，能够完美模拟真人点击。
