# 通道精度、可分离性与视觉弹出

> 来源：Munzner Ch5 §5.5-5.6

## 核心论点

通道效能不是一个笼统的"好用/不好用"——它可以沿五个精确的维度被量化拆解。

### 精度：Stevens 幂定律 (§5.5.1)
- 人对不同通道的感知精度遵循幂函数 S = Iⁿ
- **长度 n = 1.0**：感知与真值完美匹配，这是最精确的通道
- **面积 n < 1**（亚线性/压缩）：面积翻倍，感知远不到两倍——人天生低估面积差异
- **饱和度 n > 1**（超线性/放大）：微小的饱和度变化被夸大感知
- Cleveland & McGill 实验排序：对齐位置 > 非对齐位置 > 长度 > 角度 > 面积 >> 其他

### 可辨别性 (§5.5.2)
- 每个通道能提供的"可区分步级 (Bins)"数量有限
- 线宽只有 3-4 步；色相约 6-12 步（取决于上下文）
- **铁律**：需要编码的值的数量 ≤ 通道可用 Bins 数。不匹配就必须聚合或换通道

### 可分离性 vs 整合性 (§5.5.3)
- **可分离通道对**：位置 + 色相 → 可独立读取两个属性
- **整合通道对**：水平尺寸 + 垂直尺寸 → 自动融合为"面积"感知，三组（小/扁/大），无法回溯原始二维信息
- **RGB 陷阱**：红绿通道完全不可分离——计算机色彩模型与人类感知模型是两套系统
- 尺寸与色相之间存在干扰：小对象上的颜色更难辨别

### 视觉弹出 (§5.5.4)
- 弹出 = 低级视觉系统的**大规模并行处理**，目标检测时间不随干扰项数量增长
- 色相弹出强于形状弹出（红色从蓝色海洋中跳出速度 > 圆从方块海洋）
- **致命限制**：两个通道同时编码时弹出失效——红色圆形无法从"红方块 + 蓝圆"中弹出，退化为串行搜索
- 设计者一次只能依赖**一个通道**的弹出效应

### 分组 (§5.5.5)
- 分组强度排序：包含 > 连接 > 邻近 > 相似（色相/运动/形状）
- 空间区域分组远强于其他通道 → 这就是为什么分类数据首选空间区域编码

### 相对判断 vs 绝对判断 (§5.6 Weber's Law)
- 人类感知系统基于**相对判断**，不是绝对判断
- 对齐+共享刻度 → 精度暴增（15% 长度差难辨 → 50% 空白差易辨）
- 颜色感知完全依赖上下文：同色块在不同背景下看起来截然不同（棋盘错觉）

## 反面论据（双覆盖）

- 弹出不是万能：超过一个通道就退化为串行搜索
- 整合通道对并非"坏的"：用它编码单属性三类别反而高效
- Weber's Law 意味着所有"不对齐、不加框"的绝对大小比较都不可靠
