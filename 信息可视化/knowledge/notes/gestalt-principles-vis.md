# 格式塔知觉组织原则与可视化设计

> 来源：郝亚维第一章 §四·(四)·1; Munzner Ch5 参考

## 核心论点

**人类视觉天生就在"找规律"**——格式塔心理学揭示了视知觉自动组织信息的七大法则，直接决定了可视化设计中元素如何被读者感知为"一组"或"分离"。

### 七大原则

1. **靠近性 (Proximity)**：距离越近 → 越容易被感知为同组。可视化中的间距就是信息层级
2. **相似性 (Similarity)**：形状/颜色/大小相同 → 被归为同类。这是色彩编码和形状编码的心理学基础
3. **连续性 (Continuity)**：视觉倾向于感知连续形状而非碎片。折线图之所以"好读"的底层原因
4. **闭合性 (Closure)**：不完整图形会被大脑自动"补完"。卡尼萨三角——看不见的三角形
5. **主体与背景 (Figure-Ground)**：小图形自动成为主体，大色块自动成为背景。信息层级设计依据
6. **简单对称性 (Simplicity/Symmetry)**：对称、规则、简单的图形优先被整体感知
7. **共同命运 (Common Fate)**：共同运动的元素被视为一组——**动态可视化的理论基石**

### 在可视化设计中的实操映射

| 格式塔原则 | 可视化设计映射 |
|:---|:---|
| 靠近性 | 图表内分组间距 > 组内间距 |
| 相似性 | 同类数据用同色/同形 |
| 连续性 | 折线图、流图的可读性 |
| 闭合性 | 区域图填充、边界暗示 |
| 主体/背景 | 数据层 vs 网格层的视觉层级 |
| 共同命运 | 动画中同步运动的元素标识关联性 |

## 反面案例

- 违反靠近性：将不相关的图例紧贴数据区域 → 读者误以为是标注
- 违反相似性：无意义地给同类数据赋予不同颜色 → "彩虹图"灾难
- 滥用闭合性：过多暗示边界 → 读者看到不存在的分组

## 教学关键词
`Gestalt principles`, `proximity`, `similarity`, `closure`, `figure-ground`, `pre-attentive`
