# Vibe Coding 范式：自然语言驱动的编程新范式

> 来源：Andrej Karpathy (2025-02) Twitter/X, IBM, Wikipedia

## 定义

由 OpenAI 联合创始人、前特斯拉 AI 负责人 **Andrej Karpathy** 于 2025 年 2 月提出：

> "Fully give in to the vibes, embrace exponentials, and forget that the code even exists."
> ——完全跟着感觉走，拥抱指数增长，忘掉代码本身的存在。

Vibe Coding 是一种**自然语言驱动的编程范式**：开发者用日常语言描述目标和期望功能，AI（LLM）负责生成对应的可执行代码。

## 核心特征

1. **自然语言即接口**：不再需要精确的语法和命令，用"人话"描述即可
2. **角色转变**：开发者从"写代码的人"变成**架构师、提示词工程师、测试员和修订者**
3. **先生成后精修 (Code First, Refine Later)**：鼓励快速原型和大胆实验
4. **降低门槛**：让缺乏传统编程经验的人也能创建应用程序
5. **Software 3.0**：自然语言提示词 = 新的源代码，LLM = 新的计算单元

## 在可视化教学中的定位

对于数字媒体艺术专业学生而言，Vibe Coding 的意义：
- 绕过"学 API 手册"的枯燥阶段，直接用**视觉意象+自然语言**驱动 D3/ECharts
- 将精力集中在**设计决策**（选什么通道、用什么隐喻）而非语法debug
- **但**：必须理解底层概念（如比例尺、坐标系），否则无法排错 AI 生成的代码

## 风险与反面（双覆盖）

- **代码质量不可控**：AI 生成的代码可能有安全漏洞、性能问题
- **可维护性差**：如果开发者完全不看代码，后续修改困难
- **Simon Willison 的区分**：Vibe Coding ≠ 通用 AI 辅助编程。Vibe Coding 意味着"不审查代码内部结构就接受它"——这在生产环境中很危险
- **能力幻觉**：初学者可能误以为自己"会编程了"，实则对底层原理一无所知
