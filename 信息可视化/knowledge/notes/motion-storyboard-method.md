# 动效分镜方法：从剧本到参数化交互

> 来源：Web 调研 (Motion Design + Data Storytelling) + DMA 教材第五章
> 认知目标：掌握数据可视化的动效分镜设计流程，能独立产出分镜表并指导 AI 生成代码

## 动效分镜定义

动效分镜 (Motion Storyboard) = 为数据叙事编排的视觉蓝图。它逐帧规划：
- **何时**触发动画（滚动位置 / 用户操作）
- **什么**元素发生变化（图表状态 / 标注出现 / 过渡动画）
- **如何**过渡（缓动曲线 / 持续时长 / 分阶段编排）

## 三维拆解模型

```
X 轴 → 时间维度（滚动进度 / 步骤序号）
Y 轴 → 画面描述（关键帧缩略图 + 文字脚本）
Z 轴 → 技术指令（触发条件 + 动画参数 + 数据切换）
```

## 分镜表模板

| Step | 滚动触发点 | 叙事文本 | 画面状态 | 技术指令 |
|:---|:---|:---|:---|:---|
| 0 | 页面加载 | (标题卡) | 标题 + 背景渐入 | `gsap.from('.title', {opacity:0})` |
| 1 | `.step-1` 进入视口中心 | "1990年，中国城市化率仅26%" | 柱状图显示 1990 年数据 | `bindData(data1990)` |
| 2 | `.step-2` 进入视口中心 | "30年后，这个数字翻了两倍" | 柱状图平滑过渡到 2020 年 | `bindData(data2020); bars.transition().duration(800)` |
| 3 | `.step-3` 进入视口中心 | "但增长并不均匀……" | 地图高亮沿海省份 | `highlightCoastal()` |

## 电影类比（DMA 桥接）

| 电影概念 | 数据叙事对等 |
|:---|:---|
| 剧本 (Script) | 数据故事线（叙事文本序列） |
| 分镜脚本 (Storyboard) | 动效分镜表（关键帧 + 触发条件） |
| 运镜 (Camera Movement) | 滚动驱动的视口变化 |
| 场景转换 (Scene Transition) | 图表状态切换动画 |
| 剪辑节奏 (Editing Rhythm) | 步骤间距 × 动画缓动曲线 |

## DMA 教材第五章映射

郝亚维教材中的"推理逻辑信息"项目（如影片《恐怖游轮》《盗梦空间》的剧情分析图）本质上就是静态分镜：
- 用空间位置编码时间线
- 用颜色通道编码因果关系
- 用视觉导向流程引导阅读秩序

Scrollytelling 将这套静态分镜推向动态维度：读者的滚动行为成为"播放键"，每一幕的揭示由主动参与触发。

## AI Prompt 模板（Vibe Coding 集成）

```
请帮我写一个单 HTML 文件的 Scrollytelling 页面：
- 左侧：文本容器，包含 N 个 `.step` 文本块
- 右侧：`position: sticky` 的图表容器
- 引入 GSAP + ScrollTrigger CDN
- 每个 `.step` 进入视口中心时触发对应的图表状态切换
- 图表使用 D3，transition 动画持续 800ms
- 请为每个步骤添加 markers:true 以便调试
```

## 反面警告

- ❌ **无分镜直接编码**：跳过分镜设计将导致步骤间的叙事断裂和动画节奏混乱
- ❌ **步骤过密**：每个 step 之间应留足滚动距离（建议 ≥ 80vh），否则动画来不及完成
- ❌ **动画无缓动**：线性动画 (linear) 缺乏戏剧感，应使用 `power2.inOut` 等自然缓动
