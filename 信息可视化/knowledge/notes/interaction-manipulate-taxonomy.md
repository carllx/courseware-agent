# 交互操作分类框架

> 来源：Munzner Ch11 "Manipulate View" + Web 调研
> 认知目标：理解交互操作的系统分类，掌握 Change / Select / Navigate 三大操作族

## 核心框架

Munzner 将交互操作拆解为三大操作族：

### 1. 改变视图 (Change View over Time)
- **改变编码**：从柱状图切换到热图（如 Tableau 的拖拽切换）
- **改变参数**：调整标记大小范围、颜色映射区间
- **重排序 (Reorder)**：按不同属性列排序，利用空间位置通道的霸权地位发现新模式
- **动画过渡 (Animated Transitions)**：平滑帧序列避免跳切 (Jump Cut)；适用于变化量有限的场景；Heer & Robertson 2007 实证支持其改善图形感知

### 2. 选择元素 (Select Elements)
- **选择目标类型**：数据项 / 链接 / 属性 / 属性层级 / 视图
- **选择集合大小**：单选 / 多选 / 空集 / 主-副选择
- **高亮 (Highlighting)**：颜色变更（会遮盖原编码）、轮廓描边（保留原色编码）、尺寸增大、运动编码（最高显著性但难以忽略）
- **选择后果**：筛选、聚合、编码变更、导航目的地

### 3. 导航 (Navigate)
- **几何缩放 (Geometric Zoom)**：等同现实中的走近/远离
- **语义缩放 (Semantic Zoom)**：根据可用像素数自适应改变表示（如 LiveRAC 的时序线图）
- **约束导航 (Constrained Navigation)**：限制缩放范围 + 自动帧对焦选中项

## DMA 教学映射

| 操作族 | DMA 设计类比 | 课程关联 |
|:---|:---|:---|
| Change → Reorder | 剪辑时间线上拖拽素材重排顺序 | Scrollytelling 步骤编排 |
| Select → Highlight | 调色师在 DaVinci 中框选区域提亮 | 数据刷选与联动高亮 |
| Navigate → Semantic Zoom | 地图应用的街景/卫星视图切换 | 分层叙事的缩放逻辑 |

## 反面案例

- **无约束导航灾难**：用户在 3D 可视化中迷失方向，摄像机冲入物体内部或对准虚空
- **动画滥用**：变化元素过多时，人类无法追踪所有运动，动画过渡失效
- **高亮颜色覆盖**：选择高亮使用颜色变更时，原有的颜色编码信息被临时销毁
