## 一、实验目的

（一）掌握将网页结构转化为大模型认知素材的方法（另存为本地 HTML 模板）。
（二）掌握利用大语言模型（LLM）编写浏览器后台（Console）脚本提取信息的策略。
（三）体会“人机协作（AI Agent协作）”的过程，学会如何通过报错信息引导 AI 修复代码。
（四）能够清洗与整理抓取下来的非结构化信息，输出规范的结构化数据集（CSV）。


## 二、实验设备与环境

1. 硬件：个人计算机
2. 软件：现代浏览器（推荐 Chrome 或 Edge）、大语言模型辅助工具（如 ChatGPT、Claude、Kimi 或 VSCode Agent）


## 三、实验要求

> ⚠️ **【重要扩展要求】**：**严禁在本实验中使用“豆瓣读书”作为抓取目标！** 请务必结合你的个人兴趣选定跨领域目标（如游戏、电影、电商等）。

（一）结合个人业务兴趣，自主选定一个跨领域的包含目标信息的网页，并自行归纳出网页翻页时的 URL 参数路由变化规律（避开无限瀑布流网页）。
（二）将目标网页右键“另存为”本地 HTML 文件，并作为模板提供给大语言模型读取分析。
（三）将总结的翻页规律和明确的字段提取要求写入 Prompt 中，利用大语言模型生成可自动执行抓取和翻页的 JavaScript 脚本，在浏览器后台运行，并保留记录。
（四）最终产出一份合并了多页数据的结构化、清洗干净的表格数据（CSV）。
