# 信息可视化设计 — 实验教学规划

> [!NOTE]
> 本文档对应 `course.yaml → experiments`，共 4 个实验，合计 **20 学时（实践课时）**。
> 实验 1–3 各占**平时成绩的 30%（折合总分 15%）**；实验 4 计入**期末成绩（总分 50%）**，详见 `project_brief.md`。

---

## 实验一：数据获取与清洗（4 学时）

- **类型**：验证型
- **对应周次**：第 2–3 周
- **目标**：建立数据处理基础意识，掌握将原始数据规范化为可视化就绪格式的完整流程。
- **内容**：
  1. 从 Kaggle / 政府开放平台下载真实数据集（CSV / JSON）。
  2. 使用 Python（Pandas）或 AI 辅助识别缺失值、异常值，完成清洗。
  3. 将数据重构为 **Tidy Data** 格式（每行一个观测，每列一个变量）。
  4. 撰写数据描述报告：数据来源、字段说明、清洗决策记录。
- **工具**：Python / Jupyter Notebook、AI 自然语言辅助、Excel 可选。
- **交付物**：
  - 清洗后的 Tidy CSV / JSON 文件
  - 数据描述报告（含来源说明与清洗决策）

---

## 实验二：零代码图表映射与分析（4 学时）

- **类型**：设计型
- **对应周次**：第 2–3 周（配合 W2 Marks & Channels 理论 + W3 数据类型讲授）
- **目标**：通过 RawGraphs 零代码可视化平台体验多维数据的通道映射，运用视觉编码理论（Munzner Marks & Channels）选择合理图表类型，并使用 Figma 进行矢量精修，完成具有视觉隐喻意图的静态可视化作品。
- **内容**：
  1. 在 RawGraphs 2.0 平台加载数据（教师提供的校园采样数据集或内置示例），检查数据类型解析。
  2. 从流向图（Alluvial）、小提琴图（Violin）、蜂群图（Beeswarm）等图表类型中选择至少 **2 种**，配置维度到图表变量的通道映射。
  3. 在 Customize 面板中调整视觉参数，导出 SVG 矢量文件。
  4. 将 SVG 导入 Figma，按数据墨水比原则与 Munzner 通道有效性法则进行矢量精修。
  5. 撰写设计说明：通道映射逻辑、数据洞察发现与零代码工具局限性反思。
- **工具**：RawGraphs 2.0（https://app.rawgraphs.io/）、Adobe Figma。
- **交付物**：
  - RawGraphs 生成的图表文件（SVG/PNG，≥2 种图表类型）
  - Figma 精修前后对比图
  - 设计说明文档（含通道映射逻辑、数据洞察与工具反思，≥300 字）

## 实验三：交互可视化开发（6 学时）

- **类型**：综合型
- **对应周次**：第 5–6 周（配合 W5 生成艺术 + W6 交互叙事讲授）
- **目标**：运用 Vibe Coding 工作流，基于 Web 技术实现具有响应式交互功能的可视化组件。
- **内容**：
  1. 确定交互目标：筛选 / 缩放 / 详情提示 / 滚动叙事（Scrollytelling），至少实现 2 种。
  2. 采用**分步提示词接力策略**驱动 AI 生成 ECharts 或 D3.js 组件。
  3. 实现数据的动态加载与绑定（异步 fetch / CSV 解析）。
  4. 添加前端动效（过渡动画 / hover 高亮 / 联动过滤）。
  5. 本地运行并录制演示视频。
- **工具**：ECharts / D3.js、HTML + CSS + JS、GSAP / ScrollTrigger（可选）、AI 辅助。
- **交付物**：
  - 可运行源代码包（HTML + CSS + JS + 数据文件）
  - 演示视频（≥1 分钟，展示交互功能）
  - 实验报告（含 Vibe 工作流过程记录与反思）

## 实验四：综合项目实战（6 学时）

- **类型**：创新型
- **对应周次**：第 7–8 周
- **目标**：围绕真实社会/文化议题，独立完成具有人文关怀与艺术深度的交互数据叙事作品，并部署至公网。

> [!IMPORTANT]
> 实验四为**期末综合作品**，详细要求（选题方向、Munzner 验证、交付物、评分细则）见：
> 📄 [`practices/project_brief.md`](./project_brief.md)

**核心里程碑**：

| 时间 | 节点 |
|---|---|
| 第 7 周课堂 | 完成"项目一页纸"，通过 Critique 互评 |
| 第 7 周课后 | 完成所有数据清洗与基础图表原型 |
| 第 8 周课堂 | 完成部署，进行 Final Presentation |
