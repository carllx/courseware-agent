项目实战指南：D3.js Bar Chart Race（动态条形图赛跑）

欢迎来到 D3.js 高阶动态图表实战！本项目将指导你如何借助大语言模型（Agent）的力量，在本地开发并运行一个复杂流畅的 Bar Chart Race（动态条形图赛跑）。

1. 项目结构预览

请注意，你不需要自己手动去写代码！在接下来的步骤中，大语言模型（Agent）将会根据你的指令为你自动生成如下的基础项目结构，你可以先在这里预估一下最终会产生哪些文件： - index.html：网页骨架 - style.css：样式表 - main.js：核心图表动效逻辑 - data/category-brands.csv：用来驱动动画的原始数据集（你需要提前将数据文件放在此位置）

2. 🚨 避坑指南：跨域报错 (CORS Error)

为什么以前双击能开，现在非得搞个服务器这么麻烦？

这是因为现在我们的图表需要使用 d3.csv() 读取另外一个数据文件。为了防止恶意网页窃取你的硬盘隐私，现代浏览器有一道非常死板的“防盗门机制”：只要网页是双击打开的（地址栏显示 file:///），就绝对不允许它去读取周围的任何其他文件。这就是为什么数据死活加载不出来，图表一片空白的原因。

✅ 正确的启动姿势：

千万别直接双击打开！我们要利用 VSCode 在本地建一个临时“小前台”。请在左侧扩展商店安装 Live Server 插件。安装完毕后，右键点击 index.html，选择 “Open with Live Server”（或点击底部状态栏的 Go Live 按钮）。

别听到“服务器 (Server)”就觉得要发到网上去，这完全是不连外网的本地“角色扮演”。此时地址变成 http://127.0.0.1:5500（这串数字代表你自己的电脑）。浏览器不再偷偷溜进硬盘翻找文件，而是光明正大走到前台要文件。有了这个正规交接，浏览器的安全警报解除，图表就能顺畅加载了！

💡 核心记忆点： - 双击打开 (file:///) = 浏览器处于“防盗隔离模式”，网页像被关禁闭，不准碰旁边的数据文件。 - Live Server (http://127.0.0.1) = 在自己电脑上开了一个“本地服务台”，左手递网页，右手递数据，浏览器觉得很安全，图表就能正常显示了。

3. 召唤 Agent (Golden Prompt)

Bar Chart Race 是一个高度复杂的动态图表。普通的指令往往会让不够聪明的大模型退化生成成折线图或者毫无动画效果的静态条形图。

经过大量测试，我们为你总结出了一套高鲁棒性（极度稳定）的“黄金指令”。请将以下提示词完整复制，发送给你的 VSCode Agent：

请读取 data/category-brands.csv，使用 D3.js 为我生成一个 **Bar Chart Race（动态条形图赛跑）**。


叙事要求：请以时间（日期/年份）为动画推进线索，展示品牌价值排名不断更迭、互相超越的动态过程。

视觉与动效要求：
1. 结构清晰：请帮我把网页骨架、样式和动效逻辑分别写在不同的文件里（例如分离出 HTML、CSS 和 JS 文件）。
2. 数值平滑过渡：动画过渡必须要非常平滑！当时间切换时，品牌数值的增长必须是连续渐变的，不能出现数值或柱子瞬间跳跃的情况。
3. 超车位移动画：当图表中的柱子发生上下排名交替时，必须像真实赛车一样有流畅的上下“超车”位移动画。新品牌挤入榜单要柔和地淡入，旧品牌掉出榜单要淡出，绝不能让柱子直接闪现或突然消失。
