# Agent 课堂演示指南：美国总统支持率图表

这份指南提供了两个演示方向。所有的提示词都已经改成了极简的“大白话”，去掉了繁琐的代码细节，同时在关键的地方保留了教授强调的专业概念，方便学生理解。

---

## 方向一：一键复刻原版图表（直接复现流）
**演示目的**：向学生展示如何用最简单的日常语言，让 Agent 直接帮我们把 Observable 的原版“总统头像蜜蜂图”给敲出来。

**发给 Agent 的指令：**
```markdown
请帮我写一个单文件的 HTML，用 D3.js ，根据当前目录下 `data/us-president-favorability.csv` 这个数据文件，做一个“总统头像蜜蜂图”。

视觉与交互要求：
1. 以总统上任日期 (First Inauguration Date) 作为横轴线索。
2. 图表上的每一个数据点，请直接用这位总统的真实头像照片（对应数据里的 Portrait URL）来表示。如果处于同一时期的头像挤在一起，请务必让它们自动错开排布（防重叠防遮挡），确保每个头像都能清晰显示。
3. 请把原本正方形的头像照片统一裁剪成精致的小圆形(例如半径为 20px)，并且绝对不要拉伸人脸的比例。
4. 当鼠标悬停在某个头像上时，请自动浮现出这位总统的名字 (Name)。
```

### 备选方案：本地图片复刻版（防网络加载失败）
**演示目的**：如果在课堂上因为网络原因无法加载来自 `Portrait URL` 的维基百科图片，可以使用已经提前下载好并追加了的 `Local Portrait Path` 字段数据来进行替代演示。

**发给 Agent 的指令：**
```markdown
请帮我写一个单文件的 HTML，用 D3.js，根据当前目录下 `data/us-president-favorability.csv` 这个数据文件，做一个“总统头像蜜蜂图”。

视觉与交互要求：
1. 以总统上任日期 (First Inauguration Date) 作为横轴线索。
2. 图表上的每一个数据点，请使用本地提前下载好的总统头像照片（对应数据里的 Local Portrait Path 字段）来表示。如果处于同一时期的头像挤在一起，请务必让它们自动错开排布（防重叠防遮挡），确保每个头像都能清晰显示。
3. 请把原本正方形的头像照片统一裁剪成精致的小圆形(例如半径为 20px)，并且绝对不要拉伸人脸的比例。
4. 当鼠标悬停在某个头像上时，请自动浮现出这位总统的名字 (Name)。
```

## 方向二：与 Agent 商量做图表（探索启发流）
**演示目的**：展示如何通过提问与 Agent 结对工作，先找洞察、定方案，再写代码，培养学生的**分析与设计思维**。

### 第一步：让 Agent 分析数据，头脑风暴
让它先看数据，给我们出主意。

**发给 Agent 的指令：**
```markdown
请帮我看一下 `data/us-president-favorability.csv` 这份数据。
基于这份数据，你能想到哪些有意思的分析视角？如果要做成可视化图表，我们可以怎么做？分别能得到什么样的洞察或见解？
请用大白话给我列出 3 个不同的图表方案。
```

### 第二步：选择方案，强制要求理论规范并生成代码
等 Agent 给完方案后，我们从中选一个（假设我们选了方案 2），然后在要求它写代码的同时，引导它使用教授课上讲的专业理论。

**发给 Agent 的指令：**
```markdown
我觉得方案 2 很好，请帮我用 HTML 单文件（结合 D3.js 和 Observable Plot）把它写出来。

在代码的最前面，请加一段注释，运用 Tamara Munzner 的理论向我解释一下你的设计思路：
1. 你的 Task Abstraction（任务抽象）是什么？
2. 你选了什么 Marks（标记）？用了哪些 Channels（通道，如位置、颜色、大小等）来映射数据？依据有效性（Effectiveness）原则，为什么这么选？

解释完之后请直接提供完整的代码。如果是用图片做图，记得加上防变形的处理。
```
