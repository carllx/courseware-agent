# 26届毕业设计（论文）归档师生协作指南

本指南根据现有教务模板、讲解录音及补充笔记提炼，旨在帮助学生明确材料筹备任务，并协助指导老师快速掌握审核与批注尺度。

## 1. 总体要求与归档顺序
*   **档案袋数量**：每位学生准备两份档案袋。右上角用铅笔分别标注 ① 和 ②（①为原件，②为复印件）。
*   **档案袋封面**：信息居中**手写**，**绝对不能出现擦除、涂抹痕迹**。指导老师姓名后**不写职称**。时间统一填写为：**二〇二六年五月**。
*   **装袋顺序**（从上到下）：论文胶装原件 -> 过程性材料汇编 -> 设计手册（最底）。
*   **打印与装订要求**：汇编材料中的每一份附件必须**单独、双面打印**，严禁出现连排情况。正文类文件排版一般要求为宋体、小四、1.5倍行距（具体以各附件模板标注的格式为准）。**⚠️关键工艺：所有汇编材料按目录顺序汇总后，必须使用“左侧三颗钉”进行规范装订**，切忌散装或随意装订。

> **🔴 全局兜底原则：任何文件中出现的签名栏、日期栏，一律不得留空。** 哪怕该项不适用，也必须划斜杠或注明“无”。所有师生签名必须齐全后方可装袋提交。
> **📅 日期格式区分原则：**
> 1. **所有“封面”类的日期**（档案袋封面、汇编材料封面、开题报告封面、论文封面等）统一使用**中文大写**（如：二〇二六年五月、二〇二五年九月，注意使用“〇”而不是“零”）。
> 2. **所有内部表格落款、签字日期**统一使用**阿拉伯数字**（如：2025年8月30日、2026年04月25日）。

## 2. 核心责任划分速查表
| 责任方 | 核心工作目标 | 必须避免的“雷区” |
| :--- | :--- | :--- |
| **学生 (执行主导)** | 1. 负责所有附件的基础信息填写、报告正文/总结撰写。<br>2. 负责格式排版调整（页眉、行距、单独双面打印）。<br>3. 在系统中导出查重报告，准备答辩现场笔录。 | ✖ 时间线倒错或穿越。<br>✖ 论文正文页面丢失页眉。<br>✖ 查重报告导成了厚厚的“全文对照版”。 |
| **指导老师 (把关审核)** | 1. 审核学生填写的日期逻辑及排版规范（尤其是页眉）。<br>2. 亲自撰写多份文件的“导师意见”。<br>3. 填写《指导教师成绩评定表》并打分（艺术类）。 | ✖ 评语敷衍（只有“同意”两字）。<br>✖ 评定表日期晚于答辩时间。<br>✖ 过程记录的打勾评价与最终给分脱节。 |
| **答辩组 (收尾核定)** | 1. 答辩组长审核答辩记录表并签字。<br>2. 答辩秘书完成答辩及总成绩评定表，专业负责人审核。 | ✖ 答辩记录过于简略、未结合具体设计情况。 |

## 3. 过程性材料汇编清单及细节排雷 (共12项)

### 3.1 封面及目录 (学生独立完成)
*   **[附件1] 汇编封面**：准确填写个人及导师基础信息，排版居中。落款时间：**二〇二六年五月**。
*   **[附件2] 归档目录**：普通情况下，《选题变动申请表》、《延迟答辩申请表》、《成绩复核申请表》需打斜杠。**实操提醒：绝不可留白，直接在对应表格的单元格内手写划“ / ”即可**。若发生上述特殊情况，对应项目必须打勾“√”，并附上对应纸质材料。

### 3.2 课题核心文件 (师生协作)
*   **[附件3] 任务书**：
    *   **学生**：撰写主体内容，调整排版。落款时间：**2025年8月30日**。**注意：须向导师确认其具体职称（教授/副教授/讲师/无）后，再准确填写表格。**
    *   **导师**：审核本人职称填写是否准确。
*   **[附件4] 开题报告**：
    *   **学生**：封面时间为 **二〇二五年九月**。**⚠️系统避坑：维普系统导出会默认将时间识别为答辩当年（2026年），学生导出后必须手动将其修改为 二〇二五年九月。**
    *   **导师**：导师签字时间必须为 **2025年9月20日**。**导师意见须手动补充文字，要求内容充实，严禁只写“同意”二字。**（后置审核节点：专业负责人9月21日，院系负责人9月22日）。
*   **[附件5] 中期检查报告**：
    *   **学生**：落款时间为 **2025年11月15日**。若使用PPT截图，必须保证图片文字清晰可辨。
    *   **导师**：填写中期意见，要求同上（有字数/实质性内容要求）。
*   **[附件6] 选题变动申请表**：
    *   **师生**：一般无需提供。如有，须仔细核对前后填写的题目（尤其注意书名号是否匹配或需要调整）。

### 3.3 过程跟进与系统报告 (师生协作)
*   **[附件7] 过程检查情况记录表**：
    *   **学生**：撰写实践总结。注意必须记录 **至少3次**，且每次间隔必须 **1个月及以上**（例如：25年12月、26年1月、26年2月）。若发现间隔仅几天或一周，必须退回重写。
    *   **导师**：在“总体完成情况”处打“√”，并填写指导意见。**打勾情况应与最终给出的分数档次保持逻辑统一。** 落款时间：**2026年03月20日**。
*   **[附件8] 定稿查重检测报告**：
    *   **学生**：从维普系统导出，**只允许打印“简洁版”**（仅一张纸），绝对不要打印带有复杂文字比对的厚版本。时间：**2026年3月**。

### 3.4 答辩及成绩评定文件 (师生协作/答辩组)

> **💻 维普系统线上操作先后顺序 (极易卡流程)**
> 按照教务逻辑：**学生先传答辩记录 -> 答辩组长审核 -> 答辩秘书给评语和评分 -> 专业负责人审核**。若学生未按时提交记录，秘书将无法完成后续操作。

*   **[附件9] 答辩记录表**：
    *   **学生**：现场答辩时记录（老师问什么，学生答什么）。**内容必须结合论文和设计情况，字数要多写一些，尽量填满整个页面空白处（至少记录3个题目）**。时间：**2026年04月25日**（答辩当天）。
    *   **答辩老师**：纸质表背面需要**两位答辩老师签字**（非一位），并填写答辩时间。答辩组长负责审核记录内容的详实性。
    *   **⚠️特别说明**：维普系统内仅需填报表单信息，无需上传该附件扫描件。**但纸质版必须打印并装订入汇编材料册中**，两者互不替代。
*   **[附件10] 延迟答辩申请表**：没有参加一辩的同学提供，正常同学打斜杠。
*   **[附件11] 指导教师成绩评定表(设计类)**：
    *   **导师**：确认选用艺术类表格（即文件夹中后缀带“(设计)”的模板）。指导导师给分与评阅给分**各占 50%**。**评语不得少于100字**。**红线要求：签字时间必须早于答辩时间（如：2026年04月24日），绝不可晚于或等于答辩时间。**
*   **[附件12] 答辩成绩及总成绩评定表**：
    *   **答辩秘书/专业负责人**：参考黄底模板撰写评语并计算分数。落款时间：**2026年04月25日**。
*   **[附加材料] 终稿查重检测报告**：
    *   **学生**：同定稿查重一样，必须是**一页纸简洁版**，检测时间为 **2026年5月**。
    *   **装订位置：作为汇编材料的最后一页，钉入左侧三颗钉装订册中。**

## 4. 档案袋其它装入材料指引 (学生核心任务)

*   **胶装论文原件**：
    *   封面可手写或打印，**不能出现擦除涂抹痕迹**。时间：**二〇二六年五月**。
    *   《原创性声明》页签字时间：**2026年4月20日**。
    *   **正文排版重点审查**：确保每一页的页眉都正常显示。
*   **设计手册（PPT打印版）**：
    *   封面需使用规范模板。排版参考张院视频模板。**封面须包含以下完整要素：**
        1. 完整论文题目（过长可分行，带书名号 `<XXXXXX毕业论文题目>`）
        2. 固定副标题：`—毕业设计手册`
        3. 学号：`2022XXXXXX`
        4. 指导老师及职称：`X X X 讲师`
    *   必须**双面打印**。
    *   **①号档案袋（原件）放彩色打印版，②号档案袋（复印件）放黑白打印版。**
